Stufe 2: Ausformulierte Umstellung auf Array

Hier siehst du konkret, wie sich der Code veraendert.

Vorher (Einzelvariablen)

a0, a1, a2, a3, a4 := 42, 7, 19, 88, 3 a5, a6, a7, a8, a9 := 25, 71, 14, 60, 9 fmt.Println(a0, a1, a2, a3, a4, a5, a6, a7, a8, a9)

Nachher (Array)

a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println(a) // Ein Pass ueber benachbarte Paare for i := 0; i < len(a)-1; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } }

Stufe 3: Indizes klassisch und mit range

Beide Varianten nutzen denselben Vergleich a[i] > a[i+1].

Variante A: klassische for-Schleife

for i := 0; i < len(a)-1; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } }

Variante B: range ueber den Bereich ohne letztes Element

for i := range a[:len(a)-1] { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } }
Merksatz: Das letzte Element hat keinen rechten Nachbarn. Deshalb endet der Lauf bei len(a)-2.

Naechste Stufe: Hardcoded Passes mit Zwischenausgabe

Wir schreiben mehrere Passes bewusst aus, damit die Sortierung sichtbar wird.

package main import "fmt" func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) // Pass 1 for i := 0; i < len(a)-1; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Println("Nach Pass 1:", a) // Pass 2 for i := 0; i < len(a)-2; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Println("Nach Pass 2:", a) // Pass 3 for i := 0; i < len(a)-3; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Println("Nach Pass 3:", a) }

Naechste Stufe: Doppelte Iteration (ohne Funktionen)

Jetzt wird aus den einzeln ausgeschriebenen Passes eine allgemeine Schleifenloesung.

package main import "fmt" func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) // aeussere Schleife: Anzahl der Passes for pass := 0; pass < len(a)-1; pass++ { // innere Schleife: benachbarte Werte vergleichen und tauschen for i := 0; i < len(a)-1-pass; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }

Vollstaendiger Code (feste oder zufaellige Startwerte)

package main import ( "fmt" "math/rand" "time" ) func main() { rand.Seed(time.Now().UnixNano()) // Variante A: feste Werte a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} // Variante B: zufaellige Werte (statt Eingabe) // for i := range a { // a[i] = rand.Intn(100) + 1 // } fmt.Println("Unsortiert:", a) for pass := 0; pass < len(a)-1; pass++ { for i := 0; i < len(a)-1-pass; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }
