Arrays in Go

Ein Array fasst eine feste Zahl von Werten des gleichen Typs unter einem Namen zusammen. Die Seite zeigt, wie man ein Array anlegt, wie man mit dem Index ein Element anspricht, wie man ein Array mit einer Schleife durchläuft und was ein zweidimensionales Array ist.

Kurstext v3.0.6, Kapitel 6, Seiten 151–162.

Worum es geht

Oft gehören mehrere Werte des gleichen Typs zusammen, zum Beispiel die sechs Zahlen einer Lottoziehung. Mit einzelnen Variablen sieht das so aus:

var z1, z2, z3, z4, z5, z6 int = 3, 17, 24, 31, 36, 47
fmt.Println(z1, z2, z3, z4, z5, z6)

Schon bei sechs Werten ist das mühsam. Bei tausend Werten geht es nicht mehr. Vor allem kann keine Schleife über z1 bis z6 laufen, denn jeder Name muss einzeln im Programm stehen.

Dafür gibt es das Array. Ein Array ist eine Folge aus einer festen Zahl von Elementen, die alle Werte eines einzigen Typs sind:

var lotto [6]int = [6]int{3, 17, 24, 31, 36, 47}
fmt.Println(lotto)    // [3 17 24 31 36 47]

Die sechs Werte haben jetzt einen gemeinsamen Namen. Jedes Element hat eine Nummer, seinen Index. Über den Index kann eine Schleife alle Elemente nacheinander ansprechen.

Schritt 1: Array und Literal

Erst vorhersagen, dann ausprobieren
  1. Was gibt fmt.Println(q) nach q := [5]float64{12.5, -8.3} aus?
    Auflösung[12.5 -8.3 0 0 0]. Das Array hat fünf Elemente. Die drei Elemente ohne Wert bekommen den Null-Wert des Typs.
  2. Übersetzt Go die Zeile var b [6]int = [4]int{5, 8, 8, 2}?
    AuflösungNein. [4]int und [6]int sind zwei verschiedene Typen.

Der Typ eines Arrays

Die Variable lotto hat den Typ [6]int. Ein Array-Typ besteht aus zwei Teilen:

  • Die Länge, in eckigen Klammern: Sie sagt, wie viele Elemente das Array hat. Sie steht fest, wenn das Programm übersetzt wird. Deshalb muss sie eine Konstante sein und darf keine Variable sein.
  • Der Element-Typ, dahinter: Alle Elemente haben diesen Typ.

Die Länge gehört zum Typ. [4]int ist deshalb ein anderer Typ als [6]int, und ein Array mit vier Elementen lässt sich keiner Variable vom Typ [6]int zuweisen.

Das Array-Literal

Rechts vom Gleichheitszeichen steht ein Array-Literal: erst der Typ, dann in geschweiften Klammern die Werte, durch Kommas getrennt. Ein Array-Literal ist ein Ausdruck.

  • Kurze Deklaration: Go leitet den Typ aus dem Literal ab. lotto := [6]int{3, 17, 24, 31, 36, 47}
  • Fehlende Werte: Stehen im Literal weniger Werte, als das Array Elemente hat, bekommen die übrigen den Null-Wert des Element-Typs. Bei Zahlen ist das 0, bei bool ist es false, bei string der leere String.
  • Ohne Literal: var jahr [12]int legt zwölf Elemente an, alle mit dem Wert 0.
  • Die Ellipse ...: Stehen im Typ drei Punkte anstelle der Länge, zählt Go die Werte im Literal. [...]int{3, 17, 24} hat den Typ [3]int.

Ausprobieren: neun Deklarationen


    

    


    
Ein Wert je Zeile

    
Ein langes Literal darf über mehrere Zeilen gehen, zum Beispiel für Kommentare. Dann steht auch hinter dem letzten Wert ein Komma:


lotto := [...]int{
    3,
    17, // Geburtsjahr von Oma
    24,
    31,
    36, // Glückszahl
    47,
}

    
Das Komma am Ende wirkt zuerst lästig. Es hat einen Vorteil: Wer die letzte Zeile verschiebt oder auskommentiert, muss kein Komma nachtragen oder löschen.


    
Ein Literal mit Variablen

    
In einem Array-Literal dürfen auch Variablen stehen. Go wertet das Literal einmal aus, in dem Augenblick der Zuweisung. Ändert sich die Variable später, bleibt das Array, wie es ist:


s := -5
r := [...]int{3, 4, s, 6}
fmt.Println(r)    // [3 4 -5 6]
s = 8
fmt.Println(r)    // [3 4 -5 6]

r = [...]int{0, 1, 0, s}    // ein Literal lässt sich jederzeit zuweisen
fmt.Println(r)    // [0 1 0 8]

  

  

    
    
  

  


  

  

    
Schritt 2: Index

    
Erst vorhersagen, dann ausprobieren
      
    
        
  1. Das Array lotto hat sechs Elemente. Welchen Index hat das letzte?
          
    Auflösung5. Die Zählung beginnt bei 0. Das letzte Element eines Arrays der Länge n hat den Index n − 1.
    2. 
      

    

    
Jedes Element eines Arrays steht an einer festen Stelle. Die Nummer dieser Stelle heißt Index. Arrays sind null-indiziert: Das erste Element hat den Index 0, das zweite den Index 1.

    
Mit einem Index-Ausdruck greift man auf ein Element zu. Er besteht aus dem Namen des Arrays und einem Ausdruck in eckigen Klammern: a[i]. Ein Element wie a[i] heißt indizierte Variable. Man kann es lesen und ihm einen Wert zuweisen wie jeder anderen Variable.


i := 2
a := [...]int{11, 22, 33, 44}
a[i] = 99
fmt.Println(a)              // [11 22 99 44]
fmt.Println(a[0] + a[3])    // 55


    
Die Länge

    
Die eingebaute Funktion len liefert die Länge eines Arrays. len(a)-1 ist deshalb immer der Index des letzten Elements, und a[len(a)-1] ist das letzte Element.


    
Ausprobieren: lesen und zuweisen

    
Wähle ein Element. Trage einen Wert ein und weise ihn zu.

    

    

      
      
      
      
    

    

      Ein Index außerhalb:
      
      
    

    

    


    
Ein Index außerhalb des Arrays

    
Ein Index, der negativ ist oder zu groß, ist ungültig. Wann Go das bemerkt, hängt davon ab, wann der Index feststeht:

    
    
      
  • Der Index ist eine Konstante: Der Compiler sieht den Fehler und übersetzt das Programm nicht.
    • 
      
  • Der Index ist eine Variable: Ihren Wert kennt Go erst, wenn das Programm läuft. Das Programm wird übersetzt und bricht an dieser Stelle mit einer Meldung ab.
    • 
    

    
Go prüft also jeden Zugriff. Ein Programm kann nie unbemerkt neben ein Array greifen.


    
Index-Positionen im Literal

    
In einem Array-Literal kann vor einem Wert sein Index stehen, gefolgt von einem Doppelpunkt. Der Wert kommt dann an diese Stelle. Alle Stellen ohne Wert bekommen den Null-Wert:


b := [8]int{5, 2: 8, 4: -2}
c := [...]int{4: 6}
fmt.Println(b)    // [5 0 8 0 -2 0 0 0]
fmt.Println(c)    // [0 0 0 0 6]

    
Bei c zählt Go mit der Ellipse bis zum größten Index: Das Array hat fünf Elemente.

  

  

    
    
  

  


  

  

    
Schritt 3: Durchlaufen

    
Erst vorhersagen, dann ausprobieren
      
    
        
  1. In einer for-range-Schleife über a steht im Rumpf v = 99. Was enthält a nach der Schleife?
          
    AuflösungDie alten Werte. v ist eine Kopie des Elements. Wer das Element ändern will, schreibt a[i] = 99. Die fünfte Fassung der Demo zeigt es.
    2. 
      

    

    
Wer alle Elemente eines Arrays der Reihe nach braucht, nimmt eine Schleife. Mit der for-Klausel aus Kapitel 5 sieht sie fast immer gleich aus:

    
    
      
  • Init-Anweisung i := 0: Die Laufvariable beginnt beim Index des ersten Elements.
    • 
      
  • Bedingung i < len(a): Im Rumpf ist i höchstens len(a)-1, also der Index des letzten Elements.
    • 
      
  • Post-Anweisung i++: Nach jedem Durchlauf geht es zum nächsten Index.
    • 
    


    
Die for-Anweisung mit range-Klausel

    
Weil diese Schleife so oft vorkommt, hat Go eine kürzere Form dafür, die for-range-Schleife:


for i, v := range a {
    …
}

    
    
      
  • Rechts von range: Dort steht das Array.
    • 
      
  • Die erste Variable, hier i: Sie ist die Index-Variable und hat den Typ int. Sie beginnt bei 0 und wird nach jedem Durchlauf um 1 erhöht.
    • 
      
  • Die zweite Variable, hier v: Sie hat den Element-Typ des Arrays. Vor jedem Durchlauf bekommt sie den Wert von a[i]. Sie darf fehlen.
    • 
    

    
Beide Variablen gelten nur im Rumpf der Schleife. Die Namen i für Index und v für das englische value sind üblich.


    
Ausprobieren: fünf Schleifen Zeile für Zeile

    

    
    
    
    
      
      
      
    
    
    
    
    
    
    
    Ausgabe des Programms:
    
    
    
    
    

    
    Welche Variable man weglassen kann
    
    
      
      
    • Nur der Wert wird gebraucht: Go übersetzt kein Programm mit einer ungenutzten Variable. Für den Index steht dann der leere Bezeichner _: for _, v := range a.
      • 
      
    • Nur der Index wird gebraucht: Die zweite Variable fällt einfach weg: for i := range a.
      • 
      
    • Keine von beiden wird gebraucht: for range a führt den Rumpf einmal je Element aus.
      • 
    
    

    
    Was die for-range-Schleife bringt
    
    
    Sie ist kürzer als die Schleife mit for-Klausel, und in ihr kann man sich bei Anfang, Bedingung und Schrittweite nicht verschreiben. Ein Leser muss keine for-Klausel prüfen.
    

    
    Seit Go 1.22: range über eine ganze Zahl
    

    for i := range 10 {
    fmt.Println(i)    // 0 bis 9
}
    
    
    Diese Form braucht kein Array. Sie zählt von 0 bis zu der Zahl hinter range, die Zahl selbst ausgenommen.
    
  
    
  
    
    
    
  
    
  
    

  
    
  
    
    
    Schritt 4: Zwei Dimensionen
    
    
    Erst vorhersagen, dann ausprobieren
      
      
        
    1. a hat den Typ [3][2]int. Was liefert len(a), was len(a[0])?
          
      Auflösung3 und 2. a ist ein Array aus drei Elementen. Jedes Element ist ein Array aus zwei ganzen Zahlen.
      2. 
      
    
    
    
    
    Ein Array in Go ist eine Folge von Werten und hat damit eine Dimension. Der Element-Typ darf aber selbst ein Array-Typ sein. So entsteht ein zweidimensionales Array. Es entspricht einer Matrix aus der linearen Algebra, ein einfaches Array entspricht einem Vektor.
    

    a := [3][2]int{
    {1, 2},
    {3, 4},
    {5, 6},
}
fmt.Println(a)    // [[1 2] [3 4] [5 6]]
    
    
    Den Typ [3][2]int liest man von links: ein Array der Länge 3, dessen Elemente den Typ [2]int haben. Das sind 3 Zeilen mit je 2 Spalten.
    
    
    Für jede Dimension kommt ein Paar eckiger Klammern dazu: a[i][j] ist das Element in Zeile i und Spalte j. a[i] allein ist die ganze Zeile i, ein Array vom Typ [2]int.
    

    
    Ausprobieren: Zeile und Spalte
    
    
    Wähle ein Element der Matrix.
    
    
    
    
    

    
    Durchlaufen mit zwei Schleifen
    
    
    Für ein zweidimensionales Array nimmt man zwei verschachtelte Schleifen. Die äußere läuft über die Zeilen, die innere über die Spalten einer Zeile. Das folgende Programm setzt alle negativen Elemente einer Matrix auf 0 und gibt sie aus.
    
    
      
    
      
      
      
      
      
    
      
    
      
    
      Ausgabe des Programms:
      
    
      
    
      
    
      range b liefert die Indizes der Zeilen, range b[i] die Indizes der Spalten in Zeile i. Das Programm braucht die Indizes, weil es mit b[i][j] = 0 in die Matrix schreibt. Das Verb %3v gibt jeden Wert drei Zeichen breit aus, so stehen die Spalten untereinander.
      

    
      Nur lesen: die Zeile als Wert
      

      for i, zeile := range a {
    fmt.Printf("Zeile %v: ", i)
    for _, element := range zeile {
        fmt.Printf("%v ", element)
    }
    fmt.Println()
}
// Zeile 0: 1 2
// Zeile 1: 3 4
// Zeile 2: 5 6
      
    
      Hier bekommt zeile in jedem Durchlauf eine ganze Zeile von a, also ein Array vom Typ [2]int. Die innere Schleife läuft über diese Zeile.
      
  
      
  
      
    
    
  
      
  
      

  
      
  
      
    
      Schritt 5: Slices
      
    
      Die Länge eines Arrays steht fest. Ein Element anhängen kann man nicht. In der Praxis braucht man das aber oft. Go hat dafür einen eigenen Typ, den Slice. Ein Slice ist, einfach gesagt, ein Array, dessen Länge wachsen kann, während das Programm läuft.
      

      zahlen := []int{1, 2, 3}       // ein Slice: eckige Klammern ohne Länge
zahlen = append(zahlen, 4)     // append hängt ein Element an
teil := zahlen[1:3]            // ein neuer Slice aus den Elementen 1 und 2

fmt.Println(zahlen)         // [1 2 3 4]
fmt.Println(teil)           // [2 3]
fmt.Println(len(zahlen))    // 4
fmt.Println(cap(zahlen))    // 6
      
    
      
      
      FrageArraySlice
      
      
        
      Wie schreibt man den Typ?Die Länge steht in den Klammern: [4]int.Die Klammern sind leer: []int.
      
        
      Wann steht die Länge fest?Sie steht beim Übersetzen fest und gehört zum Typ.Sie kann sich ändern, während das Programm läuft.
      
        
      Kann man ein Element anhängen?Nein. Go übersetzt append mit einem Array nicht.Ja, mit append.
      
            
    
      

    
      Was dahinter steckt
      
    
      Ein Slice benutzt intern ein Array fester Größe. len liefert die Länge des Slice, cap die Größe dieses internen Arrays, die Kapazität. Reicht der Platz nicht mehr, legt Go ein neues, größeres Array an und kopiert die Elemente dorthin. Im Beispiel hat Go 1.26 beim Anhängen des vierten Elements Platz für sechs geschaffen.
      

    
      Im Kurs bleibt es bei Arrays
      
    
      Im Kurstext werden Slices nur an dieser einen Stelle gezeigt. Alle Beispiele des Kurses verwenden Arrays, auch dort, wo man in der Praxis einen Slice nähme. Zwei Gründe stehen dort: Arrays gibt es in fast jeder Programmiersprache, und die Speicherverwaltung hinter einem Slice ist verwickelter.
