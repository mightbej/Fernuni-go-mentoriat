🔬 Exkurs: Binäre Codierung und Zweierkomplement

Wie werden Ganzzahlen auf Bit-Ebene dargestellt und wie funktionieren Addition und Subtraktion im Rechenwerk?

Vorzeichenlose Ganzzahlen (uint8)

Mit 8 Bit können Zahlen von 0 bis 255 (2⁸ - 1) dargestellt werden. Alle Bits haben positive Wertigkeiten:

Bit-Position 7 6 5 4 3 2 1 0
Wertigkeit 128 64 32 16 8 4 2 1
Berechnung:
Beispiele aus dem Skript:
00000000= 0
00000001= 1
01111111= 127
10000000= 128
10000001= 129
11111111= 255

Vorzeichenbehaftete Ganzzahlen (int8) – Zweierkomplement

Mit 8 Bit können Zahlen von -128 bis 127 dargestellt werden. Das höchstwertige Bit hat negative Wertigkeit:

Bit-Position 7 6 5 4 3 2 1 0
Wertigkeit -128 64 32 16 8 4 2 1
💡 Vorzeichen ablesen: Wenn Bit 7 = 0 → positive Zahl (0 bis 127)
Wenn Bit 7 = 1 → negative Zahl (-128 bis -1)
Berechnung (Zweierkomplement):
Beispiele aus dem Skript:
00000000= -128 + 0 = 0
00000001= -128 + 1 = 1
01111111= -128 + 127 = 127
10000000= -128 + 0 = -128
10000001= -128 + 1 = -127
11111111= -128 + 127 = -1

Zweierkomplement berechnen

Um eine negative Zahl zu codieren, wird das Zweierkomplement gebildet:

Methode: Negative Zahl im Zweierkomplement
  1. Betrag der Zahl als Binärzahl darstellen
  2. Alle Bits invertieren (0 → 1, 1 → 0) = Einerkomplement
  3. 1 addieren = Zweierkomplement

Rechenoperationen auf Bit-Ebene

Der große Vorteil des Zweierkomplements: Subtraktion kann als Addition implementiert werden!

💡 Prinzip: a - b = a + (-b)
Die Subtraktion wird auf die Addition zurückgeführt, indem der negative Wert (im Zweierkomplement) addiert wird.
