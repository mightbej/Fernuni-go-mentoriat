Quiz 6 – bool-Typ und Vergleichsoperatoren

true, false und die Operatoren ==, !=, <, >, <=, >= für alle primitiven Typen.

Merkhilfe

  • bool hat genau zwei Werte: true und false.
  • Vergleichsoperatoren liefern immer ein Ergebnis vom Typ bool.
  • == prüft Gleichheit, != prüft Ungleichheit.
  • <, >, <=, >= sind für alle geordneten Typen (int, float64, string) verfügbar.
  • Strings werden lexikografisch verglichen ("Anna" < "Berta" ist true).
var a int = 10
var b int = 20
fmt.Println(a == b)   // false
fmt.Println(a != b)   // true
fmt.Println(a <  b)   // true
fmt.Println(a >= 10)  // true

Quizrunde (richtig / falsch)

Erst gemeinsam abstimmen, dann auswerten.

AussageDeine WahlAuflösung
Der Ausdruck 5 > 3 ergibt in Go den Wert true.
Richtig: 5 ist größer als 3.
In Go kann man if 1 { ... } schreiben, weil 1 als „wahr" gilt.
Falsch: In Go müssen Bedingungen exakt vom Typ bool sein. 1 ist kein bool.
Der Nullwert (default) einer bool-Variablen in Go ist false.
Richtig: Der Nullwert von bool ist false.
Der Ausdruck "Anna" < "Berta" ist in Go gültig und ergibt true.
Richtig: Strings können in Go mit < verglichen werden (lexikografisch).
10 == 10.0 ist in Go immer gültig, weil beide den Wert 10 haben.
Falsch: Wenn einer der Operanden eine Variable ist, müssen die Typen übereinstimmen.
Eine bool-Variable kann nur mit true oder false verglichen werden, nicht mit 1 oder 0.
Richtig: Go kennt kein implizites Casting von int nach bool.
Das Ergebnis von fmt.Println(3 == 3) ist die Ausgabe true.
Richtig: fmt.Println gibt bool-Werte als "true" oder "false" aus.
>= ist in Go nur für numerische Typen (int, float64) verfügbar, nicht für string.
Falsch: <, >, <=, >= funktionieren auch für string (lexikografisch).
Der Ausdruck a != b ergibt true, wenn a und b verschiedene Werte haben.
Richtig: != ist der "ungleich"-Operator.
Man kann in Go einen bool-Wert direkt zu einem int addieren.
Falsch: bool und int sind verschiedene Typen – eine Addition würde einen Compilerfehler erzeugen.
