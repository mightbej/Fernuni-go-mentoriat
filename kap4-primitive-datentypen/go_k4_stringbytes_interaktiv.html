Strings: Bytes und Zeichen

Ein String in Go ist eine Folge von Bytes. Ein Zeichen kann ein Byte belegen oder bis zu vier. Deshalb hat „Tür“ drei Zeichen und die Länge 4.

Kurstext v3.0.6, Abschnitt 4.6.2, Seiten 102–107.

Worum es geht

Go speichert jedes Zeichen eines Strings im Format UTF-8:

  • ASCII-Zeichen: Die 128 ASCII-Zeichen brauchen je ein Byte.
  • Alle anderen Unicode-Zeichen: Sie brauchen zwei bis vier Bytes, zum Beispiel ü und ß je zwei.

Was in Go Bytes zählt

  • len(s): Die Funktion liefert die Zahl der Bytes.
  • s[i]: Der Index-Ausdruck liefert ein einzelnes Byte.
  • s[low:high]: Der Slice-Ausdruck schneidet nach Bytes.

Wer dabei mit Zeichen rechnet, bekommt bei Umlauten falsche Ergebnisse.

Was Zeichen zählt

Wer mit Zeichen arbeiten will, wandelt den String in ein []rune um. Darin ist jedes Element genau ein Zeichen, und der Index zählt Zeichen. Ein Schnitt kann dann kein Zeichen mehr zerteilen.

Die zwei Schritte

  • Schritt 1 legt einen String als Reihe von Bytes hin. Über jedem Byte steht das Zeichen, zu dem es gehört, darunter sein Index.
  • Schritt 2 zeigt, wie man mit []rune Zeichen zählt und schneidet.

Ein String als Byte-Reihe

Erst vorhersagen, dann ausprobieren
  1. Welchen Wert liefert len("Tür")?
    Auflösung4. Das ü belegt zwei Bytes, T und r je eines.
  2. Welchen Substring liefert "Tür"[1:3]?
    Auflösung„ü“. Die Bytes mit Index 1 und 2 bilden zusammen das ü. Der obere Index 3 gehört nicht mehr dazu.
  3. Mit welchem Slice-Ausdruck bekommt man aus „Tür“ das r?
    Auflösung"Tür"[3:4]. Das r ist das vierte Byte, nicht das dritte.
  4. Was liefert "Tür"[1:2]?
    AuflösungEin einzelnes Byte mit dem Wert 195, die erste Hälfte des ü. Das ist kein gültiges Zeichen. Go meldet keinen Fehler, die Konsole zeigt dafür meist das Ersatzzeichen �.
  5. Der String ist „Abo“. Welchen Wert und welchen Typ hat s[0]?
    AuflösungDen Wert 65 und den Typ byte. s[0] ist kein String. Deshalb übersetzt Go "H" + s[0] nicht.

Mit Zeichen arbeiten

Erst vorhersagen, dann nachlesen
  1. Wie viele Bytes und wie viele Zeichen hat „Grüße“?
    Auflösung7 Bytes und 5 Zeichen. len(s) liefert 7, len([]rune(s)) und utf8.RuneCountInString(s) liefern 5.
  2. Der String ist „Maßstab“. Was liefert s[3:7], und wie bekommt man „stab“, ohne Bytes zu zählen?
    Auflösungs[3:7] beginnt mit der zweiten Hälfte des ß und liefert "\x9fsta". Mit r := []rune(s) liefert string(r[3:7]) den String „stab“. Das s ist das vierte Zeichen, also Index 3.

Die Typen string, byte und rune

TypWas ein Wert dieses Typs istWo er auf dieser Seite vorkommt
stringEr ist eine Folge von Bytes beliebiger Länge.Der ganze String s und jeder Substring s[low:high] haben diesen Typ.
byteEr ist ein Byte. byte ist ein anderer Name für uint8.Der Wert von s[i] hat diesen Typ.
runeEr ist die Unicode-Nummer eines Zeichens. rune ist ein anderer Name für int32.Die Nummer unter jedem Zeichen in Schritt 1 ist eine Rune, zum Beispiel U+00FC für ü.
[]runeEr ist eine Folge von Runen, also eine Folge ganzer Zeichen.Nach r := []rune(s) zählen len(r), r[i] und r[a:b] Zeichen.

Umwandeln und zurück

  • []rune(s) zerlegt den String in seine Zeichen.
  • string(…) macht aus Runen wieder einen String.
s := "Maßstab"
r := []rune(s)

fmt.Println(len(s))         // 8, Bytes
fmt.Println(len(r))         // 7, Zeichen
fmt.Println(string(r[2]))   // ß
fmt.Println(string(r[3:7])) // stab
fmt.Println(s[3:7])         // schneidet durch das ß

Zeichenweise durch einen String

Auch die Schleife mit range läuft zeichenweise über einen String. Der Index, den sie liefert, ist aber die Position des ersten Bytes:

for i, z := range "Tür" {
    fmt.Println(i, string(z))
}
// 0 T
// 1 ü
// 3 r

Die Schleife mit range wird im Kurstext in Abschnitt 6.2 bei den Arrays behandelt.

Ein []rune belegt für jedes Zeichen 4 Bytes, auch für ein a, und die Umwandlung kopiert den ganzen Text. Deshalb ist der String in Go die sparsame Form und []rune die bequeme.
