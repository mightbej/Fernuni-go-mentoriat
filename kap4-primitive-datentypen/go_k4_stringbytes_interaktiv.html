Strings: Bytes und Zeichen

Ein String in Go ist eine Folge von Bytes. Ein Zeichen kann ein Byte belegen oder bis zu vier. Deshalb hat „Tür" drei Zeichen und die Länge 4. Kurstext Kapitel 4.6, String Datentyp.

Was die Seite zeigt

Go speichert jedes Zeichen eines Strings im Format UTF-8. Die 128 ASCII-Zeichen brauchen je ein Byte. Alle anderen Unicode-Zeichen brauchen zwei bis vier Bytes, zum Beispiel ü und ß je zwei.

Drei Dinge in Go zählen Bytes und nicht Zeichen: Die Funktion len(s) liefert die Zahl der Bytes. Der Index-Ausdruck s[i] liefert ein einzelnes Byte. Der Slice-Ausdruck s[low:high] schneidet nach Bytes. Wer mit Zeichen rechnet, bekommt bei Umlauten falsche Ergebnisse.

Wer mit Zeichen arbeiten will, wandelt den String in ein []rune um. Darin ist jedes Element genau ein Zeichen, und der Index zählt Zeichen. Ein Schnitt kann dann kein Zeichen mehr zerteilen.

Die Seite legt den String als Reihe von Bytes hin. Über jedem Byte steht das Zeichen, zu dem es gehört, darunter sein Index im String. Ganz oben steht der Index desselben Zeichens im []rune. So sieht man beide Zählweisen übereinander.

Mit Zeichen statt mit Bytes arbeiten

Die Umwandlung []rune(s) zerlegt den String in seine Zeichen. Die Umwandlung string(…) macht aus Runen wieder einen String.

s := "Maßstab"
r := []rune(s)

fmt.Println(len(s))         // 8, Bytes
fmt.Println(len(r))         // 7, Zeichen
fmt.Println(string(r[2]))   // ß
fmt.Println(string(r[3:7])) // stab
fmt.Println(s[3:7])         // schneidet durch das ß

Auch die Schleife mit range läuft zeichenweise über einen String. Der Index, den sie liefert, ist aber die Position des ersten Bytes:

for i, z := range "Tür" {
    fmt.Println(i, string(z))
}
// 0 T
// 1 ü
// 3 r
Ein []rune belegt für jedes Zeichen 4 Bytes, auch für ein a, und die Umwandlung kopiert den ganzen Text. Deshalb ist der String in Go die sparsame Form und []rune die bequeme.

Erst vorhersagen, dann ausprobieren

  1. Welchen Wert liefert len("Tür")?
    Auflösung4. Das ü belegt zwei Bytes, T und r je eines.
  2. Welchen Substring liefert "Tür"[1:3]?
    Auflösung„ü". Die Bytes mit Index 1 und 2 bilden zusammen das ü. Der obere Index 3 gehört nicht mehr dazu.
  3. Mit welchem Slice-Ausdruck bekommt man aus „Tür" das r?
    Auflösung"Tür"[3:4]. Das r ist das vierte Byte, nicht das dritte.
  4. Was liefert "Tür"[1:2]?
    AuflösungEin einzelnes Byte mit dem Wert 195, die erste Hälfte des ü. Das ist kein gültiges Zeichen. Go meldet keinen Fehler, die Konsole zeigt dafür meist das Ersatzzeichen �.
  5. Wie viele Bytes und wie viele Zeichen hat „Grüße"?
    Auflösung7 Bytes und 5 Zeichen. len(s) liefert 7, len([]rune(s)) und utf8.RuneCountInString(s) liefern 5.
  6. Der String ist „Maßstab". Was liefert s[3:7], und wie bekommt man „stab", ohne Bytes zu zählen?
    Auflösungs[3:7] beginnt mit der zweiten Hälfte des ß und liefert "\x9fsta". Mit r := []rune(s) liefert string(r[3:7]) den String „stab". Das s ist das vierte Zeichen, also Index 3.
  7. Der String ist „Abo". Welchen Wert und welchen Typ hat s[0]?
    AuflösungDen Wert 65 und den Typ byte. s[0] ist kein String. Deshalb übersetzt Go "H" + s[0] nicht.
