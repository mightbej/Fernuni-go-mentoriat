Logische Operatoren und Vergleiche in Go

Ein Vergleich wie x < 10 liefert einen Wahrheitswert. Die Seite zeigt die sechs Vergleichsoperatoren, den Vergleich von Strings und wie man mehrere Vergleiche mit &&, || und ! zu einer Bedingung verknüpft.

Kurstext v3.0.6, Abschnitt 4.5.2, Seiten 96–98, und Abschnitt 4.1, Seiten 45–52.

Worum es geht

Ein Programm muss entscheiden können: Ist die Eingabe gültig? Ist das Ende der Liste erreicht? Jede solche Entscheidung beginnt mit einem Vergleich.

var alter int = 17
fmt.Println(alter >= 18)                 // false
fmt.Println(alter >= 6 && alter < 18)    // true

Ein Vergleich ist ein Ausdruck. Sein Wert hat immer den Typ bool, er ist also true oder false. Ein Ausdruck mit diesem Typ heißt boolescher Ausdruck.

Mit den drei logischen Operatoren entsteht aus mehreren Vergleichen ein einziger boolescher Ausdruck:

  • &&, die Konjunktion: a && b ist true, wenn beide Operanden true sind.
  • ||, die Disjunktion: a || b ist true, wenn mindestens ein Operand true ist.
  • !, die Negation: !a kehrt den Wert um.

Schritt 1: Sechs Operatoren

OperatorWann der Ausdruck true istFür welche Typen es den Operator gibt
==Beide Operanden haben den gleichen Wert.Es gibt ihn für alle primitiven Typen: Ganzzahlen, Gleitkommazahlen, bool und string.
!=Die Operanden haben verschiedene Werte.
<Der linke Wert ist kleiner als der rechte.Es gibt ihn nur für geordnete Typen: Ganzzahlen, Gleitkommazahlen und string. Für bool gibt es ihn nicht.
<=Der linke Wert ist kleiner als der rechte oder gleich.
>Der linke Wert ist größer als der rechte.
>=Der linke Wert ist größer als der rechte oder gleich.

<= und >= stehen für die Zeichen ≤ und ≥ der Mathematik. Das Gleichheitszeichen steht immer hinten.

Drei Regeln

  • Der Wert zählt, nicht die Schreibweise: 0xaf == 175 ist true, ebenso 2.5 == 25e-1. Beide Seiten werden erst ausgewertet, dann verglichen.
  • Erst rechnen, dann vergleichen: Die Vergleichsoperatoren binden schwächer als +, -, * und /. In 10*5 == 70-20 rechnet Go zuerst beide Seiten aus und vergleicht dann 50 mit 50.
  • Beide Seiten brauchen den gleichen Typ: Eine Variable vom Typ int lässt sich nicht mit einem String vergleichen und auch nicht mit einer Variable vom Typ float64.

== ist nicht =

a == 5 fragt, ob a den Wert 5 hat. a = 5 gibt a den Wert 5. Wer die zwei verwechselt, bekommt in Go eine Meldung des Compilers, denn eine Zuweisung hat in Go keinen Wert und kann nicht als Bedingung stehen.

Ausprobieren: wahr, falsch oder gar nicht

Die Variablen sind für alle Ausdrücke gleich belegt:

var a int = 2 + 3
var b int = 5
var s = "Hallo Welt"
var t = "Hallo " + "Welt"

    


    
bool ist keine Zahl

    
Go wandelt einen Wahrheitswert nie von selbst in eine Zahl um und eine Zahl nie in einen Wahrheitswert. In C++ gilt 0 als false und jede andere Zahl als true. In Go muss in einer Bedingung ein boolescher Ausdruck stehen: Statt if x schreibt man if x != 0.

  

  

    
    
  

  


  

  

    
Schritt 2: Strings vergleichen

    
Erst vorhersagen, dann ausprobieren
      
    
        
  1. Ist "affe" > "Ziege" wahr oder falsch?
          
    AuflösungWahr. Schon das erste Zeichen entscheidet: Das kleine a hat die Nummer 97, das große Z die Nummer 90. Jeder Kleinbuchstabe ist größer als jeder Großbuchstabe.
    2. 
        
  2. Ist "56" > "199" wahr oder falsch?
          
    AuflösungWahr. Verglichen werden Zeichen und keine Zahlen. Das erste Zeichen entscheidet: Die Ziffer 5 ist größer als die Ziffer 1.
    3. 
      

    

    
Die Operatoren <, <=, > und >= gibt es auch für Strings. Go vergleicht zwei Strings nach ihrer lexikographischen Ordnung. Das ist die Ordnung eines Wörterbuchs, nur mit einer anderen Reihenfolge der Zeichen.


    
Die Regel

    
    
      
  1. Go vergleicht die zwei Strings Zeichen für Zeichen von links.
    2. 
      
  2. Das erste Paar verschiedener Zeichen entscheidet. Der String mit dem größeren Zeichen an dieser Stelle ist der größere.
    3. 
      
  3. Ist ein String zu Ende, bevor ein Unterschied auftritt, dann ist der längere String der größere.
    4. 
    


    
Welches Zeichen größer ist

    
Jedes Zeichen hat eine Nummer. Das Zeichen mit der größeren Nummer ist das größere.

    

    

      
ZeichenNummernBeispiel

      
        
Das LeerzeichenEs hat die Nummer 32.Das Leerzeichen ist kleiner als jede Ziffer und jeder Buchstabe.

        
Die Ziffern 0 bis 9Sie haben die Nummern 48 bis 57.Die Ziffer 8 hat die Nummer 56.

        
Die Großbuchstaben A bis ZSie haben die Nummern 65 bis 90.Das Z hat die Nummer 90.

        
Die Kleinbuchstaben a bis zSie haben die Nummern 97 bis 122.Das a hat die Nummer 97.

        
Die Umlaute und das ßSie haben Nummern über 122.Das ä hat die Nummer 228, das Ä die Nummer 196.

      
    

    

    
Daraus folgt: Ziffern sind kleiner als Großbuchstaben, und Großbuchstaben sind kleiner als Kleinbuchstaben.

Wo das vom Wörterbuch abweicht

    
    
      
  • Groß vor klein: "Zebra" < "apfel" ist wahr. Im Wörterbuch steht Apfel vor Zebra, egal wie man es schreibt.
    • 
      
  • Umlaute hinten: "Ärger" > "Zebra" ist wahr, weil das Ä eine größere Nummer hat als das Z.
    • 
      
  • Ziffern als Zeichen: "10" < "9" ist wahr, obwohl die Zahl 10 größer ist als die Zahl 9.

Schritt 3: Vergleiche verknüpfen

    
Erst vorhersagen, dann ausprobieren
      
    
        
  1. In der Mathematik schreibt man 0 ≤ x ≤ 9. Übersetzt Go den Ausdruck 0 <= x <= 9?
          
    AuflösungNein. Go rechnet von links: 0 <= x ist ein Wahrheitswert, und einen Wahrheitswert kann man nicht mit 9 vergleichen. Richtig ist x >= 0 && x <= 9.
    2. 
      

    

    
Ein einzelner Vergleich prüft eine Grenze. Für einen Bereich braucht man zwei Vergleiche und einen logischen Operator.

    
    
      
  • Innerhalb, mit &&: x >= 0 && x <= 9 ist wahr, wenn x beide Grenzen einhält.
    • 
      
  • Außerhalb, mit ||: x < 0 || x > 9 ist wahr, wenn x eine der zwei Grenzen verletzt.
    • 
      
  • Das Gegenteil, mit !: !(x >= 0 && x <= 9) ist wahr, wenn x nicht im Bereich liegt. Der Ausdruck hat immer den gleichen Wert wie der Ausdruck mit ||.
    • 
    


    
Was zuerst gerechnet wird

    
Die Bindungsstärke legt fest, welcher Operator seine Operanden zuerst bekommt. Von stark nach schwach:

    
    
      
  1. Die einstelligen Operatoren, zum Beispiel ! und das Minus vor einer Zahl.
    2. 
      
  2. * und /, dann + und -.
    3. 
      
  3. Die sechs Vergleichsoperatoren.
    4. 
      
  4. &&.
    5. 
      
  5. ||.
    6. 
    

    
Deshalb braucht x >= 0 && x <= 9 keine Klammern: Erst werden die zwei Vergleiche ausgewertet, dann verknüpft && ihre Ergebnisse. Das ! bindet dagegen am stärksten. Ohne die Klammern in !(x >= 0 && x <= 9) würde es nur auf x wirken, und das übersetzt Go nicht.

Zwei Vergleiche hintereinander

    
Vergleichsoperatoren haben alle die gleiche Bindungsstärke. Stehen zwei hintereinander, rechnet Go von links. Das geht nur gut, wenn Klammern sagen, was gemeint ist:


5 != 7 != (2 != 2)    // true:  true != false
4 > 2 == (5 < 9)      // true:  true == true

    
Ohne die Klammern würde Go in der ersten Zeile 5 != 7 auswerten und den Wahrheitswert dann mit der Zahl 2 vergleichen. Das übersetzt Go nicht.
