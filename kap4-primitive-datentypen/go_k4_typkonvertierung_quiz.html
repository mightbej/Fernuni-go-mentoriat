Quiz 9 – Typkonvertierung: int ↔ float64

Wann konvertiert man, wie macht man es, und was passiert dabei?

Merkhilfe

  • Explizite Konvertierung: float64(a) oder int(f).
  • Bei int(f) werden Nachkommastellen abgeschnitten (nicht gerundet!).
  • Denkfehler: float64(a/b) teilt erst als int, dann konvertiert – zu spät!
  • Richtig für echten Quotienten: float64(a) / float64(b).
  • Eine Typkonvertierung ändert nie den gespeicherten Wert der Variable – nur den Wert des Ausdrucks.
var a int = 25
var f float64 = 1.7

// Richtig: int → float64
fmt.Println(0.75 * float64(a))       // 18.75

// int(f) schneidet ab
fmt.Println(int(f))                  // 1  (nicht 2!)

// Denkfehler!
fmt.Println(float64(a / 10))         // 2.0  (erst 25/10=2, dann float64)
// Richtig:
fmt.Println(float64(a) / float64(10)) // 2.5

Quizrunde (richtig / falsch)

Erst gemeinsam abstimmen, dann auswerten.

AussageDeine WahlAuflösung
In Go kann man eine int-Variable direkt mit einer float64-Variable multiplizieren.
Falsch: Typen müssen übereinstimmen. Eine explizite Konvertierung ist nötig.
int(1.9) ergibt in Go den Wert 1, nicht 2.
Richtig: Nachkommastellen werden abgeschnitten, nicht gerundet.
float64(25 / 10) ergibt 2.5.
Falsch: Zuerst wird 25/10=2 (int-Division) berechnet, dann float64(2)=2.0. Ergebnis: 2.0.
float64(25) / float64(10) ergibt 2.5.
Richtig: Beide Operanden werden zuerst zu float64, dann wird float-Division durchgeführt.
Eine Typkonvertierung wie int(f) ändert den Wert der Variable f selbst nicht.
Richtig: Die Konvertierung wirkt nur auf den Wert des Ausdrucks, nicht auf f.
int(-2.9) ergibt in Go -3 (abrunden).
Falsch: Go schneidet Richtung null ab. int(-2.9) = -2.
Die Schreibweise float64(a) ähnelt syntaktisch einem Funktionsaufruf, ist aber eine Typkonvertierung.
Richtig: Syntaktisch ähnlich, aber semantisch eine Konvertierung, keine Anweisung.
Die Zuweisung var i int = 5.0 ist gültig, weil 5.0 ein ganzzahliger konstanter Float-Ausdruck ist.
Richtig: Ganzzahlige konstante Float-Ausdrücke dürfen implizit an int angepasst werden.
Die Zuweisung var i int = 5.5 ist in Go gültig.
Falsch: 5.5 ist nicht ganzzahlig – das ergibt einen Compilerfehler.
Um eine float64-Variable einer int-Variablen zuzuweisen, braucht man immer eine explizite Konvertierung.
Richtig: Bei Variablen findet keine implizite Typanpassung statt.
Noch nicht ausgewertet.
