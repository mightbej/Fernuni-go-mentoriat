🔢 Zweierkomplement – Binäre Codierung in Go

Wie werden vorzeichenbehaftete Ganzzahlen auf Bit-Ebene dargestellt?
Verstehe die Codierung von int8 und die Arithmetik im Rechenwerk.

📖 Grundlagen: Bit-Positionen und Nummerierung

💡 Konvention: Das niederwertigste Bit (LSB) steht rechts, das höchstwertige Bit (MSB) steht links. Die Nummerierung beginnt bei 0 (rechts) und läuft bis n-1 (links).

Bei einer 8-Bit-Folge (1 Byte):

Bit-Position 76543210
Beschreibung MSB
(links)		Mittlere BitsLSB
(rechts)

MSB = Most Significant Bit (höchstwertiges Bit)
LSB = Least Significant Bit (niederwertiges Bit)

➕ Vorzeichenlose Ganzzahlen (unsigned) – uint8

Bei vorzeichenlosen Datentypen haben alle Bits positive Wertigkeiten. Mit n Bits können Zahlen von 0 bis 2n - 1 dargestellt werden.

➖ Vorzeichenbehaftete Ganzzahlen (signed) – int8 mit Zweierkomplement

Bei vorzeichenbehafteten Datentypen wird das Zweierkomplement verwendet. Der entscheidende Unterschied: Das höchstwertige Bit (Bit 7) hat eine negative Wertigkeit!

Anzahl Bits
8 Bit (int8)
Wertebereich
-128 bis +127
✨ Vorteil des Zweierkomplements:
  • Subtraktion kann auf Addition zurückgeführt werden
  • Keine separate Hardware für Subtraktion nötig
  • Negation ist technisch sehr einfach realisierbar

Wertigkeiten bei int8 (Zweierkomplement):

Bit-Position 76543210
Wertigkeit -1286432168421
Als Potenz -2⁷2⁶2⁵2⁴2³2²2¹2⁰
🔑 Kernprinzip: Die 7 rechten Bits (Position 0-6) haben die üblichen positiven Wertigkeiten (1, 2, 4, ..., 64). Das linke Bit (Position 7) hat eine negative Wertigkeit von -128.

Vorzeichen ablesen:

✓ Bit 7 = 0 → Positive Zahl
Wert = 0 + (Bits 0-6)
Bereich: 0 bis +127
✓ Bit 7 = 1 → Negative Zahl
Wert = -128 + (Bits 0-6)
Bereich: -128 bis -1

🔄 Zweierkomplement berechnen – Negative Zahlen bilden

Um aus einer positiven Zahl die entsprechende negative Zahl im Zweierkomplement zu erhalten:

1 Betrag als Binärzahl darstellen – z.B. +42 = 00101010
2 Alle Bits invertieren (0→1, 1→0) → 11010101 (Einerkomplement)
3 1 addieren → 11010110 (Zweierkomplement)
🔄 Umkehrung: Das Zweierkomplement des Zweierkomplements ergibt die ursprüngliche Zahl zurück!

⚠️ Wichtiger Hinweis: Zweierkomplement in Go-Quellcode

🚨 Vorsicht – Verwechslungsgefahr!

Die hier erläuterte binäre Codierung im Zweierkomplement betrifft die Repräsentation auf System-Ebene (wie der Compiler die Werte speichert). Dies darf nicht mit der Notation von Integer-Literalen als Binärzahl im Go-Quellcode verwechselt werden!

Im Go-Quellcode:

  • Mit Integer-Literalen (0b...) können nur positive Zahlenwerte als Binärzahl notiert werden
  • Es existiert in Go keine Darstellungsform für negative Integer-Literale im Zweierkomplement
  • Eine negative Zahl wird notiert, indem man den Betrag als Binärzahl schreibt und ein Minuszeichen davor setzt

Beispiele:

Go-Quellcode Bedeutung Interne Repräsentation (int8) Gültig?
var a int8 = 0b00001001 +9 00001001 ✓ Gültig
var b int8 = -0b00001001 -9 (Betrag als Binär + Minus) 11110111 (Zweierkomplement) ✓ Gültig
var c int8 = 0b11110111 247 (als uint interpretiert) Overflow bei int8! ✗ Fehler
💡 Merke: Im Quellcode schreibst du -0b1001 für -9, aber intern speichert der Compiler dies als 11110111 im Zweierkomplement. 
// Beispiel aus dem Skript
var positiv int8 = 0b00001001    // +9
var negativ int8 = -0b00001001   // -9 (nicht 0b11110111!)

fmt.Println(positiv)  // Ausgabe: 9
fmt.Println(negativ)  // Ausgabe: -9

🎯 Zusammenfassung

uint8 (vorzeichenlos)

  • Alle Bits positiv
  • Bereich: 0 bis 255
  • 8 Bits = 2⁸ = 256 Werte
  • Keine negativen Zahlen

int8 (vorzeichenbehaftet)

  • Bit 7 hat negative Wertigkeit (-128)
  • Bereich: -128 bis +127
  • Zweierkomplement-Codierung
  • Subtraktion = Addition des Negativen
✅ Vorteile des Zweierkomplements:
  1. Nur eine Addition im Rechenwerk nötig (keine separate Subtraktion)
  2. Negation ist einfach: Bits invertieren + 1 addieren
  3. Eindeutige Darstellung der Null (nur 00000000)
  4. Vorzeichen ergibt sich automatisch aus der Bit-Wertigkeit
