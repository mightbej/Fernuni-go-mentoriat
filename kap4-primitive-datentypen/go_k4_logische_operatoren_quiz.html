Quiz 7 – Logische Operatoren: &&, ||, !

Wie werden bool-Werte mit UND, ODER und NICHT verknüpft?

Merkhilfe

  • && (UND): Ergebnis ist true, wenn beide Operanden true sind.
  • || (ODER): Ergebnis ist true, wenn mindestens einer true ist.
  • ! (NICHT): Kehrt den Wert um – !true → false, !false → true.
  • Kurzschlussauswertung: Bei && wird der zweite Operand nicht ausgewertet, wenn der erste schon false ist.
true  && true   → true
true  && false  → false
false && true   → false
true  || false  → true
false || false  → false
!true           → false

Quizrunde (richtig / falsch)

Erst gemeinsam abstimmen, dann auswerten.

In Go schreibt man das logische UND als & (einzelnes Zeichen).
Falsch: Das logische UND ist && (doppelt). & ist der bitweise AND-Operator.
Der Ausdruck a >= 0 && a <= 100 prüft, ob a im Bereich 0 bis 100 liegt.
Richtig: Beide Bedingungen müssen gleichzeitig wahr sein.

Richtig: Logische Operatoren auf bool-Werten liefern immer bool.
