Quiz 8 – string-Typ: Grundlagen und Unveränderbarkeit

Zeichenketten in Go – Konkatenation, Vergleich und warum Strings immutable sind.

Merkhilfe

  • Strings sind in Go unveränderbar (immutable) – einzelne Zeichen können nicht geändert werden.
  • Mit + entsteht immer ein neuer String – der ursprüngliche bleibt unverändert.
  • Der Nullwert von string ist der leere String "".
  • String-Literale werden in doppelte Anführungszeichen gesetzt: "Hallo".
  • s[0] liefert ein byte (uint8), keinen Buchstaben – und kann nicht zugewiesen werden.
var a string = "Sommer"
var b string = a
a = a + "zeit"
fmt.Println(a)  // Sommerzeit
fmt.Println(b)  // Sommer (unverändert!)

Quizrunde (richtig / falsch)

Erst gemeinsam abstimmen, dann auswerten.

AussageDeine WahlAuflösung
Strings in Go sind unveränderbar – man kann ein einzelnes Zeichen nicht direkt ersetzen.
Richtig: Strings sind immutable. Man kann nur einen neuen String erstellen.
Nach a = a + "zeit" zeigt eine andere Variable b, die vorher b = a zugewiesen bekam, nun auch "Sommerzeit".
Falsch: b hat den alten Wert "Sommer" behalten – es wurde ein neuer String für a erzeugt.
Der Nullwert einer nicht initialisierten string-Variable in Go ist der leere String "".
Richtig: Go initialisiert string-Variablen mit "".
Die Zuweisung s[0] = 'U' ist in Go gültig, um das erste Zeichen eines Strings zu ersetzen.
Falsch: Strings sind immutable. s[0] kann nicht auf der linken Seite einer Zuweisung stehen.
"hoch" + "springen" ergibt den neuen String "hochspringen".
Richtig: + verkettet zwei Strings zu einem neuen.
In Go können Strings und Zahlen mit + direkt verknüpft werden.
Falsch: Go erlaubt keine implizite Umwandlung. "Wert: " + 42 ist ein Compilerfehler.
Der Ausdruck s[0] liefert bei einem String s einen byte-Wert (uint8).
Richtig: String-Indexzugriff liefert das Byte an dieser Position, kein Zeichen.
String-Literale in Go werden in doppelte Anführungszeichen gesetzt, z. B. "Hallo".
Richtig: Einfache Anführungszeichen sind für rune-Literale gedacht.
var s string = "Ohr" gefolgt von s[0] = 85 ist eine gültige Möglichkeit, das 'O' in 'U' zu ändern.
Falsch: Strings sind immutable. s[0]=85 ist nicht erlaubt – stattdessen s = "Uhr".
Beim Kopieren von Strings muss in Go kein zusätzlicher Speicher belegt werden, weil Strings unveränderbar sind.
Richtig: Da niemand einen String ändern kann, dürfen Kopien denselben Speicher teilen.
Noch nicht ausgewertet.
