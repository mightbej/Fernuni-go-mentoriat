🔤 Go String-Datentyp

Interaktive Beispiele zu String-Literalen, Unicode, UTF-8 und String-Operationen

1️⃣ String-Literale

Interpretierte String-Literale ("...")

String-Literale werden mit doppelten Anführungszeichen begrenzt und unterstützen Escape-Sequenzen.

var text string = "grüne Wiese" var pfad string = "C:\\Program Files\\Go" var zitat string = "Er sagte \"Hallo\"" var zeilen string = "Zeile 1\nZeile 2"
⚠️ Wichtig: Backslash \ und Anführungszeichen " müssen escaped werden: \\ und \"

Interaktiver String-Parser

Rohe String-Literale (`...`)

Mit Backquotes (`) begrenzt. Escape-Sequenzen werden NICHT interpretiert!

var pfad string = `C:\Program Files\Go` var zitat string = `Er sagte "Hallo"` var html string = `<html> <body> <p>Text</p> </body> </html>`
✅ Vorteile:
  • Keine Escape-Sequenzen nötig
  • Perfekt für Windows-Pfade
  • Kann Zeilenumbrüche enthalten
  • Ideal für mehrzeiligen Code (HTML, JSON, etc.)

Vergleich: Interpretiert vs. Roh

Escape-Sequenzen

Spezielle Zeichenfolgen mit besonderer Bedeutung in interpretierten String-Literalen:

\n – Zeilenumbruch (newline)
\t – Tabulator (horizontal tab)
\\ – Backslash
\" – Doppelte Anführungszeichen
\r – Wagenrücklauf (carriage return)
\a – Alarm/Bell
\b – Backspace
\f – Form Feed
\v – Vertikaler Tab
var text = "Der Backslash \\ ist ein \"besonderes\" Zeichen." fmt.Println(text) // Ausgabe: Der Backslash \ ist ein "besonderes" Zeichen.

Unicode-Zeichen

Go unterstützt den vollständigen Unicode-Zeichensatz mit über 120.000 Zeichen!

Unicode code points (Runes):
\uXXXX – 4-stellige Hexadezimalzahl (für BMP-Zeichen)
\UXXXXXXXX – 8-stellige Hexadezimalzahl (für alle Unicode-Zeichen)
var unendlich = "∞" // direkte Eingabe var unendlich2 = "\u221e" // Unicode \u221e var smiley = "😀" // direkte Eingabe var smiley2 = "\U0001f600" // Unicode \U0001f600

2️⃣ String-Datentyp und UTF-8

Strings als Byte-Sequenzen

Ein String in Go ist eine Sequenz von Bytes, die Unicode-Zeichen im UTF-8 Format codiert.

UTF-8 Encoding:
  • ASCII-Zeichen (A-Z, 0-9, ...): 1 Byte
  • Umlaute (ä, ö, ü, ß): 2 Bytes
  • Viele Symbole (∞, €, ...): 3 Bytes
  • Emojis (😀, 🎉, ...): 4 Bytes
var a = "anrufen" // len(a) == 7 (7 ASCII-Zeichen, je 1 Byte) var e = "Tür" // len(e) == 4 (T=1, ü=2, r=1 Byte) var f = "Maßstab" // len(f) == 8 (M=1, a=1, ß=2, s=1, t=1, a=1, b=1) var g = "\u221e" // len(g) == 3 (∞ benötigt 3 Bytes) var h = "\U0001f600" // len(h) == 4 (😀 benötigt 4 Bytes)
⚠️ Wichtig: len(s) liefert die Anzahl der Bytes, nicht die Anzahl der Zeichen! Die Anzahl der Zeichen liefert utf8.RuneCountInString(s).

3️⃣ Zugriff auf String-Teile

Index-Ausdruck s[idx]

Zugriff auf ein einzelnes Byte (nicht Zeichen!) an Position idx.

Wichtig:
  • Index beginnt bei 0
  • Letzter Index ist len(s)-1
  • Rückgabewert ist vom Typ byte (= uint8)
  • Bei Unicode-Zeichen > 1 Byte: Index zeigt auf einzelnes Byte!
var s = "Abo" fmt.Println(s[0], s[1], s[2]) // Ausgabe: 65 98 111 fmt.Printf("%#x %#x %#x", s[0], s[1], s[2]) // 0x41 0x62 0x6f // A=65=0x41, b=98=0x62, o=111=0x6f

Byte-Index Explorer

Slice-Ausdruck s[low:high]

Zugriff auf einen Substring (Teilstring) von Index low bis high-1.

Syntax:
  • s[low:high] – von low bis high-1
  • s[:high] – von Anfang bis high-1 (= s[0:high])
  • s[low:] – von low bis Ende (= s[low:len(s)])
  • Länge: high - low
"anrufen"[2:5] // "ruf" (Länge 5-2=3) "anrufen"[:2] // "an" (entspricht [0:2]) "anrufen"[2:] // "rufen" (entspricht [2:7]) "Hallo Welt"[0:5] // "Hallo" "Hallo Welt"[6:10] // "Welt" "Tür"[1:3] // "ü" (2 Bytes!)

4️⃣ String-Operationen

Konkatenation mit +

Strings können mit dem + Operator verkettet werden.

var a = "hoch" + "springen" // "hochspringen" var b = "Sommer" var c = b + "zeit" // "Sommerzeit"
⚠️ Wichtig: Keine implizite Typumwandlung!
"Zahl: " + 42 ist NICHT erlaubt!
Stattdessen: "Zahl: " + strconv.Itoa(42)

Unveränderbarkeit (Immutability)

Strings sind unveränderbar – einzelne Zeichen können nicht modifiziert werden!

var s = "Ohr" s[0] = 85 // ❌ FEHLER! Strings sind unveränderbar s = "Uhr" // ✅ OK: Neuen String zuweisen
var a = "Sommer" var b = a // b enthält "Sommer" a = a + "zeit" // a enthält jetzt "Sommerzeit" fmt.Println(b) // Ausgabe: "Sommer" (unverändert!)
