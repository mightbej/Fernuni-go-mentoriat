Quiz 10 – Alle Typen: Gemischte Wiederholung

Fragen quer durch Kapitel 4: int, float64, bool, string und Typkonvertierung.

Quizrunde (richtig / falsch)

Die farbigen Tags zeigen, welches Thema die Frage betrifft.

AussageDeine WahlAuflösung
intvar x int = 3.5 ist in Go gültig.
Falsch: 3.5 ist nicht ganzzahlig – Compilerfehler.
intDer Ausdruck 13 % 4 ergibt 1.
Richtig: 13 = 3×4 + 1, also Rest 1.
floatDer Standardtyp für Floating-Point-Literale in Go ist float64.
Richtig: float64 ist der Standard-Floating-Point-Typ.
boolIn Go kann man schreiben: if 0 { ... }, weil 0 für false steht.
Falsch: Go akzeptiert nur echte bool-Werte als Bedingung. 0 ist kein bool.
stringStrings in Go sind unveränderbar – mit + entsteht immer ein neuer String.
Richtig: Strings sind immutable. + erzeugt immer einen neuen String.
Konv.float64(7 / 2) ergibt 3.5.
Falsch: Erst wird 7/2=3 (int-Division) berechnet, dann float64(3)=3.0. Ergebnis: 3.0.
intbyte ist ein Alias für uint8 und kann Werte 0–255 speichern.
Richtig: byte = uint8, vorzeichenlos, 8 Bit.
boolDer Ausdruck (10 > 5) && !(3 == 3) ergibt false.
Richtig: (10>5)=true, !(3==3)=!true=false → true && false = false.
stringDer Ausdruck "Hallo" + 42 ist in Go gültig.
Falsch: In Go gibt es keine implizite Typanpassung. String und int können nicht mit + verknüpft werden.
Konv.Bei der Konvertierung int(-1.7) ist das Ergebnis -1 (Richtung null abschneiden).
Richtig: Go schneidet Richtung null – int(-1.7) = -1, nicht -2.
floatvar g float64 = 9 ist gültig – das Integer-Literal wird implizit angepasst.
Richtig: Konstante Integer-Ausdrücke dürfen implizit als float64 verwendet werden.
intint8 und int können in Go ohne Konvertierung gemischt werden.
Falsch: Auch int8 und int sind verschiedene Typen – Konvertierung nötig.
Noch nicht ausgewertet.
