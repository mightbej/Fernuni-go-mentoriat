🔄 Go Typkonvertierung

Implizite Typanpassung und explizite Typkonvertierung zwischen int und float64

1️⃣ Implizite Typanpassung

Strikte Typisierung in Go

Go hat ein sehr striktes Typsystem. Implizite Typanpassungen gibt es nur in Ausnahmefällen:

✅ Erlaubt: Implizite Anpassung von konstanten Ausdrücken
  • Konstante Integer-Ausdrücke (Literale, Berechnungen mit Literalen)
  • Ganzzahlige, konstante Floating-Point-Ausdrücke
// ✅ Implizite Anpassung konstanter Ausdrücke var g float64 = 9 // int-Literal → float64 g = g / 2 fmt.Println(g) // 4.5 fmt.Println(3 * 10 / g) // 6.666666666666667 fmt.Println(6 * 0.25) // 1.5 fmt.Println(15.0 / 2.0) // 7.5 fmt.Println(15.0 / 2) // 7.5 (2 → 2.0) fmt.Println(15 / 2.0) // 7.5 (15 → 15.0) fmt.Println(15 / 2) // 7 (ganzzahlige Division!)
// ✅ Ganzzahlige float-Ausdrücke var i int = 5.0 // zulässig, da ganzzahlig i = 2.5 * 2.4 // zulässig: 2.5 * 2.4 = 6.0 fmt.Println(i) // 6
❌ NICHT erlaubt: Implizite Anpassung von Variablen
Variablen werden niemals implizit konvertiert!
var a int = 25 var f float64 = 1.7 // ❌ FEHLER: Typ einer Variablen wird nie implizit angepasst // fmt.Println(0.75 * a) // fmt.Println(f * a)

2️⃣ Explizite Typkonvertierung

Syntax: T(a)

Eine Typkonvertierung wird durchgeführt, indem der Ausdruck a in runde Klammern gesetzt und ihm der Typname T vorangestellt wird.

Syntax: T(ausdruck)

Beispiele:
• float64(25) – int → float64
• int(3.7) – float64 → int (Nachkommastellen werden abgeschnitten!)
• float64(a) – int-Variable → float64
• int(f) – float64-Variable → int
⚠️ Wichtig:
• Eine Typkonvertierung ist keine Anweisung, sondern ein Ausdruck
• Die Konvertierung betrifft nur den Wert des Ausdrucks, nicht die Variable selbst
• Bei float→int werden Nachkommastellen abgeschnitten (nicht gerundet!)
var a int = 25 var f float64 = 1.7 // ✅ Explizite Konvertierung von int nach float64 fmt.Println(0.75 * float64(a)) // 18.75 == 0.75 * 25.0 // ✅ Beide Varianten möglich: fmt.Println(f * float64(a)) // 42.5 == 1.7 * 25.0 fmt.Println(int(f) * a) // 25 == 1 * 25 // ✅ Zuweisung mit Konvertierung f = float64(a) // f = 25.0

3️⃣ Float → Int: Nachkommastellen abschneiden

Abschneiden, nicht Runden!

Bei der Konvertierung von float64 nach int werden die Nachkommastellen einfach abgeschnitten (nicht gerundet).

⚠️ Achtung: Abschneiden, nicht Runden!

int(3.9) = 3 (nicht 4!)
int(7.1) = 7
int(-2.8) = -2 (nicht -3!)
Positive Zahlen:
int(1.7) → 1
int(3.14159) → 3
int(9.99) → 9
Negative Zahlen:
int(-1.7) → -1
int(-3.14) → -3
int(-9.99) → -9
Grenzfälle:
int(0.9) → 0
int(-0.9) → 0
int(5.0) → 5

4️⃣ Division: Ganzzahlig vs. Rational

Ganzzahlige Division (int / int)

Division zweier int-Werte liefert den Ganzzahlquotienten.

var a int = 25 var b int = 10 // Division zweier Integers → Ganzzahlquotient fmt.Println(a / b) // 2 (nicht 2.5!)
Ausdruck Ergebnis Erklärung
25 / 10 2 Ganzzahlquotient
15 / 2 7 7.5 abgeschnitten
10 / 3 3 3.333... abgeschnitten
7 / 10 0 0.7 abgeschnitten

Rationaler Quotient (float64 / float64)

Für den "echten" Quotienten müssen beide Operanden nach float64 konvertiert werden.

var a int = 25 var b int = 10 // ✅ Beide Operanden konvertieren fmt.Println(float64(a) / float64(b)) // 2.5
✅ Korrekt:
float64(a) / float64(b)

Beide Operanden werden zu float64 konvertiert, dann wird die Division durchgeführt.
Schrittweise Auswertung:
1 float64(25) / float64(10)
2 25.0 / 10.0
3 2.5 ✅

Häufige Fehler

❌ Häufiger Fehler: float64(a / b)

Dieser Ausdruck berechnet zuerst den Ganzzahlquotienten und konvertiert dann das Ergebnis!
❌ FALSCH:
float64(a / b)
1 25 / 10 → 2
2 float64(2) → 2.0 ❌
✅ RICHTIG:
float64(a) / float64(b)
1 float64(25) → 25.0
2 25.0 / 10.0 → 2.5 ✅
var a int = 25 var b int = 10 // ❌ FALSCH: Erst Division, dann Konvertierung fmt.Println(float64(a / b)) // 2.0 (nicht 2.5!) // ✅ RICHTIG: Erst Konvertierung, dann Division fmt.Println(float64(a) / float64(b)) // 2.5
