Programmierübung: Ein Telefonbuch als Verbund-Array

Drei kleine Funktionen arbeiten auf einem Array von Verbünden: Sie suchen die jüngste Person, zählen doppelte Namen und kehren die Reihenfolge um.

Kurstext v3.0.6, Abschnitt 8.4, Seiten 221–226. Die drei Funktionen stehen nicht im Kurstext.

Worum es geht

In Abschnitt 8.4 des Kurstexts stehen zwei Algorithmen auf einem Array von Verbünden: die binäre Suche und Bubblesort. Diese Übung bleibt bei dem Telefonbuch und fügt drei einfachere Aufgaben hinzu. Jede ist eine Schleife über das Array, und jede greift auf ein Feld der Verbünde zu.

Das Telefonbuch hat sechs Einträge. Jeder Eintrag ist ein Verbund mit drei Feldern:

type person struct {
    name          string
    telefonnummer int
    alter         int
}

telbuch := [6]person{
    {"Meier", 4711, 34},
    {"Becker", 5522, 58},
    {"Koch", 7745, 19},
    {"Meier", 9081, 41},
    {"Arnold", 3310, 27},
    {"Becker", 1234, 63},
}

Alle drei Funktionen bekommen einen Zeiger auf das Array, wie binSuche und bubblesort im Kurstext. Das Programm arbeitet mit einem Array fester Länge und verwendet keine Slices.

Die Schritte

  • Schritt 1: Eine Funktion liefert den Index der jüngsten Person.
  • Schritt 2: Zwei geschachtelte Schleifen zählen die Paare mit dem gleichen Namen.
  • Schritt 3: Eine Schleife mit zwei Indizes kehrt das Array um.
  • Schritt 4: Das ganze Programm zum Kopieren.

Schritt 1: Die jüngste Person

Erst vorhersagen, dann ausprobieren
  1. Die Funktion soll die jüngste Person finden. Sie kann den Verbund zurückgeben oder den Index. Was hat main vom Index, das eine Kopie des Verbunds nicht bietet?
    AuflösungMit dem Index erreicht main den Eintrag im Array selbst und kann ihn ändern, zum Beispiel mit telbuch[j].telefonnummer = 1111. Eine Änderung an der Kopie bliebe ohne Wirkung auf das Array.

Die Funktion merkt sich in minIndex den Index der jüngsten Person, die sie bisher gesehen hat. Sie beginnt mit dem Index 0 und vergleicht das Alter jedes weiteren Eintrags mit dem Alter am gemerkten Index.

    Ausgabe

    Die Funktion indexÄlteste unterscheidet sich in einem Zeichen: Sie vergleicht mit >. Sie steht in Schritt 4.

    Das Muster ist findMin aus der Programmierübung Selection Sort mit Zeigern.

    Schritt 2: Doppelte Namen

    Erst vorhersagen, dann ausprobieren
    1. Im Telefonbuch stehen Meier und Becker je zweimal. Liefert telbuch[0] == telbuch[3] deshalb true?
      AuflösungNein. == vergleicht alle Felder. Die zwei Einträge haben den gleichen Namen, aber verschiedene Telefonnummern und ein verschiedenes Alter.

    Die Funktion vergleicht jeden Eintrag mit jedem späteren. Die äußere Schleife wählt einen Eintrag i, die innere läuft über alle Einträge j dahinter. So kommt jedes Paar genau einmal an die Reihe.

      Ausgabe

      • Vergleich nach einem Feld: a[i].name == a[j].name vergleicht nur die Namen. a[i] == a[j] wäre nur true, wenn alle drei Felder übereinstimmen.
      • Aufwand: Sechs Einträge ergeben 5 + 4 + 3 + 2 + 1 = 15 Vergleiche. Das ist die gleiche Formel wie bei Bubblesort, n · (n − 1) / 2.

      Schritt 3: Umkehren

      Erst vorhersagen, dann ausprobieren
      1. Das Array hat sechs Elemente. Wie viele Vertauschungen kehren es um?
        AuflösungDrei: das erste mit dem letzten, das zweite mit dem vorletzten, das dritte mit dem vierten. Danach haben sich die zwei Indizes getroffen.

      Die Funktion führt zwei Indizes: i läuft von vorn, j von hinten. Solange i kleiner ist als j, vertauscht sie die zwei Elemente und rückt beide Indizes zur Mitte.

      Die Funktion ändert das Array von main. Deshalb braucht sie den Zeiger: Mit einem Parameter vom Typ [6]person würde sie eine Kopie umkehren, und das Array von main bliebe, wie es ist.

        Ausgabe

        • i, j := 0, len(a)-1: Die for-Klausel deklariert zwei Variablen auf einmal.
        • i, j = i+1, j-1: Eine Tupel-Zuweisung ändert beide Indizes nach jedem Durchlauf.
        • a[i], a[j] = a[j], a[i]: Die gleiche Tupel-Zuweisung wie in bubblesort vertauscht zwei ganze Verbünde.

        Schritt 4: Das ganze Programm

        package main

import "fmt"

type person struct {
    name          string
    telefonnummer int
    alter         int
}

// liefert den Index der jüngsten Person
func indexJüngste(a *[6]person) int {
    minIndex := 0
    for i := 1; i < len(a); i++ {
        if a[i].alter < a[minIndex].alter {
            minIndex = i
        }
    }
    return minIndex
}

// liefert den Index der ältesten Person
func indexÄlteste(a *[6]person) int {
    maxIndex := 0
    for i := 1; i < len(a); i++ {
        if a[i].alter > a[maxIndex].alter {
            maxIndex = i
        }
    }
    return maxIndex
}

// zählt die Paare von Elementen mit dem gleichen Namen
func zähleDoppelte(a *[6]person) int {
    anzahl := 0
    for i := 0; i < len(a)-1; i++ {
        for j := i + 1; j < len(a); j++ {
            if a[i].name == a[j].name {
                anzahl++
            }
        }
    }
    return anzahl
}

// kehrt die Reihenfolge der Elemente um
func umkehren(a *[6]person) {
    for i, j := 0, len(a)-1; i < j; i, j = i+1, j-1 {
        a[i], a[j] = a[j], a[i]
    }
}

func main() {
    telbuch := [6]person{
        {"Meier", 4711, 34},
        {"Becker", 5522, 58},
        {"Koch", 7745, 19},
        {"Meier", 9081, 41},
        {"Arnold", 3310, 27},
        {"Becker", 1234, 63},
    }

    j := indexJüngste(&telbuch)
    fmt.Println("Jüngste Person:", telbuch[j].name, telbuch[j].alter)
    ä := indexÄlteste(&telbuch)
    fmt.Println("Älteste Person:", telbuch[ä].name, telbuch[ä].alter)

    fmt.Println("Paare mit gleichem Namen:", zähleDoppelte(&telbuch))

    umkehren(&telbuch)
    fmt.Println("Umgekehrt:", telbuch)
}

        Ausgabe

        Jüngste Person: Koch 19 Älteste Person: Becker 63 Paare mit gleichem Namen: 2 Umgekehrt: [{Becker 1234 63} {Arnold 3310 27} {Meier 9081 41} {Koch 7745 19} {Becker 5522 58} {Meier 4711 34}]

        Zum Weiterdenken

        Zu diesen Aufgaben gibt es hier keine Lösung.

        • Sortiert? Schreibe eine Funktion istSortiert(a *[6]person) bool, die prüft, ob das Array aufsteigend nach dem Namen sortiert ist. Wie viele Vergleiche braucht sie höchstens?
        • Gleiches Alter: Zwei Personen sind gleich alt. Welche von beiden liefert indexJüngste, und welches Zeichen müsstest du ändern, damit die Funktion die andere liefert?
