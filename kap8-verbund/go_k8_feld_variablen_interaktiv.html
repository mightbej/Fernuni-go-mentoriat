Verbund-Variablen und Feld-Variablen in Go

Jedes Feld eines Verbunds ist selbst eine Variable. Ein Programm liest sie, weist ihr einen Wert zu und kann ihre Adresse nehmen. Die Seite zeigt das an der Verbund-Variable anna aus dem Kurstext.

Kurstext v3.0.6, Abschnitt 8.2.3, Seiten 204–205.

Worum es geht

Zwei Begriffe aus Abschnitt 8.2.3 des Kurstexts tragen diese Lektion:

  • Verbund-Variable: eine Variable eines Verbund-Typs, zum Beispiel anna vom Typ person.
  • Feld-Variable: ein Feld einer Verbund-Variable, zum Beispiel anna.ort. Sie ist eine Variable vom Typ des Felds, hier string.

Der Wert einer Verbund-Variable setzt sich aus den Werten ihrer Felder zusammen. Die gleiche Sicht kennst du vom Array: Auch ein Element a[i] ist eine Variable.

Alle Beispiele verwenden diesen Typ:

type person struct {
    vorname     string
    nachname    string
    gebJahr     int
    ort         string
    verheiratet bool
}

Was dazugehört

  • Abschnitt 8.2 und 8.2.1, Typ und Literal: Die Lektion Verbund in Go zeigt die Definition des Typs und das Verbund-Literal.
  • Abschnitt 6.1, indizierte Variable: Die Lektion Arrays in Go zeigt in Schritt 2 den Zugriff auf ein Element.
  • Abschnitt 7.4, Zeiger: Schritt 2 dieser Lektion braucht & und *. Die Lektion Zeiger in Go erklärt beide in Schritt 2.

Schritt 1: Punkt-Notation

Erst vorhersagen, dann ausprobieren
  1. anna.nachname hat den Wert "Schmidt". Welchen Wert hat das Feld nach anna.nachname += "-Schiller"?
    Auflösung"Schmidt-Schiller". Das Feld ist eine Variable vom Typ string, und += hängt an einen String an.

Auf ein Feld greift ein Programm mit der Punkt-Notation zu: Name der Verbund-Variable, ein Punkt, Name des Felds. anna.nachname ist der Bezeichner der Feld-Variable nachname im Verbund anna.

Mit diesem Bezeichner geht alles, was mit jeder anderen Variable geht: Das Programm liest ihren Wert in einem Ausdruck und weist ihr einen neuen Wert zu.

    Schritt 2: Wert eines Felds oder Zeiger auf das Feld

    Erst vorhersagen, dann ausprobieren
    1. heimat enthält eine Kopie von anna.ort, pHeimat enthält die Adresse von anna.ort. Dann läuft anna.ort = "München". Was liefern heimat und *pHeimat?
      Auflösungheimat liefert weiter "Hamburg", die Kopie ändert sich nicht. *pHeimat liefert "München", denn der Zeiger führt zum Feld selbst.

    Eine Verbund-Variable und jedes ihrer Felder sind adressierbar: Der Adressoperator & liefert einen Zeiger auf den Verbund oder auf ein Feld.

    Wer mit einem Feld arbeitet, muss wie bei jeder Variable unterscheiden:

    • Der Wert des Felds: var heimat string = anna.ort legt eine Kopie des Werts ab. Danach hat heimat mit dem Verbund nichts mehr zu tun.
    • Das Feld selbst: var pHeimat *string = &anna.ort legt die Adresse der Feld-Variable ab. *pHeimat ist das Feld anna.ort.

    Die Demo beginnt mit dem Stand am Ende von Schritt 1. Die Variable anna hat den Wert {Anna Schmidt-Schiller 1966 Hamburg true}.

      Ausgabe

      Der Hauptspeicher unter dem Rahmen zeigt den Unterschied als Zellen: heimat hat eigene Zellen ab der Adresse 200, dorthin wurde der Wert kopiert. pHeimat hat 8 Zellen, in denen die Zahl 140 steht. Das ist im Modell die Adresse des Felds ort im Verbund anna, der bei Zelle 100 beginnt. Die Adressen sind erfunden.

      Das Gleiche gilt in beiden Richtungen: Eine Änderung am Feld ist über den Zeiger sichtbar, und eine Zuweisung über den Zeiger ändert das Feld. Die Kopie heimat bleibt bei beidem außen vor.

      Schritt 3: Ein Verbund als Ganzes

      Erst vorhersagen, dann ausprobieren
      1. Nach kopie := anna läuft kopie.ort = "Bonn". Welchen Wert hat anna.ort danach?
        AuflösungDen alten Wert, "Ulm". kopie ist eine eigene Variable mit eigenen Feldern.

      Was für ein Feld gilt, gilt für den ganzen Verbund: Eine Zuweisung kopiert den Wert. Der Wert eines Verbunds besteht aus den Werten aller Felder, also kopiert die Zuweisung alle Felder.

        Ausgabe

        Die Tupel-Zuweisung personA, personB = personB, personA aus Abschnitt 8.1 des Kurstexts nutzt das: Sie tauscht zwei Verbünde mit allen Feldern in einer Anweisung.

        Wie es weitergeht

        • Zeiger auf den ganzen Verbund: Die Lektion Zeiger auf Verbünde zeigt pPer.nachname.
        • Im Speicher: Die Seite Speichermodell: Verbund zeigt, an welcher Adresse jedes Feld liegt.
