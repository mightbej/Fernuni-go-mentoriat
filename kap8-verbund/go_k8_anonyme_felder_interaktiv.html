Anonyme Felder und eingebettete Verbünde in Go

Ein Feld darf ohne Namen deklariert werden, nur mit seinem Verbund-Typ. Der Zugriff auf die Felder des eingebetteten Verbunds wird dadurch kürzer: r.x an der Stelle von r.umkreis.mitte.x.

Kurstext v3.0.6, Abschnitt 8.3.2, Seiten 216–220.

Worum es geht

Ein hierarchischer Verbund ordnet seine Felder in Ebenen. Das ist übersichtlich, macht aber den Zugriff lang: Wer ein Feld der untersten Ebene anspricht, muss alle Felder darüber nennen.

In Go gibt es dafür das anonyme Feld, englisch anonymous field: ein Feld, bei dessen Deklaration nur der Typ dasteht. Ein Verbund in einem anonymen Feld heißt eingebetteter Verbund, englisch embedded struct.

Das Beispiel des Kurstexts stammt aus einem Zeichenprogramm:

  • Kreis: Mittelpunkt mit x und y, dazu ein Radius.
  • Rad: ein Kreis, dazu eine Zahl von Speichen.

Was dazugehört

  • Abschnitt 8.3, Verbund als Feld: Die Lektion Hierarchische Verbünde zeigt den Zugriff über mehrere Ebenen.
  • Abschnitt 8.2.1 und 8.2.2, Literal und Ausgabe: Die Lektion Verbund in Go, Schritt 3 und 4, mit den zwei Schreibweisen des Literals und dem Verb %+v.
Für die verkettete Liste in Kapitel 9 brauchst du die rekursiven Verbund-Typen aus Abschnitt 8.3.1, die anonymen Felder brauchst du dort nicht. Wer wenig Zeit hat, liest erst die Lektion Rekursive Verbund-Typen.

Schritt 1: Flach, hierarchisch, eingebettet

Erst vorhersagen, dann ausprobieren
  1. Ein Rad enthält einen Kreis im Feld umkreis, der Kreis enthält einen Punkt im Feld mitte. Wie lautet der Zugriff auf die x-Koordinate des Rads r?
    Auflösungr.umkreis.mitte.x. Der Weg nennt jedes Feld auf dem Weg nach unten.

Im Kurstext entsteht der Typ für das Rad in drei Varianten. Wähle eine. Die Seite zeigt die Deklarationen und den Zugriff auf alle vier Werte eines Rads.

Typen und Zugriff

Im Speicher sind alle drei gleich

Ein Rad besteht in jeder der drei Varianten aus vier Werten vom Typ int: x, y, Radius und Speichen. Im Hauptspeicher liegen sie hintereinander, bei 8 Zellen je int sind das 32 Zellen. Die Varianten unterscheiden sich nur darin, unter welchem Namen das Programm die Zellen anspricht.

Kurstext v3.0.6, Abschnitt 8.3.2, Seiten 216–218. Alle Deklarationen und Zugriffe stammen aus dem Kurstext. Der Absatz zum Speicher ist eine Ergänzung.

Schritt 2: Zugriff über anonyme Felder

Erst vorhersagen, dann ausprobieren
  1. Das Feld vom Typ kreis im Typ rad hat keinen Namen bekommen. Was gibt fmt.Printf("%+v\n", r) an der Stelle des Feldnamens aus?
    AuflösungDen Namen des Typs: kreis. Ein anonymes Feld bekommt den Bezeichner seines Typs als Namen.

Die Demo verwendet die dritte Variante:

type punkt struct {
    x, y int
}

type kreis struct {
    punkt // anonymes Feld
    radius int
}

type rad struct {
    kreis // anonymes Feld
    speichen int
}

Der Verbund punkt ist eingebettet in kreis, und kreis ist eingebettet in rad. Beim Zugriff dürfen die anonymen Felder fehlen.

    Ausgabe

    Drei Wege zum gleichen Feld

    Ein anonymes Feld hat doch einen Namen: Go verwendet den Bezeichner seines Typs. Deshalb sind diese drei Zuweisungen erlaubt und meinen das Gleiche:

    r.x = 5             // alle anonymen Felder weggelassen
r.kreis.x = 5       // anonymes Feld kreis angegeben
r.kreis.punkt.x = 5 // anonyme Felder kreis und punkt angegeben
    Zwei anonyme Felder des gleichen Typs in einem Verbund sind nicht erlaubt. Beide hätten den gleichen Namen, und der kurze Zugriff wäre nicht eindeutig. Auf type doppelt struct { punkt; punkt } meldet Go: punkt redeclared.

    Kurstext v3.0.6, Abschnitt 8.3.2, Seiten 218–219. Die Typen, die Zuweisungen und die Ausgabe mit %+v stammen aus dem Kurstext. Die Zeilen 7 und 8 der Demo und die Meldung des Compilers sind ergänzt, geprüft mit Go 1.26.

    Schritt 3: Literale

    Erst vorhersagen, dann ausprobieren
    1. Der Zugriff r.x = 5 ist erlaubt. Übersetzt Go auch das Literal rad{x: 5}?
      AuflösungNein. Die Abkürzung gilt nur für den Zugriff. Ein Literal nennt jede Ebene.

    Für Literale gibt es keine Abkürzung. Es bleiben die zwei Schreibweisen aus Abschnitt 8.2.1:

    • Ohne Feldnamen: Die Werte aller Felder stehen da, Ebene für Ebene geklammert.
    • Mit Feldnamen: Für ein anonymes Feld steht der Name seines Typs als Feldname, dann ein Doppelpunkt und das Literal des eingebetteten Verbunds.

    Wähle ein Literal. Die Seite zeigt, was fmt.Printf("%+v\n", r) danach ausgibt, oder die Meldung des Compilers.

    Ausgabe oder Meldung

    Über mehrere Zeilen geschrieben sieht das zweite Literal so aus:

    r = rad{
    kreis: kreis{ // impliziter Feldname, ":", Typ-Name
        punkt: punkt{
            x: 22,
            y: 33,
        },
        radius: 55,
    },
    speichen: 4,
}
