Zeiger auf Verbünde in Go

Ein Zeiger kann auf einen Verbund zeigen. Über den Zeiger greift ein Programm auf die Felder zu, und Go erlaubt dafür eine kurze Schreibweise: pPer.nachname.

Kurstext v3.0.6, Abschnitt 8.2.4, Seiten 205–207.

Worum es geht

Zu jedem Typ T gibt es in Go den Zeiger-Typ *T. Das gilt auch für einen Verbund-Typ: Eine Variable vom Typ *person nimmt die Adresse einer Variable vom Typ person auf.

Neu sind in Abschnitt 8.2.4 des Kurstexts zwei Kurzschreibweisen:

  • pPer.nachname an der Stelle von (*pPer).nachname: Go dereferenziert den Zeiger beim Zugriff auf ein Feld von selbst.
  • &rgb{128, 0, 80}: Der Adressoperator vor einem Verbund-Literal erzeugt eine Variable ohne Namen und liefert ihre Adresse.

Was dazugehört

  • Abschnitt 7.4, Zeiger: Die Lektion Zeiger in Go erklärt &, *, nil und new.
  • Hinweis 7.4, Kurzschreibweise für Zeiger auf Arrays: pa[i] an der Stelle von (*pa)[i] ist das gleiche Muster. Es steht in Schritt 1 der gleichen Lektion.
  • Abschnitt 8.2.3, Feld-Variablen: Die Lektion Verbund-Variablen und Feld-Variablen zeigt die Punkt-Notation.

Die Beispiele verwenden zwei Typen des Kurstexts:

type person struct {
    vorname     string
    nachname    string
    gebJahr     int
    ort         string
    verheiratet bool
}

type rgb struct {
    red, green, blue int
}

Schritt 1: Feld-Zugriff über einen Zeiger

Erst vorhersagen, dann ausprobieren
  1. pPer zeigt auf anna. Die Zuweisung pPer.nachname = "Maier" nennt die Variable anna nicht. Welchen Wert hat anna.nachname danach?
    Auflösung"Maier". pPer.nachname ist das Feld nachname des Verbunds, auf den pPer zeigt.

Wer über einen Zeiger auf ein Feld zugreifen will, geht in zwei Schritten: erst vom Zeiger zum Verbund, dann vom Verbund zum Feld.

  • Lange Schreibweise: (*pPer).nachname. Der Stern dereferenziert den Zeiger, die Klammern sind nötig.
  • Kurze Schreibweise: pPer.nachname. Go dereferenziert den Zeiger von selbst.

Beide meinen das Gleiche. Im Kurstext steht das als Hinweis 8.2.

    Schritt 2: Der Zeiger im Speicher

    Erst vorhersagen, dann ausprobieren
    1. Ein Zeiger auf einen int8 braucht 8 Zellen. Wie viele Zellen braucht ein Zeiger auf einen Verbund mit drei Feldern?
      AuflösungAuch 8 Zellen. In einem Zeiger steht eine Adresse, und jede Adresse ist gleich lang.

    Im Hauptspeicher ist ein Zeiger auf einen Verbund das Gleiche wie ein Zeiger auf eine Ganzzahl: eine Variable mit 8 Zellen, in denen eine Adresse steht. Der Unterschied steckt im Typ des Zeigers. Er sagt, was an dieser Adresse liegt:

    • *int8: An der Adresse liegt eine Zelle, zu lesen als int8.
    • *rgb: An der Adresse beginnt ein Verbund vom Typ rgb mit drei Feldern. Wo jedes Feld liegt, sagt der Bauplan des Typs.

    Damit ein Feld in eine Zelle passt, haben die Felder von rgb in diesem Modell den Typ uint8. Das Modell zeigt vier Variablen:

    var n int8 = 42               // Zelle 100
farbe := rgb{128, 0, 80}      // Zellen 101 bis 103
var pn *int8 = &n            // Zellen 104 bis 111, darin die Adresse 100
var pFarbe *rgb = &farbe     // Zellen 112 bis 119, darin die Adresse 101

    Wähle einen Ausdruck. Die Zellen, die der Rechner dafür liest, sind gelb markiert.

    Wert

    Die Kurzschreibweise pFarbe.green ist im Speicher eine Rechnung mit zwei Zahlen: die Adresse aus dem Zeiger und der Abstand des Felds aus dem Bauplan.

    Das Modell vereinfacht. Zellen, die Adressen 100 bis 119, der Bauplan und der Typ uint8 für die Felder gehören zum Modell dieser Seite. Im Kurstext hat rgb Felder vom Typ int.

    Schritt 3: Die Adresse eines Verbund-Literals

    Erst vorhersagen, dann ausprobieren
    1. &42 übersetzt Go nicht, ein Literal hat keine Adresse. Übersetzt Go &rgb{128, 0, 80}?
      AuflösungJa. Ein Verbund-Literal ist ein zusammengesetztes Literal, und zusammengesetzte Literale sind adressierbar.

    Verbund-Literale und Array-Literale heißen zusammengesetzte Literale. Sie sind adressierbar. Der Adressoperator vor einem Verbund-Literal ist eine Kurzschreibweise für zwei Anweisungen:

    // kurz
var pFarbe *rgb = &rgb{128, 0, 80}

// ausgeschrieben
var pFarbe *rgb = new(rgb) // anonyme Variable
*pFarbe = rgb{128, 0, 80}  // Literal-Wert zuweisen

    Hinter der kurzen Schreibweise geschieht also Folgendes: new erzeugt eine anonyme Verbund-Variable, und sie bekommt den Wert des Literals. Der Zeiger enthält ihre Adresse.

    Die Demo führt erst den kurzen und dann den ausgeschriebenen Code aus, mit zwei Zeigern pFarbe und pZwei.

      Schritt 4: Ein Literal als Argument

      Erst vorhersagen, dann ausprobieren
      1. f1 := &rgb{22, 33, 44} und f2 := &rgb{22, 33, 44} verwenden das gleiche Literal. Was liefert f1 == f2?
        Auflösungfalse. Jedes &rgb{…} erzeugt eine neue Variable. Die zwei Zeiger zeigen auf zwei verschiedene Variablen mit dem gleichen Wert.

      Die Kurzschreibweise zahlt sich bei einem Funktionsaufruf aus. Eine Funktion erwartet einen Zeiger auf einen Verbund:

      func fügeHinzu(pFarbe *rgb) {
    // ...
}

      Der Aufrufer will ihr eine Farbe übergeben, die er nur an dieser Stelle braucht:

      // kurz: die Adresse des Literals als Argument
fügeHinzu(&rgb{0, 255, 10})

// ausgeschrieben: mit einer Hilfsvariable
h := new(rgb)
*h = rgb{0, 255, 10}
fügeHinzu(h)

      Jedes Literal, eine neue Variable
