1. Einstieg: struct-Zeiger als naechster Schritt

Der Studienbrief fuhrt nach der Feldadressierbarkeit weiter zum Zeiger auf den gesamten Verbund. Ein struct kann also nicht nur selbst Werte enthalten, sondern auch ueber einen Zeiger referenziert werden.

Kernidee: Ein Zeiger auf einen Verbund zeigt auf die komplette Verbund-Variable. Beim Feldzugriff darf Go den Zeiger implizit dereferenzieren.

2. Eine Zeiger-Variable auf einen struct-Typ

Fuer jeden Datentyp gibt es auch den passenden Zeigertyp. Im Studienbrief wird dies als *person beschrieben.

var anna = person{"Anna", "Schmidt", 1966, "Hamburg", false} var pPer *person = &anna

3. Feldzugriff via Verbund-Zeiger

Ueblicherweise waere fuer den Feldzugriff die explizite Dereferenzierung noetig. Der Studienbrief zeigt aber die kompaktere Go-Schreibweise, bei der der Zeiger automatisch dereferenziert wird.

(*pPer).nachname = "Meier" pPer.nachname = "Mueller"
explizit

(*pPer).nachname

kompakt

pPer.nachname

Merke: Beide Schreibweisen sind aequivalent. Die kompakte Form ist in der Praxis ueblich.

4. Der Unterschied zwischen & und *

Beim Zeigergebrauch wird die Richtung besonders wichtig: & liefert eine Adresse, * holt den Wert hinter einer Adresse. Der Studienbrief beschreibt das als Kurzschreibweise fuer Referenzierung und Dereferenzierung.

var pFarbe *rgb = &rgb{128, 0, 80} var pFarbe2 *rgb = new(rgb) *pFarbe2 = rgb{128, 0, 80}
OperatorBedeutung
&xAdresse von x
*pWert an der Adresse, auf die p zeigt
new(T)erzeugt eine anonyme Variable und liefert einen Zeiger
Didaktischer Punkt: Das & auf einem Literal bedeutet nicht „Adresse einer fertigen Variablen“, sondern die Kurzschreibweise fuer die Erzeugung einer anonymen Variable.

5. Verbund-Literale sind adressierbar

Der Studienbrief hebt hervor, dass zusammengesetzte Literale adressierbar sind. Deshalb kann man direkt einen Zeiger auf ein Verbund-Literal erzeugen.

var pFarbe *rgb = &rgb{128, 0, 80} fugeHinzu(&rgb{0, 255, 10})
Wichtig: Die kompakte Schreibweise ist eine Kurzform, bei der implizit new aufgerufen wird. Praktisch spart sie Hilfsvariablen.

6. Verbund-Literale als Funktionsargumente

Ein grosser Vorteil der adressierbaren Literale liegt bei Funktionsaufrufen: Der Zeiger auf das Literal kann direkt als Argument uebergeben werden.

fugeHinzu(&rgb{0, 255, 10}) h := new(rgb) *h = rgb{0, 255, 10} fugeHinzu(h)
Vorteil: Keine Hilfsvariable noetig, der Aufruf bleibt kurz und lesbar.

7. Jedes Literal erzeugt eine neue Variable

Auch wenn zwei Verbund-Literale denselben Wert besitzen, entstehen beim Adressieren zwei verschiedene anonyme Variablen. Die Zeiger vergleichen also Adressen, nicht Werte.

f1 := &rgb{22, 33, 44} f2 := &rgb{22, 33, 44} fmt.Println(f1 == f2)
VergleichBedeutung
f1 == f2false, weil die Zeiger auf unterschiedliche Variablen zeigen
*f1 == *f2true, wenn die Werte der referenzierten Verbunde gleich sind
Typischer Irrtum: Gleicher Wert bedeutet nicht gleiche Adresse. Jedes &rgb{...} erzeugt eine neue anonyme Variable.
