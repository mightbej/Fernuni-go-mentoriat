# Willkommen im Mentoriat: Kurstext, Go und Lernquellen

Die Seite ist die Lektion zur ersten Sitzung des Mentoriats. Sie erklärt den Aufbau des Kurstexts und seine farbigen Kästen, stellt fünf Wege vor, Go-Programme auszuführen, und nennt Lernquellen.

Die Seite hat fünf Reiter. Sichtbar ist immer nur ein Schritt.

Für alle Schritte gilt:

- Auf dieser Seite gibt es keinen Go-Code zum Ausführen. Der Student kann keinen Code ändern und keinen eigenen Code ausführen.
- Ansprechpartner, Termine der Sitzungen, Fristen der Aufgabenpakete und die Klausur stehen nicht auf dieser Seite. Sie stehen im Kurs in Moodle und im angepinnten Beitrag des Mentors im Forum des Mentoriats. Auf solche Fragen verweist die Antwort dorthin und nennt keine Daten, keine Namen und keine Adressen.
- Fachfragen gehören in das Forum des Kurses in Moodle, Fragen zu den Sitzungen an den Mentor Thomas Czinkota.

## Schritt 2: Go auf dem Rechner

Reiter: go

### Aufbau der Darstellung

- Ein Absatz sagt, was der Kurstext dazu enthält: nur den Befehl `go run hello_world.go` in Abschnitt 3.2 und die Version Go 1.22 in Hinweis 3.1. Wie Go auf den Rechner kommt, steht nicht im Kurstext.
- Eine Tabelle stellt fünf Wege nebeneinander, mit den Spalten Weg, was der Student installiert, ob ein Programm Eingaben lesen kann, was der Weg kostet.
  - Go Playground im Browser: nichts zu installieren, keine Eingaben, also kein `fmt.Scan`, kostenlos.
  - Go selbst von go.dev: Programme laufen in der Konsole mit `go run`, Eingaben gehen, kostenlos.
  - GoLand von JetBrains: braucht vorher Go, Eingaben gehen in der Konsole von GoLand, für Studenten kostenlos mit einer Adresse `@studium.fernuni-hagen.de`.
  - Visual Studio Code mit der Go Extension: braucht vorher Go, kostenlos, nach dem Lehrstuhl nur für Fortgeschrittene.
  - Editorlotse des Mentors: Paket entpacken, EXE starten, Go holt er selbst, Eingaben tippt der Student unter der Ausgabe ein. Für die Leiste braucht er einen Schlüssel von KI:connect. Das Paket folgt in Moodle.
- Die ersten vier Wege beschreibt der Lehrstuhl in Moodle auf der Seite „Compiler und weitere Software“. Dort steht auch, wie man GoLand einrichtet.
- Eine Liste darunter: Der Student wählt den Weg selbst, der Mentor führt in den Sitzungen im Editorlotsen vor. Unter Windows prüft der Microsoft Defender jede neu übersetzte EXE, der erste Start dauert dann einige Sekunden. Der Playground ersetzt die lokale Installation nicht.

Voraussetzungen sind ein Alter ab 18 Jahren, ein Nachweis des Studiums und eine hinterlegte Zahlungsmethode. Ohne Kündigung läuft das Abo kostenpflichtig weiter.
  - GitHub Education: Mit dem Student Developer Pack bekommen nachgewiesene Studenten GitHub Copilot kostenlos. GitHub hat die Bedingungen im Jahr 2026 mehrmals geändert.
  - ChatGPT und andere Sprachmodelle.
- Ein grüner Kasten: Ein Sprachmodell irrt sich. Jede Erklärung am Kurstext prüfen, jedes Programm mit Go. Den Kurstext bei einem fremden Dienst nur für sich selbst hochladen.
- Die Angebote von Google und GitHub haben den Stand 15.10.2026. Was danach gilt, steht auf den Seiten von Google und GitHub. Preise nach dem kostenlosen Jahr nennt die Seite nicht.
