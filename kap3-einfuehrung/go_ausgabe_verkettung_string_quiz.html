Quiz: Ausgabe und Verkettung von String in Go

Zuerst gemeinsam raten, dann mit einem Klick die Aufloesung einblenden.

Merkhilfe aus dem Skript

  • fmt.Println() ohne Argumente erzeugt nur einen Zeilenumbruch.
  • Bei string + string wird ein neuer String durch Verkettung gebildet.
  • fmt.Println(a, b) trennt Argumente in der Ausgabe mit Leerzeichen.
  • Der urspruengliche String in einer Variablen wird durch Verkettung nicht geaendert.
Beispiel: tempText + " C:"

Quizrunde (richtig/falsch)

Hinweis: Erst abstimmen lassen, dann auf Auswerten + Aufloesung klicken.

Aussage Deine Wahl Aufloesung
fmt.Println() ohne Argumente erzeugt eine Leerzeile.
Richtig: nur Zeilenumbruch.
Der Ausdruck tempText + " C:" ist eine String-Verkettung.
Richtig: links und rechts sind String.
String-Verkettung mit + aendert den linken Operanden direkt.
Falsch: es entsteht ein neuer String.
Bei fmt.Println(tempText+" C:", tempC) wird zwischen den zwei Argumenten ein Leerzeichen ausgegeben.
Richtig: Println trennt Argumente mit Leerzeichen.
fmt.Println("A" + 5) ist gueltig, weil + alles verketten kann.
Falsch: String und Zahl koennen nicht direkt mit + verknuepft werden.
Wenn tempText den Wert "Temperatur in " hat, dann ergibt tempText + " F:" den String "Temperatur in F:" mit dem vorhandenen Leerzeichen aus tempText.
Richtig: Verkettung uebernimmt vorhandene Zeichen exakt.
Die drei Zeilen fuer C/F/K koennen alle denselben Basisstring tempText verwenden.
Richtig: je Zeile wird nur ein anderer Suffix angehaengt.
fmt.Println("Temperatur in C:", 22) gibt ohne Leerzeichen aus.
Falsch: es erscheint ein Leerzeichen zwischen den Argumenten.
fmt.Println("A", "B") und fmt.Println("A"+"B") erzeugen unterschiedliche Ausgabe.
Richtig: erstes ergibt A B, zweites AB.
Der Datentyp string legt fest, dass in der Variablen Zeichenketten gespeichert werden.
Richtig: Typbindung bestimmt erlaubte Werte.
Noch nicht ausgewertet.

Mini-Code zum Durchsprechen

var tempText string = "Temperatur in "
var tempC float64 = 22
fmt.Println()
fmt.Println(tempText+" C:", tempC)

Didaktischer Fokus: Leerzeile durch leeres Println und danach Ausgabe mit verkettetem Label plus Zahlenwert.
