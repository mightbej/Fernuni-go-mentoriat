Go Fehlersuche fuer Anfaenger

Drei kurze Programme mit einfacher Syntax und wenigen, gut besprechbaren Fehlern. Die Programme sind bewusst klein gehalten, damit die Studierenden sich auf die Fehlersuche konzentrieren koennen.

Empfohlener Ablauf

  • Programm lesen und zuerst nur Vermutungen sammeln.
  • Dann in den Go-Editor kopieren und die Fehlermeldungen besprechen.
  • Danach das korrigierte Programm gemeinsam starten.

Programm 1: Einfache Flaechenberechnung

Fokus: Funktionsaufruf und Argumentliste.

package main

import "fmt"

func rechteck(a int, b int) int {
    return a * b
}

func main() {
    fmt.Println(rechteck(3 4))
}
Lehrkraft-Hinweise
  • Nur ein kleiner Syntaxfehler.
  • Gut geeignet fuer die Frage: Wie muessen Argumente getrennt werden?

Programm 2: Temperaturausgabe

Fokus: String-Ausgabe mit fmt.Println.

package main

import "fmt"

func main() {
    var tempC int = 22
    fmt.Println("Temperatur in C: " + tempC)
}
Lehrkraft-Hinweise
  • Syntax ist sehr einfach, der Fehler steckt im Typmix.
  • Gute Anschlussfrage: Wie gibt man Text und Zahl korrekt gemeinsam aus?

Programm 3: if-Anweisung

Fokus: implizite Semikolons und Stellung der geschweiften Klammer.

package main

import "fmt"

func main() {
    var x int = 5

    if x > 0
    {
        fmt.Println("positiv")
    }
}
Lehrkraft-Hinweise
  • Formal sehr einfach, aber didaktisch wertvoll.
  • Gut geeignet, um Go-Regel zur Klammerstellung zu besprechen.
