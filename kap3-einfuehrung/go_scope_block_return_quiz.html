Quiz: call-by-value, Scope, Block und return

Interaktive Wiederholung zu Abschnitt 3.4 (Fortsetzung).

Merkhilfe

  • Bei call-by-value werden Werte der Argumente uebergeben.
  • Der Geltungsbereich eines Namens ist auf seinen Block (und Unterbloecke) begrenzt.
  • Parameter sind implizit deklarierte Variablen mit Scope im Funktionsrumpf.
  • return beendet die Funktion und gibt optional einen Wert passenden Typs zurueck.
func rechteck(seiteA int, seiteB int) int return flaeche

Quizrunde (richtig/falsch)

Erst gemeinsam einschaetzen, dann Aufloesung einblenden.

Aussage Deine Wahl Aufloesung
Beim Aufruf rechteck(a, b) mit a=3 und b=4 erhalten seiteA und seiteB die Werte 3 und 4.
Richtig: Parameter werden mit Argumentwerten initialisiert.
Diese Art der Uebergabe nennt man call-by-value.
Richtig: uebergeben werden Werte, nicht direkte Speicherorte.
Die in einer Funktion deklarierte Variable flaeche ist im gesamten Programm sichtbar.
Falsch: Scope ist auf den Funktionsblock beschraenkt.
Der Geltungsbereich einer Deklaration bezieht sich auf den Block, in dem sie steht, plus Unterbloecke.
Richtig: das ist die grundlegende Scope-Regel.
Parameter einer Funktion haben ebenfalls nur Scope innerhalb des Funktionsrumpfs.
Richtig: Parameter sind implizit deklarierte Variablen im Funktionsblock.
Die Anweisung return flaeche beendet die Funktion an dieser Stelle.
Richtig: nach return geht es am Aufrufpunkt weiter.
Der von return gelieferte Wert muss zum Rueckgabetyp der Funktion passen.
Richtig: sonst ist es ein Typfehler.
Der Ausdruck seiteA * seiteB ist unabhaengig von den uebergebenen Argumentwerten immer gleich.
Falsch: Ergebnis haengt von den konkreten Parameterwerten ab.
Ein Block ist in Go nur der Koerper einer Funktion; andere Blöcke gibt es nicht.
Falsch: jeder Anweisungsblock in geschweiften Klammern ist ein Block.
Der Begriff Sichtbarkeit eines Bezeichners ist eng mit seinem Geltungsbereich verbunden.
Richtig: nur im Scope ist ein Name bekannt und nutzbar.
Noch nicht ausgewertet.

Mini-Code zum Durchsprechen

func rechteck(seiteA int, seiteB int) int {
    var flaeche int = seiteA * seiteB
    return flaeche
}

func main() {
    var a int = 3
    var b int = 4
    fmt.Println(rechteck(a, b)) // 12
}
