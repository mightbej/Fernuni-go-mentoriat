Quiz: 3.4 Funktionen in einem Go Programm

Interaktive Wiederholung zu Deklaration, Parametern, Argumenten, Rueckgabewert und call-by-value.

Merkhilfe

  • Funktionsdeklaration beginnt mit func, dann Name, Parameterliste und optional Rueckgabetyp.
  • Parameter werden in der Deklaration festgelegt, Argumente im Aufruf uebergeben.
  • main ist obligatorisch und hat in diesem Kontext keinen Rueckgabewert.
  • Die Uebergabe der Argumentwerte erfolgt hier als call-by-value.
  • Der Funktionsrumpf ist ein Block zwischen { und }.
func rechteck(seiteA int, seiteB int) int rechteck(a, b)

Quizrunde (richtig/falsch)

Erst diskutieren lassen, dann mit Auswerten + Aufloesung aufdecken.

Aussage Deine Wahl Aufloesung
Ein Go-Programm besteht typischerweise aus mehreren Funktionsdeklarationen und Funktionsaufrufen.
Richtig: Funktionen sind ein zentraler Baustein von Go-Programmen.
In func rechteck(seiteA int, seiteB int) int sind seiteA und seiteB Parameter.
Richtig: Parameter werden in der Deklaration angegeben.
In rechteck(a, b) sind a und b Parameter der Funktion.
Falsch: im Aufruf sind a und b Argumente.
Der Rueckgabetyp steht zwischen schliessender Klammer ) der Parameterliste und oeffnender Klammer { des Rumpfs.
Richtig: dort wird der Datentyp des Rueckgabewerts deklariert.
Funktionen ohne Rueckgabewert muessen den Rueckgabetyp void angeben.
Falsch: in Go wird der Rueckgabetyp dann einfach weggelassen.
main ist die obligatorische Funktion des Programms.
Richtig: ohne passende main startet das Programm nicht als ausfuehrbares Programm.
Beim Aufruf rechteck(a, b) mit a=3 und b=4 werden die Parameter mit den Werten 3 und 4 belegt.
Richtig: uebergeben werden die Werte der Argumente.
Der Funktionsrumpf ist syntaktisch ein Block, also eine Folge von Anweisungen in { und }.
Richtig: das ist die Blockstruktur in Go.
Bei call-by-value kann die Funktion die Ursprungsvariablen des Aufrufers direkt veraendern.
Falsch: uebergeben werden Werte, nicht direkte Variable-Referenzen.
Im Aufruf quader(rechteck(a, b), c) ist der Rueckgabewert von rechteck(a, b) ein Argument fuer quader.
Richtig: Funktionsaufrufe koennen als Argumentausdruecke dienen.
Die Funktion rechteck liefert in dem Beispiel einen Wert vom Typ float64 zurueck.
Falsch: Rueckgabetyp ist int.
Beim Aufruf rechteck(7, 9) sind 7 und 9 Argumente in Form von Integer-Literalen.
Richtig: Argumente muessen keine Variablen sein.
Noch nicht ausgewertet.

Mini-Code zum Durchsprechen

func rechteck(seiteA int, seiteB int) int {
    var flaeche int = seiteA * seiteB
    return flaeche
}

func main() {
    var a int = 3
    var b int = 4
    fmt.Println(rechteck(a, b))
}

Kernidee: Deklaration (Parameter, Rueckgabetyp) und Aufruf (Argumente, Wertuebergabe) klar trennen.
