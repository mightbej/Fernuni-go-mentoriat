Quiz: Implizite Semikolons in Go

Frage je Zeile: Setzt Go hier am Zeilenende automatisch ein Semikolon?

Merkhilfe

  • Go setzt automatisch ein Semikolon am Zeilenende nach bestimmten Token.
  • Typische Faelle mit implizitem Semikolon: Identifier, Literale, ), ], }, sowie break, continue, fallthrough, return.
  • Kein implizites Semikolon nach z. B. for, if, Operatoren (+) oder Komma.

Quizrunde

Erst abstimmen lassen, dann auf Auswerten + Aufloesung klicken.

Zeile (Ende markiert durch Zeilenumbruch) Deine Wahl Aufloesung 
name
Ja: Identifier am Zeilenende. 
"Go"
Ja: String-Literal am Zeilenende. 
fmt.Println(x)
Ja: Die Zeile endet mit ). 
}
Ja: Nach } wird eingefuegt. 
return
Ja: return gehoert zu den Ausnahmen mit Einfuegung. 
for
Nein: Nach for wird nicht eingefuegt. 
a +
Nein: Operator am Zeilenende. 
x,
Nein: Komma am Zeilenende. 
obj.
Nein: Punkt am Zeilenende. 
{
Nein: Nach { wird nicht eingefuegt.
Noch nicht ausgewertet.

Typischer Stolperstein

if x > 0
{
    fmt.Println(x)
}

Hier fuehrt der Zeilenumbruch nach 0 dazu, dass ein Semikolon eingefuegt wird. Deshalb erwartet der Parser direkt danach { auf derselben Zeile.
