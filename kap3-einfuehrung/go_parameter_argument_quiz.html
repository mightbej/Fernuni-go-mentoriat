Quiz: Parameter vs. Argument in Go

Ordne jeden markierten Begriff zu: Parameter oder Argument.

Merkhilfe

  • Parameter gehoeren zur Funktionsdeklaration.
  • Argumente gehoeren zum Funktionsaufruf.
  • Bei der Ausfuehrung erhalten Parameter die Werte der Argumente.
Deklaration: func rechteck(seiteA int, seiteB int) int Aufruf: rechteck(a, b)

Quizrunde

Erst abstimmen lassen, dann auf Auswerten + Aufloesung klicken.

Aussage (markierter Begriff) Deine Wahl Aufloesung
In func rechteck(seiteA int, seiteB int) int ist seiteA ein ...
Parameter: Teil der Deklaration.
In func rechteck(seiteA int, seiteB int) int ist seiteB ein ...
Parameter: Name plus Typ in der Deklaration.
Im Aufruf rechteck(a, b) ist a ein ...
Argument: Wert/Variable beim Aufruf.
Im Aufruf rechteck(a, b) ist b ein ...
Argument: wird an die Funktion uebergeben.
Im Aufruf rechteck(7, 9) ist 7 ein ...
Argument: Integer-Literal beim Aufruf.
Im Aufruf rechteck(7, 9) ist 9 ein ...
Argument: zweiter uebergebener Wert.
In der Funktionsdefinition ist die Variable, die beim Aufruf belegt wird, ein ...
Parameter: lokale Variable im Funktionsrumpf.
Die Werte, die bei rechteck(a, b) uebergeben werden, sind ...
Argumente: Werte beim Aufruf.
Der Gueltigkeitsbereich von seiteA in rechteck ist der Funktionsrumpf. seiteA ist ein ...
Parameter: gueltig nur innerhalb der Funktion.
Beim Aufruf rechteck(a, b) werden die aktuellen Werte von a und b als ... verwendet.
Argumente: ihre Werte belegen dann die Parameter.
Noch nicht ausgewertet.

Mini-Beispiel zum Durchsprechen

func rechteck(seiteA int, seiteB int) int {
    return seiteA * seiteB
}

var a int = 3
var b int = 4
fmt.Println(rechteck(a, b))

Didaktischer Kern: seiteA und seiteB sind Parameter, a und b sind Argumente.
