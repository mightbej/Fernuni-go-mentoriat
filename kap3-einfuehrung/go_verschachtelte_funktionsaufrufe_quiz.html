Quiz: Funktionsaufruf als Ausdruck und Verschachtelung

Letzter Abschnitt aus 3.4: Auswertungsreihenfolge bei verschachtelten Funktionsaufrufen.

Merkhilfe

  • Wenn eine Funktion einen Wert zurueckgibt, kann ihr Aufruf als Ausdruck verwendet werden.
  • Bei verschachtelten Aufrufen wird zuerst der innere Aufruf ausgewertet.
  • Der Rueckgabewert des inneren Aufrufs wird als Argument an den aeusseren Aufruf uebergeben.
fmt.Println(rechteck(a, b)) quader(rechteck(a, b), c)

Quizrunde (richtig/falsch)

Erst gemeinsam diskutieren, dann mit Auswerten + Aufloesung aufdecken.

Aussage Deine Wahl Aufloesung
Da rechteck einen Wert zurueckliefert, ist rechteck(a, b) ein Ausdruck.
Richtig: Funktionsaufruf mit Rueckgabewert ist als Ausdruck nutzbar.
In fmt.Println(..., rechteck(a, b)) wird der von rechteck gelieferte Wert als Argument an fmt.Println uebergeben.
Richtig: der Ausdruckswert wird uebergeben.
Bei quader(rechteck(a, b), c) wird zuerst rechteck(a, b) ausgewertet.
Richtig: der innere Aufruf liefert zuerst das Argument fuer quader.
Mit a=3, b=4, c=5 ergibt quader(rechteck(a, b), c) den Wert 60.
Richtig: rechteck liefert 12, danach quader(12, 5) = 60.
Bei verschachtelten Aufrufen wird zuerst die aeussere Funktion vollstaendig ausgefuehrt.
Falsch: benoetigte innere Argumentausdruecke werden zuerst ausgewertet.
Der Ausdruck rechteck(a, b) kann nicht an fmt.Println uebergeben werden.
Falsch: gerade weil er einen Wert liefert, ist das moeglich.
Ein verschachtelter Funktionsaufruf liegt vor, wenn ein Funktionsaufruf als Argument eines anderen Aufrufs vorkommt.
Richtig: genau das ist hier der Fall.
In quader(rechteck(a, b), c) ist c der Rueckgabewert von rechteck.
Falsch: Rueckgabewert von rechteck ist das erste Argument von quader.
Der Rueckgabewert von quader(...) wird anschliessend als Argument an fmt.Println uebergeben.
Richtig: so entsteht am Ende die Ausgabe des berechneten Werts.
Die Deklaration von quader erfolgt analog zu rechteck: func, Name, Parameter, Rueckgabetyp, Rumpf.
Richtig: gleiche Struktur, andere Bedeutung der Parameter.
Noch nicht ausgewertet.

Mini-Code zum Durchsprechen

var a int = 3
var b int = 4
var c int = 5

fmt.Println("Flaeche:", rechteck(a, b))
fmt.Println("Volumen:", quader(rechteck(a, b), c))
// rechteck(a,b) -> 12
// quader(12,c) -> 60

Didaktischer Fokus: inneren Aufruf auswerten, Rueckgabewert weiterreichen, dann aeusseren Aufruf ausfuehren.
