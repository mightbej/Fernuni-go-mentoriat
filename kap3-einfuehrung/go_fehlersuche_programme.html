Go Fehlersuche: 3 Beispielprogramme

Diese Seite enthaelt drei absichtlich fehlerhafte Go-Programme. Die Fehler sind fachlich an eure Unterrichtseinheit angepasst und sollen sich gut fuer gemeinsames Suchen, Begruenden und anschliessendes Testen im Go-Editor eignen.

Didaktische Idee

  • Zuerst nur das Programm ansehen und Vermutungen sammeln.
  • Dann das Programm in den Go-Editor kopieren und Compiler-Meldungen besprechen.
  • Danach die inhaltlichen oder logischen Fehler suchen, die nicht sofort vom Compiler gefunden werden.
  • Die Lehrkraft-Hinweise sind absichtlich eingeklappt.

Programm 1: Rechteck und Quader

Fokus: Funktionsaufrufe, Scope, Rueckgabewert, verschachtelte Berechnung.

package main

import "fmt"

func rechteck(seiteA int, seiteB int) int {
    var flaeche int = seiteA * seiteB
    return flaeche
}

func quader(grundflaeche int, hoehe int) int {
    var volumen int = grundflaeche * hoehe
    return grundflaeche
}

func main() {
    var a int = 3
    var b int = 4
    var c int = 5

    fmt.Println("Flaeche:", rechteck(a b))
    fmt.Println("Volumen:", quader(flaeche, c))
}
Lehrkraft-Hinweise
  • Ein Syntaxfehler steckt im Funktionsaufruf von rechteck.
  • Ein Bezeichner wird ausserhalb seines Scope verwendet.
  • Die Funktion quader liefert zwar einen Wert zurueck, aber nicht den gemeinten.

Programm 2: Temperaturausgabe

Fokus: Ausgabe, String-Verkettung, Bindungsstaerken, Datentypen.

package main

import "fmt"

func main() {
    var tempC float64 = 22
    var tempText string = "Temperatur in"
    var tempF float64 = (32 + tempC) * 1.8
    var tempK float64 = tempC - 273.15

    fmt.Println()
    fmt.Println(tempText + " C:" + tempC)
    fmt.Println(tempText + " F:", tempF)
    fmt.Println(tempText + " K:", tempK)
}
Lehrkraft-Hinweise
  • Ein Fehler betrifft die Verknuepfung von String und Zahl.
  • Mindestens zwei Rechenfehler sind inhaltlich, nicht rein syntaktisch.
  • Die Ausgabe wirkt auf den ersten Blick fast plausibel, ist aber fachlich nicht sauber.

Programm 3: if, return und call-by-value

Fokus: implizite Semikolons, Blocksyntax, Parameter und Werteuebergabe.

package main

import "fmt"

func addiereEins(zahl int) int {
    zahl = zahl + 1
    return zahl
}

func main() {
    var x int = 7

    if x > 0
    {
        fmt.Println("x ist positiv")
    }

    addiereEins(x)
    fmt.Println("Wert von x:", x)
}
Lehrkraft-Hinweise
  • Ein Fehler haengt mit der Stellung der geschweiften Klammer nach if zusammen.
  • Das Programm zeigt nach einer Korrektur noch immer ein interessantes inhaltliches Verhalten.
  • Sehr gut geeignet fuer die Frage: Warum ist x am Ende nicht 8?
