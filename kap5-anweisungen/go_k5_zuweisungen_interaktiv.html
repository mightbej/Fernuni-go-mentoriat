Zuweisungen in Go

Eine Zuweisung gibt einer Variable einen neuen Wert. Die Seite zeigt die Zuweisung mit =, die kombinierten Operatoren wie +=, die Anweisungen ++ und --, die Tupel-Zuweisung und die einfachen Anweisungen.

Kurstext v3.0.6, Abschnitte 5.3 und 5.4, Seiten 126–129.

Worum es geht

Eine Variable behält ihren Wert, bis das Programm ihr einen neuen gibt. Das tut die Zuweisung, englisch assignment statement:

x = 10       // x bekommt den Wert 10
x = x + 12   // x bekommt den Wert 22

Die Zuweisung ist ein Kennzeichen der imperativen Programmierung: Das Programm ändert Schritt für Schritt die Werte seiner Variablen.

Go hat neben der Zuweisung mit = kürzere Schreibweisen für Zuweisungen, die oft vorkommen. Sie lassen sich alle auf die Zuweisung mit = zurückführen.

  • Abschnitt 3.3.5, Seiten 33–35, die erste Zuweisung in Go: In Listing 3.2 stehen tempC = 10 und tempC = tempC + 12. Dort wird auch der Ausdruck erklärt.

Zuweisung mit =

Die einfachste Zuweisung hat drei Teile:

x = x + 5
  • Links steht eine Variable. Sie bekommt den neuen Wert. Hier ist es x.
  • In der Mitte steht der Zuweisungsoperator =.
  • Rechts steht ein Ausdruck. Hier ist es x + 5. Der Typ seines Werts muss zum Typ der Variable passen.

Was Go bei einer Zuweisung tut

  • Erst auswerten: Go rechnet den Ausdruck auf der rechten Seite aus. Hat x den Wert 10, ergibt x + 5 den Wert 15.
  • Dann ablegen: Go legt diesen Wert in der Variable auf der linken Seite ab. Der alte Wert 10 ist überschrieben und verloren.

= ist kein Gleichheitszeichen

In der Mathematik wäre x = x + 5 eine Gleichung ohne Lösung. In Go ist es eine Anweisung und wird gelesen als: Der Variable x wird der Wert von x + 5 zugewiesen.

Der Zuweisungsoperator hat eine Richtung: von rechts nach links. Andere Schreibweisen betonen das:

  • Pseudocode: oft x ← x + 5, mit einem Pfeil nach links.
  • Pascal: x := x + 5. In Go bedeutet := etwas anderes, nämlich die kurze Variablendeklaration.

Ob zwei Werte gleich sind, prüft in Go der Gleichheitsoperator == aus Abschnitt 4.5.2, Seiten 96–98.

    Wenn der Typ nicht passt

    Go wandelt bei einer Zuweisung keinen Wert stillschweigend in einen anderen Typ um. Wer einer Variable vom Typ float64 den Wert einer Variable vom Typ int zuweisen will, schreibt die Konversion hin: f = float64(x). Dazu gibt es die Seite Typkonvertierung.

    Einer Konstante lässt sich nichts zuweisen. Dazu gibt es die Seite Konstanten.

    Kombinierte Operatoren

    Oft hängt der neue Wert einer Variable von ihrem alten Wert ab: Die Variable steht links vom = und noch einmal als linker Operand auf der rechten Seite.

    x = x * 8
y = y + 5
z = z - (2 + 3)

    Für diese Zuweisungen hat Go eine kürzere Schreibweise:

    x *= 8       // entspricht x = x * 8
y += 5       // entspricht y = y + 5
z -= 2 + 3   // entspricht z = z - (2 + 3)

    Der Operator *= verbindet den Zuweisungsoperator = mit dem Multiplikationsoperator *. Die Variable links ist zugleich der linke Operand der Multiplikation. Der Ausdruck rechts ist der rechte Operand.

    Kurze SchreibweiseLange SchreibweiseWas die Zuweisung tut
    x *= 8x = x * 8Sie multipliziert x mit 8.
    x /= 8x = x / 8Sie teilt x durch 8.
    x %= 8x = x % 8Sie ersetzt x durch den Rest der Division durch 8.
    x += 8x = x + 8Sie erhöht x um 8.
    x -= 8x = x - 8Sie verringert x um 8.

    Die rechte Seite gehört zusammen

    Die dritte Zeile oben verdient einen zweiten Blick. z -= 2 + 3 entspricht z = z - (2 + 3), mit Klammern. Go wertet erst den ganzen Ausdruck rechts aus, hier zu 5, und zieht dann 5 von z ab.

    Wer die Klammern vergisst und z = z - 2 + 3 liest, rechnet falsch: Das ergäbe z + 1.

    Welche kombinierten Operatoren es gibt

    Einen kombinierten Operator gibt es zu jedem binären Operator, der multipliziert oder addiert oder ihnen in der Bindungsstärke gleichsteht. Das sind die Operatoren der Bindungsstärken 5 und 4 aus der Tabelle in Abschnitt 4.1.2, Seite 50.

    • Rechnen: *=, /=, %=, +=, -=.
    • Bits: zum Beispiel <<= und >>= für die Bitverschiebung. Dazu gibt es die Seite Bitverschiebung.
    • Strings: + verkettet zwei Strings, also hängt += einen String an. Hat wetter den Wert "Regen", ergibt wetter += "schauer" den Wert "Regenschauer".

    ++ und --

    Am häufigsten ändert ein Programm eine Variable um genau 1, zum Beispiel beim Zählen. Dafür gibt es zwei eigene Anweisungen:

    • Inkrementierungs-Anweisung x++: Sie erhöht x um 1. Sie entspricht x += 1 und x = x + 1.
    • Dekrementierungs-Anweisung y--: Sie verringert y um 1. Sie entspricht y -= 1 und y = y - 1.

    Anweisung und kein Ausdruck

    ++ und -- sehen aus wie Operatoren, sind aber keine.

    • + und - sind Operatoren. Mit ihnen bildet man Ausdrücke, und ein Ausdruck hat einen Wert: x + 1 ergibt 11, wenn x den Wert 10 hat.
    • x++ ist eine Anweisung. Sie tut etwas, hat aber keinen Wert. Deshalb kann x++ nicht dort stehen, wo Go einen Ausdruck erwartet.

      In anderen Sprachen

      In Java und einigen anderen Sprachen ist x++ zugleich Anweisung und Ausdruck. Dort gibt es zwei Formen:

      • Post-Increment x++: Der Ausdruck liefert den alten Wert von x, danach wird x erhöht.
      • Pre-Increment ++x: Erst wird x erhöht, der Ausdruck liefert den neuen Wert.

      Hat x den Wert 10, bekommt y in Java durch y = x++ den Wert 10 und durch y = ++x den Wert 11. In beiden Fällen hat x danach den Wert 11.

      Go kennt diese Unterscheidung nicht. In Go schreibt man zwei Anweisungen untereinander, und jeder sieht die Reihenfolge:

      y = x
x++

      Tupel-Zuweisung

      Eine Deklaration kann mehrere Variablen auf einmal anlegen. Genauso kann eine Zuweisung mehreren Variablen auf einmal Werte geben. Sie heißt Tupel-Zuweisung, englisch tuple assignment:

      x, y, z := 10, 8, -5    // Deklaration von drei Variablen
x, y, z = 22, 33, 44    // Tupel-Zuweisung an drei Variablen

      Links und rechts vom = stehen gleich viele Einträge. Die erste Variable bekommt den ersten Wert, die zweite den zweiten und so weiter. Stimmt die Anzahl nicht, übersetzt Go das Programm nicht. Zu x, y = 22, 33, 44 meldet der Compiler assignment mismatch: 2 variables but 3 values.

      Zwei Schritte

      • Schritt 1, auswerten: Go wertet alle Ausdrücke auf der rechten Seite aus und merkt sich die Werte.
      • Schritt 2, zuweisen: Go weist die gemerkten Werte den Variablen auf der linken Seite zu.

      Weil Go sich die Werte merkt, bevor es die erste Variable überschreibt, lassen sich zwei Werte mit einer einzigen Anweisung vertauschen: a, b = b, a.

      Ausprobieren: zwei Werte vertauschen

      a beginnt mit 3, b mit 8. Am Ende soll a den Wert 8 und b den Wert 3 haben.

        Die gelb markierte Zeile ist die Zeile, die gerade ausgeführt wird oder wurde. Ein grüner Strich links bedeutet: Die Zeile ist schon gelaufen. Ein gelb unterlegter Kasten hat sich mit dem letzten Schritt geändert. Ein gestrichelter Kasten zeigt einen Wert, den Go sich nur für diese Anweisung merkt.

        Wann man die Tupel-Zuweisung nimmt

        • Passend: Die Variablen gehören inhaltlich zusammen, zum Beispiel die Koordinaten x, y und z, und rechts stehen einfache Ausdrücke wie Literale.
        • Passend: Zwei Werte werden vertauscht.
        • Unpassend: Die Variablen haben nichts miteinander zu tun, oder rechts stehen längere Ausdrücke. Dann liest sich eine Zuweisung je Zeile besser.

        Das Vertauschen mit einer dritten Variable steht schon in Abschnitt 2.6 des Kurstexts, dort heißt sie k. Dazu gibt es die Seite Unterprogramme und Funktionen, Schritt 1.

        Einfache Anweisungen

        Go fasst fünf Arten von Anweisungen unter dem Namen einfache Anweisung zusammen, englisch simple statement:

        • Kurze Variablendeklaration: zum Beispiel zahl := 20 oder x, y := 1, -1.
        • Zuweisung: zum Beispiel x = 3 * y oder name = "Peter".
        • Inkrementierungs- und Dekrementierungs-Anweisung: zum Beispiel i++ oder alter--.
        • Funktionsaufruf: zum Beispiel f() oder quader(4, 7).
        • Leere Anweisung: nichts, also nur Leerraum.

        Wozu man den Begriff braucht

        An manchen Stellen einer Kontrollfluss-Anweisung erlaubt Go nur eine einfache Anweisung. Kontrollfluss-Anweisungen sind die Anweisungen, die den Ablauf steuern, zum Beispiel if und for.

        Das erste Beispiel im Kurstext ist die for-Anweisung mit for-Klausel aus Abschnitt 5.5.3.2, Seiten 142–146:

        for i := 1; i <= 10; i++ {
    fmt.Println(i)
}
        • Vor dem ersten Semikolon steht die Init-Anweisung, hier i := 1. Sie muss eine einfache Anweisung sein.
        • Hinter dem zweiten Semikolon steht die Post-Anweisung, hier i++. Auch sie muss eine einfache Anweisung sein.

        Dazu gibt es die Seite for-Anweisung mit for-Klausel.
