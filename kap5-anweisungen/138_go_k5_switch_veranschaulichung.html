🔀 switch-Anweisungen in Go

Mehrfachverzweigungen kompakt und übersichtlich

FernUni Hagen - Kurs 01613 - Kurstext v3.0.6, Abschnitt 5.5.2, Seiten 133–137

🎯 Was ist eine switch-Anweisung?

Die switch-Anweisung (switch statement) ist eine alternative Art der Kontrollfluss-Anweisung für Mehrfachverzweigungen. Sie ermöglicht es, einen Wert mit mehreren möglichen Werten zu vergleichen und entsprechend zu reagieren.

💡 Hauptvorteil:

Switch-Anweisungen sind kompakter und übersichtlicher als lange if-else-Ketten, besonders wenn ein Wert mit vielen möglichen Fällen verglichen werden soll.

Wann switch statt if-else verwenden?

  • ✅ Wenn ein Wert mit mehreren konstanten Werten verglichen wird
  • ✅ Wenn viele Gleichheits-Vergleiche (==) durchgeführt werden
  • ✅ Wenn die Lesbarkeit durch kompakte Syntax verbessert wird
  • ✅ Wenn ein Funktionsaufruf nur einmal ausgewertet werden soll

📝 Syntaktische Struktur

switch ausdruck { case wert1: // Anweisungen für wert1 case wert2, wert3: // Anweisungen für wert2 ODER wert3 default: // Anweisungen falls kein case zutrifft }

Komponenten

Element Beschreibung Pflicht?
switch Schlüsselwort ✓ Ja
switch-Ausdruck Wert, der verglichen wird (kann weggelassen werden → tagless switch) ○ Optional
case Schlüsselwort für jeden Fall ✓ Min. 1
case-Ausdruck Wert(e) zum Vergleichen (durch Komma getrennt) ✓ Ja
: Doppelpunkt nach case-Ausdruck ✓ Ja
Anweisungsteil Code, der ausgeführt wird ✓ Ja
default Wird ausgeführt, wenn kein case zutrifft ○ Optional

🗓️ Beispiel: Wochentags-Zuordnung

Das Beispiel aus dem Kurstext zeigt, wie eine Zahl einem Wochentag zugeordnet wird.

Quelle: Das Programm ist Listing 5.3 switch_wochentag.go aus dem Kurstext „Imperative Programmierung“ (Kurs 01613) der FernUniversität in Hagen, Abschnitt 5.5.2.

var num int var text string fmt.Scan(&num) switch num { case 1: text = "Montag" case 2: text = "Dienstag" case 3: text = "Mittwoch" case 4: text = "Donnerstag" case 5: text = "Freitag" case 6, 7: text = "Wochenende" default: text = "unbekannt" } fmt.Println(num, "ist", text, "zugeordnet.")

Ablauf der Ausführung

  1. switch-Ausdruck auswerten: Der Wert von num wird ermittelt
  2. Vergleich von oben nach unten: Jeder case-Ausdruck wird der Reihe nach geprüft
  3. Erste Übereinstimmung: Sobald ein case zutrifft, wird sein Anweisungsteil ausgeführt
  4. Beenden: Nach Ausführung eines case wird die switch-Anweisung beendet
  5. default: Wenn kein case zutrifft und default existiert, wird dieser ausgeführt

✅ Wichtig:

Genau ein Zweig wird ausgeführt! Es gibt kein Fallthrough wie in Java/C++ - die Ausführung stoppt automatisch nach dem ersten zutreffenden case.

📋 Mehrere Werte in einem case

Ein case kann mehrere Werte enthalten, die durch Kommas getrennt werden:

case 6, 7: text = "Wochenende"

💡 Bedeutung:

Dieser case trifft zu, wenn num entweder 6 ODER 7 ist. Die Komma-Trennung entspricht einem logischen ODER (||).

Beispiele mit mehreren Werten

switch note { case 1, 2: fmt.Println("Sehr gut oder gut") case 3, 4: fmt.Println("Befriedigend oder ausreichend") case 5, 6: fmt.Println("Mangelhaft oder ungenügend") }

⚖️ switch vs. if-else Vergleich

Beide Varianten erreichen das gleiche Ergebnis, aber switch ist kompakter:

switch num { case 1: text = "Montag" case 2: text = "Dienstag" case 3: text = "Mittwoch" case 6, 7: text = "Wochenende" default: text = "unbekannt" }

Vorteile:

  • ✅ Kompakter und übersichtlicher
  • ✅ num == muss nicht wiederholt werden
  • ✅ Mehrere Werte einfach: case 6, 7:
  • ✅ num wird nur einmal ausgewertet
if num == 1 { text = "Montag" } else if num == 2 { text = "Dienstag" } else if num == 3 { text = "Mittwoch" } else if num == 6 || num == 7 { text = "Wochenende" } else { text = "unbekannt" }

Nachteile:

  • ⚠️ Länger und weniger übersichtlich
  • ⚠️ num == muss in jedem Zweig wiederholt werden
  • ⚠️ Mehrere Werte: num == 6 || num == 7 umständlich

🏷️ Tagless switch (ohne switch-Ausdruck)

Der switch-Ausdruck kann weggelassen werden. In diesem Fall wird implizit true als switch-Ausdruck verwendet:

switch { case x < 0: fmt.Println("x ist negativ") case x > 0: fmt.Println("x ist positiv") default: fmt.Println("x ist Null") }

📌 Funktionsweise:

  • switch { ... } entspricht switch true { ... }
  • Jeder case-Ausdruck muss vom Typ bool sein
  • Der erste case-Ausdruck, der true ergibt, wird ausgeführt

Anwendungsfall: Bereichsprüfungen

switch { case temperatur < 0: fmt.Println("Frostig") case temperatur < 15: fmt.Println("Kühl") case temperatur < 25: fmt.Println("Angenehm") default: fmt.Println("Warm") }

✅ Vorteil:

Ideal für Mehrfachverzweigungen mit unterschiedlichen booleschen Bedingungen (nicht nur Gleichheit).

⚡ Effizienz: Funktionsaufruf nur einmal

Ein wichtiger Vorteil von switch: Der switch-Ausdruck wird nur einmal ausgewertet:

Vergleich bei Funktionsaufruf f()

❌ Ineffizient: if-else

if f() == -1 { // ... } else if f() == 1 { // f() erneut aufgerufen! // ... }

Problem: f() wird bei jedem else if erneut ausgeführt!

✅ Effizient: switch

switch f() { case -1: // ... case 1: // f() nicht erneut aufgerufen // ... }

Vorteil: f() wird nur einmal ausgeführt, Wert wird intern gespeichert!

⚠️ Wichtig bei Funktionen mit:

  • Seiteneffekten: Mehrfacher Aufruf kann unerwünscht sein
  • Wechselnden Rückgabewerten: Verschiedene Ergebnisse bei jedem Aufruf
  • Performance: Teure Berechnungen nicht wiederholen

🌍 Unterschiede zu anderen Sprachen

1. Kein Fallthrough in Go (Vorteil!)

Java/C++ (Fallthrough)

switch (x) { case 1: System.out.println("Eins"); // FEHLT break! case 2: System.out.println("Zwei"); }

Problem: Bei x=1 wird BEIDES ausgegeben: "Eins" und "Zwei" (fallthrough)

Go (Kein Fallthrough)

switch x { case 1: fmt.Println("Eins") // Automatischer Abbruch! case 2: fmt.Println("Zwei") }

Vorteil: Bei x=1 nur "Eins" - automatischer Stop nach jedem case!

🚨 Fehlerquelle in Java/C++:

Vergessenes break führt zu unbeabsichtigtem fallthrough - ein häufiger Bug! Go vermeidet dies durch automatischen Abbruch.

2. Typ-Flexibilität

Sprache Erlaubte Typen für switch-Ausdruck
Go Beliebige Typen (int, string, bool, float, etc.)
Java (alt) Nur primitive Typen (int, char) und Enums
C++ Nur ganzzahlige Typen und Enums
C Nur ganzzahlige Typen (int, char)

3. case-Ausdrücke

Go (Flexibel)

switch x { case y + 1: // Ausdruck OK case f(): // Funktionsaufruf OK case 1, 2, 3: // Mehrere Werte OK }

C/C++ (Eingeschränkt)

switch (x) { case 1: // Nur Konstanten! case 2: // case y+1: FEHLER! }

✅ Best Practices

✓ Empfohlen

  • switch für Gleichheits-Vergleiche verwenden
  • default-case hinzufügen (wenn sinnvoll)
  • Mehrere Werte mit Komma trennen
  • tagless switch für boolesche Bedingungen
  • switch bei Funktionsaufrufen (Effizienz)
  • Übersichtliche case-Anordnung

✗ Vermeiden

  • Sehr verschachtelte switch-Anweisungen
  • Zu viele cases (> 15-20)
  • Komplexe Logik im case-Ausdruck
  • switch wenn if-else klarer wäre
  • Leere case-Abschnitte ohne Kommentar
