🔄 Quiz: for-Anweisung mit for-Klausel

Teste dein Wissen über for-Schleifen in Go!

1. Aus wie vielen Komponenten besteht die for-Klausel?

  • Aus zwei Komponenten
  • Aus drei Komponenten, die durch Semikolons getrennt sind
  • Aus vier Komponenten
  • Aus einer einzigen Komponente

2. Wie heißen die drei Komponenten der for-Klausel?

  • Start-Anweisung, Loop-Bedingung, End-Anweisung
  • Init-Anweisung, Schleifenbedingung, Post-Anweisung
  • Begin-Statement, Condition, After-Statement
  • Deklaration, Prüfung, Inkrement

3. Wann wird die Init-Anweisung ausgeführt?

  • Genau einmal zu Beginn der for-Anweisung, bevor die Schleifenbedingung zum ersten Mal ausgewertet wird
  • Vor jedem Schleifendurchlauf
  • Nach jedem Schleifendurchlauf
  • Am Ende der Schleife

4. Wann wird die Post-Anweisung ausgeführt?

  • Vor jedem Schleifendurchlauf
  • Vor der Prüfung der Schleifenbedingung
  • Immer erst nach der Ausführung des Schleifenrumpfes, nach Abschluss eines Schleifendurchlaufs
  • Gleichzeitig mit der Init-Anweisung

5. Was ist eine Laufvariable?

  • Eine globale Variable, die in allen Schleifen verwendet wird
  • Eine lokale Variable der Schleife, die in der Init-Anweisung deklariert wird und deren Gültigkeitsbereich sich über die gesamte for-Anweisung erstreckt
  • Eine Variable, die nur im Schleifenrumpf gültig ist
  • Eine Variable, die nach der Schleife weiterhin verwendbar ist

6. Was passiert mit einer Laufvariablen nach Beendigung der Schleife?

for i := 0; i < 10; i++ { fmt.Println(i) } fmt.Println(i) // Was passiert hier?
  • Die Variable behält ihren letzten Wert und kann verwendet werden
  • Die Variable existiert nicht mehr - es gibt einen Compiler-Fehler
  • Die Variable wird auf 0 zurückgesetzt
  • Die Variable wird automatisch als globale Variable verfügbar

7. Welche Bezeichner sind typisch für Laufvariablen?

  • counter, index, loopVar
  • i, j, k (einzelne Buchstaben)
  • var1, var2, var3
  • x, y, z

8. Warum sind kurze Namen wie 'i' für Laufvariablen akzeptabel?

  • Weil Go nur kurze Variablennamen erlaubt
  • Weil der Gültigkeitsbereich sehr beschränkt ist - je lokaler der Scope, desto kürzer darf der Name sein
  • Weil lange Namen zu langsamen Code führen
  • Aus historischen Gründen - es ist nur eine Konvention ohne praktischen Nutzen

9. Welche Aussage über die Init-Anweisung ist korrekt?

  • Es dürfen keine Variablen deklariert werden
  • Es können mittels kurzer Variablendeklaration auch mehrere Variablen gleichzeitig deklariert werden (z.B. i, j := 0, 100)
  • Es muss immer genau eine Variable deklariert werden
  • Es dürfen nur bereits existierende Variablen zugewiesen werden

10. Welche Anweisung ist in der Post-Anweisung NICHT erlaubt?

  • i++
  • i += 2
  • i, j = i+1, j-5 (Tupel-Zuweisung)
  • k := 5 (kurze Variablendeklaration)

11. Was passiert, wenn man Init- und Post-Anweisung weglässt?

for i <= 10 { fmt.Println(i) i++ }
  • Das ist ein Syntaxfehler
  • Man erhält eine for-Anweisung mit Bedingung (entspricht einer while-Schleife in anderen Sprachen)
  • Die Schleife läuft unendlich
  • Die Schleife wird nie ausgeführt

12. Was bedeutet diese Syntax?

for { // Code hier }
  • Eine Schleife, die nie ausgeführt wird
  • Eine Endlosschleife (implizite Bedingung: true)
  • Eine Schleife mit Syntaxfehler
  • Eine Schleife, die genau einmal ausgeführt wird

13. Wie endet diese Schleife?

for i, j := 0, 100; i < j; i, j = i+1, j-5 { fmt.Println("i, j:", i, j) }
  • i, j: 19 5
  • i, j: 16 20
  • i, j: 20 0
  • i, j: 15 25

14. Was ist der Hauptvorteil der for-Klausel gegenüber der for-Anweisung mit Bedingung?

  • Sie ist schneller in der Ausführung
  • Sie fasst alle wichtigen Elemente (Initialisierung, Bedingung, Veränderung) kompakt in einer Zeile zusammen und ist idiomatischer
  • Sie erlaubt komplexere Bedingungen
  • Sie benötigt weniger Speicher
