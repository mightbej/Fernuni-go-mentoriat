📋 Aufgabenstellung

Entwickle ein Zahlenraten-Spiel mit folgenden Funktionalitäten:

Spielablauf:
  • Das Programm wählt eine Zufallszahl zwischen 1 und 100
  • Der Spieler hat maximal 7 Versuche zum Raten
  • Nach jedem Versuch gibt das Programm Hinweise: "zu groß", "zu klein" oder "richtig"
  • Bei richtiger Zahl: Glückwunsch mit Anzahl der Versuche
  • Nach dem Spiel: Frage, ob nochmal spielen
Statistik-Funktion:
  • Zähle gewonnene und verlorene Spiele
  • Berechne die durchschnittliche Anzahl der Versuche bei Gewinn
  • Kategorisiere die Leistung basierend auf dem Durchschnitt
  • Zeige Statistik am Ende jedes Spiels an
⚠️ Wichtig: Wir verwenden keine Funktionen, da diese erst später im Kurs behandelt werden. Der gesamte Code steht in der main() Funktion!

🏗️ Grundgerüst des Programms

Zuerst legen wir das Grundgerüst mit Package-Deklaration, Imports und der main-Funktion an:

package main import ( "fmt" "math/rand" "time" ) func main() { // Hier kommt der Hauptprogrammcode }
💡 Tipp: Der Import von math/rand wird für Zufallszahlen benötigt, time für die Initialisierung des Zufallsgenerators, und fmt für Ein-/Ausgabe.

Benötigte Pakete:

  • fmt - für formatierte Ausgabe und Eingabe (Kapitel 3.3.7, 4.2)
  • math/rand - für Zufallszahlen generieren
  • time - für Seed des Zufallsgenerators

📐 Programmstrukturierung (verbal)

Bevor wir Code schreiben, überlegen wir uns die Struktur:

1. Globale Konstanten definieren
  • MAX_VERSUCHE: Maximale Anzahl Rateversuche (7)
  • MIN_ZAHL: Untere Grenze des Zahlenbereichs (1)
  • MAX_ZAHL: Obere Grenze des Zahlenbereichs (100)
2. Globale Variablen für Statistik
  • anzahlSiege: Zähler für gewonnene Spiele
  • anzahlNiederlagen: Zähler für verlorene Spiele
  • gesamtVersuche: Summe aller Versuche bei Siegen
3. Hauptprogramm in main()
  • Initialisiere Zufallsgenerator
  • Zeige Begrüßung
  • Äußere Schleife: Wiederhole Spiele
    • Generiere Zufallszahl
    • Innere Schleife: Rateversuche (max. 7)
      • Lies Eingabe
      • Vergleiche mit Zielzahl (if-else)
      • Bei Treffer: break aus Schleife
    • Aktualisiere Statistik
    • Zeige Statistik mit switch-Kategorisierung
    • Frage "Nochmal?" - bei Nein: break
  • Verabschiedung
💡 Konzepte: Wir verwenden verschachtelte Schleifen (Kapitel 5.5.3) - die äußere für mehrere Spiele, die innere für Rateversuche.

📦 Konstanten & Globale Variablen definieren

💡 Kapitel 5.1.3: Globale Variablen werden außerhalb von Funktionen deklariert und sind im gesamten Programm sichtbar.
package main import ( "fmt" "math/rand" "time" ) // Konstanten für Spielparameter (Kapitel 5.2) const ( MAX_VERSUCHE = 7 MIN_ZAHL = 1 MAX_ZAHL = 100 ) // Globale Variablen für Spielstatistik (Kapitel 5.1.3) var ( anzahlSiege int anzahlNiederlagen int gesamtVersuche int ) func main() { // Hauptprogramm folgt... }

Erklärung der Konstanten (Kapitel 5.2):

  • MAX_VERSUCHE = 7: Maximale Anzahl Rateversuche pro Runde
  • MIN_ZAHL = 1: Untere Grenze des Zahlenbereichs
  • MAX_ZAHL = 100: Obere Grenze des Zahlenbereichs

Erklärung der globalen Variablen (Kapitel 5.1.3):

  • anzahlSiege: Zählt gewonnene Spiele (initialisiert mit 0)
  • anzahlNiederlagen: Zählt verlorene Spiele (initialisiert mit 0)
  • gesamtVersuche: Summe aller Versuche bei gewonnenen Spielen
⚠️ Warum global? Diese Variablen müssen über mehrere Spielrunden hinweg bestehen bleiben, daher werden sie global (außerhalb von main) deklariert.

🎲 Zufallszahl-Initialisierung & Begrüßung

Der Beginn der main()-Funktion:

func main() { // Zufallsgenerator initialisieren mit aktuellem Zeitstempel rand.Seed(time.Now().UnixNano()) // Begrüßung und Spielregeln fmt.Println("🎯 Willkommen beim Zahlenraten-Spiel!") fmt.Printf("Rate eine Zahl zwischen %d und %d.\n", MIN_ZAHL, MAX_ZAHL) fmt.Printf("Du hast %d Versuche pro Runde.\n\n", MAX_VERSUCHE) // Hier folgt die Hauptspielschleife... }
💡 Kapitel 3.3.7: fmt.Printf ermöglicht formatierte Ausgabe. %d wird durch Integer-Werte ersetzt.

Erklärung:

  • rand.Seed(...): Initialisiert den Zufallsgenerator mit der aktuellen Zeit, damit bei jedem Programmstart andere Zufallszahlen erzeugt werden
  • fmt.Println: Gibt Text mit Zeilenumbruch aus
  • fmt.Printf: Formatierte Ausgabe mit Platzhaltern (%d für int-Werte)

🔄 Innere Schleife: Rateversuche

Jetzt kommt die Kernlogik - die Schleife für die Rateversuche:

📍 Einordnung im Programm: Dieser Code steht innerhalb der äußeren for { ... }-Schleife aus Schritt 8 – einmal pro Spielrunde. Die äußere Schleife bauen wir erst in Schritt 8 ein; hier fokussieren wir uns auf die Rateversuche.
// Generiere Zufallszahl für diese Runde zielZahl := rand.Intn(MAX_ZAHL-MIN_ZAHL+1) + MIN_ZAHL // Lokale Variablen für diese Runde (Kapitel 5.1.3) versuchsZaehler := 0 gewonnen := false // For-Schleife mit Bedingung (Kapitel 5.5.3.1) for versuchsZaehler < MAX_VERSUCHE { versuchsZaehler++ // Inkrement (Kapitel 5.3.1) // Eingabe der geratenen Zahl fmt.Printf("Versuch %d/%d - Deine Zahl: ", versuchsZaehler, MAX_VERSUCHE) var geratenZahl int fmt.Scan(&geratenZahl) // If-else-if Kette zur Prüfung (Kapitel 5.5.1) if geratenZahl == zielZahl { fmt.Printf("🎉 Richtig! Die Zahl war %d!\n", zielZahl) fmt.Printf("Du hast %d Versuche gebraucht.\n", versuchsZaehler) // Statistik aktualisieren (Kapitel 5.3) anzahlSiege++ gesamtVersuche += versuchsZaehler gewonnen = true break // Verlasse Schleife (Kapitel 5.5.3.3) } else if geratenZahl < zielZahl { fmt.Println("📈 Zu klein! Versuche eine größere Zahl.") } else { fmt.Println("📉 Zu groß! Versuche eine kleinere Zahl.") } } // Falls nicht gewonnen if !gewonnen { fmt.Printf("😞 Leider verloren! Die Zahl war %d.\n", zielZahl) anzahlNiederlagen++ }

📊 Statistik-Ausgabe mit Switch

Nach jeder Runde zeigen wir die Statistik mit Kategorisierung:

📍 Einordnung im Programm: Auch dieser Block gehört in die äußere for { ... }-Schleife – direkt nach der Rateschleife aus Schritt 6, noch vor der Frage „Nochmal spielen?“ aus Schritt 8.
// Statistik-Ausgabe gesamtSpiele := anzahlSiege + anzahlNiederlagen fmt.Println("\n╔════════════════════════════╗") fmt.Println("║ 📊 STATISTIK 📊 ║") fmt.Println("╚════════════════════════════╝") fmt.Printf("Gesamt gespielt: %d\n", gesamtSpiele) fmt.Printf("Gewonnen: %d\n", anzahlSiege) fmt.Printf("Verloren: %d\n", anzahlNiederlagen) // Berechne Durchschnitt nur wenn Siege vorhanden (Kapitel 4.7) if anzahlSiege > 0 { durchschnitt := float64(gesamtVersuche) / float64(anzahlSiege) fmt.Printf("Durchschn. Versuche: %.2f\n", durchschnitt) // Switch-Anweisung für Kategorisierung (Kapitel 5.5.2) var kategorie string switch { case durchschnitt <= 3.0: kategorie = "🏆 Meister - Hervorragend!" case durchschnitt <= 4.0: kategorie = "⭐ Experte - Sehr gut!" case durchschnitt <= 5.5: kategorie = "👍 Fortgeschritten - Gut gemacht!" default: kategorie = "🌱 Anfänger - Weiter üben!" } fmt.Printf("Kategorie: %s\n", kategorie) } else { fmt.Println("Noch keine Siege!") }
💡 Kapitel 4.7: Typkonvertierung von int zu float64 mit float64(...) für die Durchschnittsberechnung.
💡 Kapitel 5.5.2: Switch ohne Ausdruck ermöglicht boolesche Bedingungen in den case-Klauseln.

Kategorien-Grenzen:

  • ≤ 3.0: 🏆 Meister
  • ≤ 4.0: ⭐ Experte
  • ≤ 5.5: 👍 Fortgeschritten
  • > 5.5: 🌱 Anfänger

🔁 Äußere Schleife: Wiederholung & Abschluss

Damit all diese Teile zusammen funktionieren, umschließen wir sie mit einer Endlosschleife:

func main() { rand.Seed(time.Now().UnixNano()) fmt.Println("🎯 Willkommen beim Zahlenraten-Spiel!") fmt.Printf("Rate eine Zahl zwischen %d und %d.\n", MIN_ZAHL, MAX_ZAHL) fmt.Printf("Du hast %d Versuche pro Runde.\n\n", MAX_VERSUCHE) // Endlosschleife für mehrere Spielrunden (Kapitel 5.5.3) for { // [Hier steht die Rateschleife von Schritt 6] // [Hier steht die Statistik von Schritt 7] // Frage nach erneutem Spiel fmt.Print("\nNochmal spielen? (j/n): ") var antwort string fmt.Scan(&antwort) // If mit logischem ODER (Kapitel 4.5) if antwort == "n" || antwort == "N" { break // Verlasse die Endlosschleife (Kapitel 5.5.3.3) } fmt.Println("\n--- Neue Runde ---\n") } fmt.Println("\n👋 Vielen Dank fürs Spielen! Bis zum nächsten Mal!") }
💡 Kapitel 5.5.3: for ohne Bedingung erzeugt eine Endlosschleife, die nur durch break verlassen werden kann.
💡 Kapitel 4.5: Der logische ODER-Operator || verknüpft zwei boolesche Ausdrücke. Wenn einer wahr ist, ist das Ergebnis wahr.

Ablauf der Schleifen:

  1. Äußere for-Schleife: Wiederholt Spielrunden, bis Spieler "n" eingibt
  2. Innere for-Schleife: Wiederholt Rateversuche, max. 7 Mal oder bis richtig geraten
  3. Break-Anweisungen:
    • Innere Schleife: Bei richtigem Raten
    • Äußere Schleife: Bei Eingabe "n" oder "N"

✅ Vollständiger lauffähiger Code

🎉 Das komplette Programm!
Kopiere diesen Code in eine .go Datei und führe ihn mit go run dateiname.go aus.
package main import ( "fmt" "math/rand" "time" ) // Konstanten für Spielparameter const ( MAX_VERSUCHE = 7 MIN_ZAHL = 1 MAX_ZAHL = 100 ) // Globale Variablen für Spielstatistik var ( anzahlSiege int anzahlNiederlagen int gesamtVersuche int ) func main() { // Zufallsgenerator initialisieren rand.Seed(time.Now().UnixNano()) fmt.Println("🎯 Willkommen beim Zahlenraten-Spiel!") fmt.Printf("Rate eine Zahl zwischen %d und %d.\n", MIN_ZAHL, MAX_ZAHL) fmt.Printf("Du hast %d Versuche pro Runde.\n\n", MAX_VERSUCHE) // Hauptschleife für mehrere Spielrunden for { // Generiere Zufallszahl für diese Runde zielZahl := rand.Intn(MAX_ZAHL-MIN_ZAHL+1) + MIN_ZAHL // Lokale Variablen für diese Runde versuchsZaehler := 0 gewonnen := false // Schleife für die Rateversuche for versuchsZaehler < MAX_VERSUCHE { versuchsZaehler++ // Eingabe der geratenen Zahl fmt.Printf("Versuch %d/%d - Deine Zahl: ", versuchsZaehler, MAX_VERSUCHE) var geratenZahl int fmt.Scan(&geratenZahl) // Prüfe die geratene Zahl if geratenZahl == zielZahl { fmt.Printf("🎉 Richtig! Die Zahl war %d!\n", zielZahl) fmt.Printf("Du hast %d Versuche gebraucht.\n", versuchsZaehler) // Aktualisiere Statistik anzahlSiege++ gesamtVersuche += versuchsZaehler gewonnen = true break } else if geratenZahl < zielZahl { fmt.Println("📈 Zu klein! Versuche eine größere Zahl.") } else { fmt.Println("📉 Zu groß! Versuche eine kleinere Zahl.") } } // Falls nicht gewonnen: Statistik aktualisieren if !gewonnen { fmt.Printf("😞 Leider verloren! Die Zahl war %d.\n", zielZahl) anzahlNiederlagen++ } // Statistik-Ausgabe gesamtSpiele := anzahlSiege + anzahlNiederlagen fmt.Println("\n╔════════════════════════════╗") fmt.Println("║ 📊 STATISTIK 📊 ║") fmt.Println("╚════════════════════════════╝") fmt.Printf("Gesamt gespielt: %d\n", gesamtSpiele) fmt.Printf("Gewonnen: %d\n", anzahlSiege) fmt.Printf("Verloren: %d\n", anzahlNiederlagen) // Berechne Durchschnitt nur wenn Siege vorhanden if anzahlSiege > 0 { durchschnitt := float64(gesamtVersuche) / float64(anzahlSiege) fmt.Printf("Durchschn. Versuche: %.2f\n", durchschnitt) // Kategorisierung mit Switch var kategorie string switch { case durchschnitt <= 3.0: kategorie = "🏆 Meister - Hervorragend!" case durchschnitt <= 4.0: kategorie = "⭐ Experte - Sehr gut!" case durchschnitt <= 5.5: kategorie = "👍 Fortgeschritten - Gut gemacht!" default: kategorie = "🌱 Anfänger - Weiter üben!" } fmt.Printf("Kategorie: %s\n", kategorie) } else { fmt.Println("Noch keine Siege!") } // Frage nach erneutem Spiel fmt.Print("\nNochmal spielen? (j/n): ") var antwort string fmt.Scan(&antwort) // Beende Schleife bei 'n' oder 'N' if antwort == "n" || antwort == "N" { break } fmt.Println("\n--- Neue Runde ---\n") } fmt.Println("\n👋 Vielen Dank fürs Spielen! Bis zum nächsten Mal!") }

Siege_Zähler, Niederlagen_Zähler, Erfolgs_Versuche_Summe var (anzahlSiege, anzahlNiederlagen, gesamtVersuche) auf Package-Ebene

Rate-Schleife (max. Versuche) for versuchsZaehler < MAX_VERSUCHE { ... break }
Tipp vergleichen (zu klein / zu groß / richtig) if / else if / else-Kette
Bewertungs-Engine (Schwellenwerte) Tagloser switch { case ... }

📖 Kapitel 5.1 - Deklaration von Variablen:
  • 5.1.1 Ausführliche Deklaration: var antwort string, var geratenZahl int
  • 5.1.2 Kurze Deklaration: zielZahl := rand.Intn(...), versuchsZaehler := 0
  • 5.1.3 Lokale Variablen: innerhalb von main() deklariert
  • 5.1.3 Globale Variablen: anzahlSiege, anzahlNiederlagen, gesamtVersuche
📖 Kapitel 5.2 - Deklaration von Konstanten:
  • MAX_VERSUCHE, MIN_ZAHL, MAX_ZAHL
  • Verwendung in Berechnungen und formatierten Ausgaben
📖 Kapitel 5.3 - Zuweisungen:
  • 5.3 Einfache Zuweisung: gewonnen = true
  • 5.3.1 Inkrement: anzahlSiege++, versuchsZaehler++
  • Zusammengesetzte Zuweisung: gesamtVersuche += versuchsZaehler
📖 Kapitel 5.5.1 - If-Anweisungen:
  • Einfache if: if anzahlSiege > 0
  • If mit Negation: if !gewonnen
  • If-else-if-Kette: Vergleich der geratenen Zahl
  • Logischer ODER-Operator: if antwort == "n" || antwort == "N"
📖 Kapitel 5.5.2 - Switch-Anweisungen:
  • Switch ohne Ausdruck mit booleschen Bedingungen
  • Verschiedene case-Fälle mit Vergleichsoperatoren (<=)
  • Default-Fall als Auffangvariante
📖 Kapitel 5.5.3 - Schleifen:
  • 5.5.3.1 For mit Bedingung: for versuchsZaehler < MAX_VERSUCHE
  • 5.5.3 Endlosschleife: for ohne Bedingung in der Hauptschleife
  • 5.5.3.3 Break-Anweisung:
    • Verlassen der Rateschleife bei richtigem Ergebnis
    • Verlassen der Hauptschleife bei "n"
📖 Kapitel 4.7 - Typkonvertierung:
  • float64(gesamtVersuche) und float64(anzahlSiege)
  • Notwendig für genaue Durchschnittsberechnung
📖 Kapitel 3.3.7 & 4.2 - Ein-/Ausgabe:
  • fmt.Println: Einfache Textausgabe
  • fmt.Printf: Formatierte Ausgabe mit Platzhaltern (%d, %.2f, %s)
  • fmt.Scan: Eingabe von Werten
