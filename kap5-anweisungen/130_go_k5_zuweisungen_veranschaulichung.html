🎯 Grundlegende Zuweisung

Die einfachste Form der Zuweisung verwendet den Zuweisungsoperator =

x = 10 // Einfache Zuweisung name = "Peter" // Zuweisung eines Strings y = x * 2 // Zuweisung mit Berechnung

💡 Grundprinzip:

Der Ausdruck auf der rechten Seite wird ausgewertet und das Ergebnis wird der Variablen auf der linken Seite zugewiesen.

⚡ Wichtig: Deklaration vs. Zuweisung

In Go gibt es zwei verschiedene Operatoren, die leicht verwechselt werden können:

:= (Deklaration mit Initialisierung)

x := 10 // Variable erstellen
  • Erstellt eine neue Variable
  • Typ wird automatisch abgeleitet
  • Nur für lokale Variablen
  • Variable darf noch nicht existieren

= (Zuweisung)

x = 20 // Wert ändern
  • Ändert eine bestehende Variable
  • Variable muss bereits existieren
  • Typ muss kompatibel sein
  • Thema dieses Kapitels

⚠️ Typische Fehler:

x := 10 x := 20 // ❌ Fehler: x wurde bereits deklariert!

Man kann eine Variable nicht zweimal mit := deklarieren!

✅ Richtig:

x := 10 // Deklaration mit Initialisierung x = 20 // Zuweisung eines neuen Werts

Erst deklarieren mit :=, dann zuweisen mit =

📖 Im Rest dieses Kapitels:

Wir konzentrieren uns auf Zuweisungen (= und Varianten wie +=, *=, etc.) für bereits existierende Variablen. Die Deklaration mit := wurde in früheren Kapiteln behandelt.

🔀 Kombinierte Zuweisungsoperatoren

Häufig wird einer Variablen ein neuer Wert zugewiesen, der sich aus einer Operation mit dem alten Wert ergibt. Go bietet dafür kompakte Operatoren:

Lange vs. Kurze Schreibweise

Multiplikations-Zuweisung (*=)

Lange Form

x = x * 8

Kurze Form

x *= 8

Der Operator *= multipliziert die Variable mit dem rechten Wert und weist das Ergebnis wieder der Variablen zu.

Divisions-Zuweisung (/=)

Lange Form

x = x / 4

Kurze Form

x /= 4

Der Operator /= dividiert die Variable durch den rechten Wert.

Modulo-Zuweisung (%=)

Lange Form

x = x % 3

Kurze Form

x %= 3

Der Operator %= berechnet den Rest der Division und weist ihn zu.

Additions-Zuweisung (+=)

Lange Form

y = y + 5

Kurze Form

y += 5

Der Operator += addiert den rechten Wert zur Variablen hinzu.

Subtraktions-Zuweisung (-=)

Lange Form

z = z - (2 + 3)

Kurze Form

z -= 2 + 3

Der Operator -= subtrahiert den rechten Wert von der Variablen.

⬆️⬇️ Inkrement und Dekrement

Die häufigste Operation ist das Erhöhen oder Verringern einer Variablen um 1. Dafür gibt es spezielle Anweisungen:

Inkrementierung (++)

x++ // x = x + 1

Erhöht den Wert der Variablen um 1

Äquivalent zu:
x += 1 oder x = x + 1

Dekrementierung (--)

y-- // y = y - 1

Verringert den Wert der Variablen um 1

Äquivalent zu:
y -= 1 oder y = y - 1

⚠️ Wichtig: Anweisung vs. Ausdruck

In Go sind ++ und -- Anweisungen, keine Ausdrücke!

  • ✅ Erlaubt: x++ (als eigenständige Anweisung)
  • ❌ Nicht erlaubt: y = x++ (kann nicht in Ausdruck verwendet werden)
  • ❌ Nicht erlaubt: y = 5 + x++

🌍 Sprachvergleich

In Sprachen wie Java oder C++ gibt es zusätzlich:

  • Post-Increment: x++ (erst Wert verwenden, dann erhöhen)
  • Pre-Increment: ++x (erst erhöhen, dann Wert verwenden)

In Go existiert nur Post-Increment/Decrement als Anweisung, nicht als Ausdruck!

📦 Tupel-Zuweisung

In Go können mehrere Variablen gleichzeitig Werte zugewiesen bekommen:

Grundprinzip

x, y, z = 22, 33, 44 // Gleichzeitige Zuweisung

🔄 Zwei-Schritt-Prozess:

  1. Schritt 1: Alle Ausdrücke auf der rechten Seite werden ausgewertet
  2. Schritt 2: Die Werte werden den Variablen auf der linken Seite zugewiesen

Praktischer Nutzen: Werte vertauschen

Die Tupel-Zuweisung ermöglicht das Vertauschen von Werten ohne Hilfsvariable:

Mit Tupel-Zuweisung ✨

a, b = b, a // Werte tauschen
Vorteile:
  • ✅ Nur eine Anweisung
  • ✅ Keine Hilfsvariable nötig
  • ✅ Elegant und übersichtlich

Ohne Tupel-Zuweisung 📝

tmp := a // Hilfsvariable a = b b = tmp
Nachteile:
  • ❌ Drei Anweisungen nötig
  • ❌ Hilfsvariable erforderlich
  • ❌ Umständlicher

Wann Tupel-Zuweisungen verwenden?

Situation Empfehlung
Variablen stehen in engem Zusammenhang (z.B. x-y-z-Koordinaten) ✓ Verwenden
Einfache Werte (Literale oder Variablen) ✓ Verwenden
Vertauschen von Werten ✓ Verwenden
Keine Beziehung zwischen Variablen ✗ Vermeiden
Komplexe Ausdrücke auf rechter Seite ✗ Vermeiden

📋 Einfache Anweisungen (Simple Statements)

In Go werden bestimmte Anweisungen als "simple statements" (einfache Anweisungen) bezeichnet. Diese dürfen an speziellen Stellen in Kontrollfluss-Anweisungen stehen.

Was sind Simple Statements?

1. Kurze Variablendeklarationen

zahl := 20 x, y := 1, -1

2. Zuweisungen

x = 3 * y name = "Peter"

3. Inkrement/Dekrement

i++ alter--

4. Funktionsaufrufe

f() quader(4, 7)

5. Leere Anweisung

Tatsächlich "nichts" bzw. Leerraum (whitespace)

📌 Wo werden Simple Statements verwendet?

Simple Statements werden in speziellen Positionen von Kontrollfluss-Anweisungen verwendet, z.B.:

  • In for-Schleifen (Initialisierung, Post-Statement)
  • In if-Anweisungen (optionale Initialisierung vor Bedingung)
  • In switch-Anweisungen

Details dazu werden in späteren Kapiteln behandelt.

⛔ Kettenzuweisungen - Nicht möglich in Go!

In vielen Programmiersprachen (Java, C++, Python, JavaScript) kann man mehrere Variablen in einer Zeile den gleichen Wert zuweisen. In Go ist das nicht möglich!

❌ Funktioniert NICHT in Go

x = y = z = 5 // Compile-Fehler!

Kettenzuweisungen sind in Go nicht erlaubt.

✅ Richtig in Go

x = 5 y = 5 z = 5

Jede Variable muss separat zugewiesen werden.

💡 Alternative: Tupel-Zuweisung

Wenn man mehreren Variablen gleichzeitig denselben Wert zuweisen möchte:

x, y, z = 5, 5, 5 // ✅ Das funktioniert!

Hier werden aber drei separate Werte zugewiesen, nicht eine Kette.

⚠️ Für Umsteiger von anderen Sprachen:

Wenn du von C, Java, JavaScript oder Python kommst: Go erlaubt keine Kettenzuweisungen. Das ist eine bewusste Design-Entscheidung für bessere Lesbarkeit.

🔒 Konstanten können nicht zugewiesen werden

Variablen, die mit const deklariert wurden, sind konstant und können nach der Initialisierung nicht mehr geändert werden.

✅ Erlaubt: Variable

var x int = 10 x = 20 // ✓ OK: Zuweisung möglich x = 30 // ✓ OK: Mehrfach änderbar

Variablen (var) können beliebig oft geändert werden.

❌ Verboten: Konstante

const Pi = 3.14 Pi = 3.14159 // ❌ Fehler! Pi = 3.0 // ❌ Fehler!

Konstanten (const) sind unveränderlich.

🎯 Wann was verwenden?

Situation Verwende
Wert wird sich ändern (Zähler, Summe, Status) var oder :=
Wert bleibt gleich (Pi, Max-Werte, Konfiguration) const

💡 Fehlermeldung:

cannot assign to Pi (declared const)

Diese Fehlermeldung erscheint beim Versuch, eine Konstante zuzuweisen.

🎨 Typ-Kompatibilität bei Zuweisungen

In Go ist Typsicherheit sehr wichtig. Der zugewiesene Wert muss zum Typ der Variablen passen!

⚠️ Wichtige Regel:

Der Typ der rechten Seite muss mit dem Typ der Variablen auf der linken Seite kompatibel sein.

Typische Fehler

❌ String zu int

var x int = 10 x = "20" // ❌ Fehler!

String kann nicht zu int zugewiesen werden.

❌ float zu int

var y int = 5 y = 3.14 // ❌ Fehler!

Fließkommazahl kann nicht zu int zugewiesen werden.

❌ int zu bool

var fertig bool = true fertig = 1 // ❌ Fehler!

In Go ist 1 nicht automatisch true!

❌ bool zu string

var name string = "Peter" name = false // ❌ Fehler!

bool kann nicht zu string zugewiesen werden.

Richtige Zuweisungen

✅ Gleicher Typ

var x int = 10 x = 20 // ✓ int zu int x = 5 + 3 // ✓ Ergebnis ist int

✅ Kompatible Typen

var name string = "Peter" name = "Anna" // ✓ string zu string name = "" // ✓ Leerer String

💡 Typ-Konvertierung:

Wenn man verschiedene Typen zuweisen möchte, muss man explizit konvertieren:

var x int = 10 var y float64 y = float64(x) // ✓ Explizite Konvertierung

Go macht keine automatische Typ-Konvertierung - das ist Absicht für mehr Sicherheit!

✅ Vorteile der strikten Typisierung:

  • Fehler werden beim Kompilieren entdeckt, nicht zur Laufzeit
  • Code ist eindeutiger und leichter zu verstehen
  • Weniger unerwartete Bugs durch implizite Konvertierungen

✅ Best Practices

✓ Empfohlen

  • Kombinierte Operatoren für kürzeren Code verwenden
  • ++ und -- statt += 1 und -= 1
  • Tupel-Zuweisung für zusammenhängende Variablen
  • Tupel-Zuweisung zum Werte-Vertauschen
  • const für unveränderliche Werte
  • var für Werte, die sich ändern

✗ Vermeiden

  • ++ oder -- in Ausdrücken verwenden
  • Kettenzuweisungen (x = y = z = 5) - nicht möglich in Go!
  • Konstanten nach der Deklaration zuweisen
  • Inkompatible Typen zuweisen (z.B. String zu int)
  • Tupel-Zuweisung mit komplexen Ausdrücken
  • Tupel-Zuweisung für unzusammenhängende Variablen
  • Lange Form wenn kurze Form existiert
