if-Anweisung in Go

Mit einer if-Anweisung hängt es von einer Bedingung ab, ob ein Stück des Programms ausgeführt wird. Die Seite zeigt if, else und else if und führt das Schaltjahr-Programm des Kurstexts Zeile für Zeile aus.

Kurstext v3.0.6, Abschnitt 5.5.1, Seiten 129–132.

Worum es geht

Ein Programm führt seine Anweisungen der Reihe nach aus. Eine bedingte Anweisung weicht davon ab: Ein Stück des Programms läuft nur, wenn eine Bedingung erfüllt ist. Ob sie erfüllt ist, entscheidet sich erst, während das Programm läuft.

Beispiel: Die Meldung „Du bist minderjährig.“ soll nur erscheinen, wenn der Wert der Variable alter kleiner als 18 ist.

In Go heißt die bedingte Anweisung if-Anweisung, englisch if-statement.

Was aus früheren Kapiteln dazugehört

  • Abschnitt 2.1, Seiten 5–8, Bedingung und Block: Dort steht die bedingte Anweisung ohne Go, als IF b THEN {…} und mit ELSE. Der Block in geschweiften Klammern ersetzt den Sprung mit GOTO. Dazu gibt es die Seite Imperative Programmierung, Schritt 3.
  • Abschnitt 2.5, Seiten 13–14, das Programm als Bild: Im Flussdiagramm und im Struktogramm ist eine Bedingung eine Stelle, an der sich der Weg teilt. Dazu gibt es die Seite Größter gemeinsamer Teiler.
  • Abschnitt 4.5, Seiten 93–98, der boolesche Ausdruck: Die Bedingung einer if-Anweisung ist ein Ausdruck vom Typ bool. Er hat den Wert true oder false. Beispiel: alter < 18. Dazu gibt es die Seiten Logische Operatoren und Vergleiche in Go und Wahrheitswerte und Kurzschluss-Auswertung.

Die fünf Schritte

  • Schritt 1 zeigt die einfachste Form: if, Bedingung, Block. Dazu kommen die Vorgaben von Go für die Schreibweise.
  • Schritt 2 ergänzt else. Aus der bedingten Anweisung wird eine Verzweigung.
  • Schritt 3 zeigt die Kette mit else if an einem Programm, das aus Punkten eine Note macht.
  • Schritt 4 führt das Schaltjahr-Programm aus Listing 5.2 Zeile für Zeile aus.
  • Schritt 5 enthält Faustregeln des Mentors. Sie gehen über den Kurstext hinaus.

if und Block

Eine if-Anweisung besteht in Go aus drei Teilen:

  • Schlüsselwort: Die Anweisung beginnt mit if.
  • Bedingung: Es folgt ein boolescher Ausdruck, zum Beispiel alter < 18.
  • Block: Es folgen Anweisungen zwischen { und }. Dieser Block heißt if-Zweig.

Der if-Zweig wird nur ausgeführt, wenn die Bedingung true ergibt. Ergibt sie false, überspringt das Programm den if-Zweig und macht hinter } weiter.

    Ein grüner Strich links bedeutet: Die Zeile wird ausgeführt. Eine blasse Zeile wird übersprungen. Hinter der Bedingung steht ihr Wert.

    Was Go bei der Schreibweise verlangt

    Jeder Knopf zeigt eine Schreibweise derselben if-Anweisung. Darunter steht, ob Go sie übersetzt.

    
    
    
      
    
    
    
    

    
    Warum Go den Block erzwingt
    
    
    In Java oder Pascal darf eine einzelne Anweisung ohne Block hinter der Bedingung stehen. Daraus entsteht ein bekannter Fehler:
    
    
      
      
    • Ausgangslage: Der if-Zweig besteht aus einer Anweisung ohne Block.
      • 
      
    • Änderung: Jemand schreibt eine zweite Anweisung darunter, rückt sie ein und vergisst die Klammern.
      • 
      
    • Folge: Die zweite Anweisung gehört nicht zum if-Zweig. Sie wird immer ausgeführt. Wegen der Einrückung fällt das beim Lesen kaum auf.
      • 
    
    
    
    In Go kann dieser Fehler nicht entstehen, weil der Block immer dasteht.
    
  
    
  
    
    
    
  
    
  
    

  
    
  
    
    
    else
    
    
    Hinter dem Block des if-Zweigs darf das Schlüsselwort else mit einem zweiten Block stehen. Dieser Block heißt else-Zweig.
    
    
      
      
    • Bedingung ergibt true: Der if-Zweig wird ausgeführt, der else-Zweig übersprungen.
      • 
      
    • Bedingung ergibt false: Der if-Zweig wird übersprungen, der else-Zweig ausgeführt.
      • 
    
    
    
    Das Programm verzweigt sich an dieser Stelle. Nach beiden Zweigen geht es hinter der letzten } gemeinsam weiter.

      Genau ein Zweig oder höchstens ein Zweig
      
    
        
      
      • Mit else: Es wird genau ein Zweig ausgeführt. Welcher es ist, hängt von der Bedingung ab.
        • 
      
      • Ohne else: Es wird höchstens ein Zweig ausgeführt. Ergibt die Bedingung false, läuft keiner.
        • 
    
      
  
      
  
      
    
    
  
      
  
      

  
      
  
      
    
      else if
      
    
      Hinter else darf statt eines Blocks eine weitere if-Anweisung stehen. So entsteht ein else-if-Zweig mit eigener Bedingung. Auf ihn darf wieder ein else-if-Zweig folgen. Die Kette kann mit einem else-Zweig enden.
      
    
      Für die Kette gelten drei Regeln:
      
    
        
      
      • Reihenfolge: Die Bedingungen werden von oben nach unten ausgewertet.
        • 
      
      • Erster Treffer: Der Zweig der ersten Bedingung, die true ergibt, wird ausgeführt. Alle Zweige darunter werden übersprungen, ihre Bedingungen werden nicht mehr ausgewertet.
        • 
      
      • Kein Treffer: Ergibt keine Bedingung true, läuft der else-Zweig. Fehlt er, läuft kein Zweig.
        • 
    
      

    
      Ausprobieren: aus Punkten wird eine Note
      
    
      
      
      
      
      
      
    
      
    
        
    
        Hinter jeder Bedingung steht true, false oder „nicht geprüft“. Ein grüner Strich links bedeutet: Die Zeile wird ausgeführt. Eine blasse Zeile wird übersprungen.

        Schaltjahr
        
    
        Das Programm aus dem Kurstext liest ein Jahr ein und gibt aus, ob es ein Schaltjahr ist. Es wendet die Regel des Gregorianischen Kalenders an:
        
    
          
      
        • Durch 4 teilbar: Das Jahr ist ein Schaltjahr. Beispiel: 2024.
          • 
      
        • Ausnahme, durch 100 teilbar: Das Jahr ist kein Schaltjahr. Beispiel: 1900.
          • 
      
        • Ausnahme von der Ausnahme, durch 400 teilbar: Das Jahr ist doch ein Schaltjahr. Beispiel: 2000.
          • 
    
        
    
        Das Programm enthält drei if-Anweisungen:
        
    
          
      
        • Zeilen 13–15, ohne else: Vor 1582 galt die Regel noch nicht. Das Programm gibt dann einen Hinweis aus und rechnet trotzdem weiter.
          • 
      
        • Zeilen 18–26, Kette mit else if: Die Kette setzt die Variable schaltjahr.
          • 
      
        • Zeilen 28–32, mit else: Die Bedingung ist die Variable schaltjahr selbst. Sie hat den Typ bool.

          Aus der Praxis
          
    
          Die Faustregeln in diesem Schritt stammen vom Mentor. Sie stehen nicht in Abschnitt 5.5.1 des Kurstexts. Go übersetzt in jedem Beispiel beide Programmstücke.
          

    
          1. Die Ausnahme steht vor der Regel
          
    
          In einer Kette mit else if steht die engste Bedingung oben. Sonst fängt eine weite Bedingung die Fälle ab, die für einen Zweig weiter unten gedacht waren.
          
    
          Beispiel ist das Notenprogramm aus Schritt 3 mit der weitesten Bedingung oben:
          

          if punkte >= 50 {
    fmt.Println("Note: Ausreichend")
} else if punkte >= 90 {
    fmt.Println("Note: Sehr gut")
}
          
    
          Für 95 Punkte gibt dieses Programm „Note: Ausreichend“ aus. Der Zweig mit punkte >= 90 kann nie laufen, weil jede Zahl ab 90 schon die erste Bedingung erfüllt.
          

    
          2. Eine boolesche Variable braucht keinen Vergleich
          

          if schaltjahr == true {   // umständlich

if schaltjahr {           // so steht es in Listing 5.2
          
    
          schaltjahr hat den Typ bool und ist damit schon eine Bedingung. Der Vergleich mit true ergibt denselben Wert noch einmal.
          
    
          Für das Gegenteil gibt es den Operator !: if !schaltjahr { statt if schaltjahr == false {.
          

    
          3. Eine lange Bedingung bekommt einen Namen
          
    
          Die Schaltjahr-Regel lässt sich als ein einziger boolescher Ausdruck schreiben. Er kann direkt hinter if stehen:
          

          if jahr%400 == 0 || (jahr%4 == 0 && jahr%100 != 0) {
    fmt.Println("Schaltjahr")
}
          
    
          Mit einer Variable sagt der Name, was die Bedingung bedeutet:
          

          istSchaltjahr := jahr%400 == 0 || (jahr%4 == 0 && jahr%100 != 0)

if istSchaltjahr {
    fmt.Println("Schaltjahr")
}
          
    
          Beide Programmstücke sind in Ordnung. Der Name lohnt sich, wenn der Leser die Bedingung erst entziffern muss oder wenn sie an mehreren Stellen gebraucht wird.
          

    
          4. Kein if im if, wenn eine Bedingung genügt
          

          if alter >= 18 {
    if hatAusweis {
        fmt.Println("Einlass")
    }
}
          
    
          Beide Bedingungen müssen erfüllt sein. Der Operator && sagt das in einer Zeile:
          

          if alter >= 18 && hatAusweis {
    fmt.Println("Einlass")
}
          
    
          Wann Go den rechten Teil von && gar nicht erst auswertet, zeigt die Seite Wahrheitswerte und Kurzschluss-Auswertung.
          
    
          Jede Stufe der Verschachtelung rückt den Code weiter nach rechts. Der Leser muss sich dann für jede Zeile merken, welche Bedingungen an dieser Stelle gelten.
          

    
          Ausblick auf Kapitel 7
          
    
          In einer Funktion lässt sich ein Sonderfall gleich am Anfang mit if und return erledigen. Der Rest der Funktion steht dann ohne Verschachtelung da. Die Anweisung return wird in Kapitel 7 behandelt.
