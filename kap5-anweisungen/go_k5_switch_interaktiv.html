switch-Anweisung in Go

Die switch-Anweisung wählt unter mehreren Fällen den ersten aus, der passt. Die Seite führt das Programm zur Zuordnung der Wochentage aus dem Kurstext Anweisung für Anweisung aus und vergleicht switch mit if.

Kurstext v3.0.6, Abschnitt 5.5.2, Seiten 133–137.

Worum es geht

Ein Programm soll oft unter mehr als zwei Fällen wählen: Aus der Zahl 1 wird „Montag“, aus der 2 wird „Dienstag“ und so weiter. Eine solche Auswahl heißt Mehrfachverzweigung.

Mit if, else if und else geht das. Kürzer und übersichtlicher geht es oft mit der switch-Anweisung, englisch switch statement:

switch num {
case 1:
    text = "Montag"
case 2:
    text = "Dienstag"
default:
    text = "unbekannt"
}

Die switch-Anweisung ist wie if und for eine Kontrollfluss-Anweisung: Sie steuert, welche Anweisungen als nächste ausgeführt werden.

Aufbau und Ablauf

Eine switch-Anweisung besteht aus dem Schlüsselwort switch, einem Ausdruck und einem Block. Die Teile haben eigene Namen:

  • switch-Ausdruck: der Ausdruck hinter switch, zum Beispiel num.
  • case-Abschnitt: das Schlüsselwort case, ein oder mehrere Ausdrücke und ein Doppelpunkt, zum Beispiel case 6, 7:.
  • case-Ausdruck: ein Ausdruck in einem case-Abschnitt, hier 6 und 7. Mehrere case-Ausdrücke sind durch Kommas getrennt.
  • Anweisungsteil: die Anweisungen, die auf den case-Abschnitt folgen, zum Beispiel text = "Wochenende".
  • default-case: ein Abschnitt, der mit default: beginnt. Er darf fehlen.

Wie Go eine switch-Anweisung ausführt

  • Auswerten: Go wertet den switch-Ausdruck einmal aus.
  • Vergleichen: Go vergleicht seinen Wert von oben nach unten mit den Werten der case-Ausdrücke.
  • Ausführen: Beim ersten case-Ausdruck mit gleichem Wert führt Go dessen Anweisungsteil aus. Damit ist die switch-Anweisung zu Ende. Die case-Abschnitte darunter prüft Go nicht mehr.
  • default: Stimmt kein case-Ausdruck überein, führt Go den Anweisungsteil des default-case aus. Gibt es keinen, tut die switch-Anweisung nichts.

Ausprobieren: du bist der Benutzer

Das Programm ordnet einer Zahl von 1 bis 7 einen Wochentag zu. Es hält in Zeile 9 an und wartet auf deine Eingabe. Wähle dann eine der neun Zahlen.

Eingabe:
num text Geprüfte case-Abschnitte bisher

    Die gelb markierte Zeile ist die Zeile, die gerade ausgeführt wurde oder an der das Programm wartet. Ein grüner Strich links bedeutet: Die Zeile ist schon gelaufen. Hinter einem geprüften case-Abschnitt steht ein Schild: rot mit „passt nicht“ oder grün mit „passt“.

    Was Go bei den case-Ausdrücken verlangt

    • Gleicher Typ: Die case-Ausdrücke müssen den gleichen Typ haben wie der switch-Ausdruck. Zu case "sechs": in einer switch-Anweisung über die Zahl num meldet der Compiler cannot convert "sechs" (untyped string constant) to type int.
    • Kein Wert doppelt: Steht case 6: zweimal da, meldet der Compiler duplicate case 6 (constant of type int) in expression switch.
    • Beliebiger Typ: Der switch-Ausdruck muss keine ganze Zahl sein. switch wort { mit case "ja", "j": vergleicht Strings.
    • Beliebige Ausdrücke: Im Listing sind die case-Ausdrücke Literale. Erlaubt sind dort beliebige Ausdrücke.
    • Platz des default-case: Er darf an jeder Stelle zwischen den case-Abschnitten stehen. Üblich ist das Ende.

    Im Kurstext wird noch eine zweite Form der switch-Anweisung erwähnt, die nach einem Typ verzweigt. Sie gehört nicht zum Stoff des Kurses.

    switch oder if

    Die Zuordnung der Wochentage lässt sich auch mit einer if-Anweisung schreiben. Beide Programme tun das Gleiche.

    
    
    
      So oft steht num im Code
    
    
    
    
    
    Die switch-Anweisung passt, wenn ein Wert mit mehreren festen Werten auf Gleichheit verglichen wird. Dann ist sie kürzer und leichter zu lesen.
    

    
    Ein Funktionsaufruf als switch-Ausdruck
    
    
    Ein zweiter Vorteil zeigt sich, wenn der switch-Ausdruck ein Funktionsaufruf f() ist. Go wertet den switch-Ausdruck nur einmal aus und merkt sich den Wert für alle Vergleiche.
    
    
    Die Funktion f dieser Demo zählt in der globalen Variable aufrufe mit, wie oft sie aufgerufen wird, und liefert den Wert 1:
    

    var aufrufe int

func f() int {
    aufrufe++
    return 1
}

    Mehrfache Aufrufe kosten Zeit. Schlimmer ist ein Aufruf mit Seiteneffekt: Liefert f nicht jedes Mal den gleichen Wert oder ändert sie etwas, wie hier die Variable aufrufe, dann verhält sich die if-Anweisung mit f() anders als gedacht.

    Ohne switch-Ausdruck
    
    
    Der switch-Ausdruck darf fehlen. Go setzt dann stillschweigend den switch-Ausdruck true ein. Diese Form heißt auf Englisch tagless switch.
    
    
    Daraus folgt:
    
    
      
      
    • Jeder case-Ausdruck hat den Typ bool. Er ist eine Bedingung, zum Beispiel x < 0.
      • 
      
    • Go sucht den ersten case-Ausdruck, der true ergibt, und führt dessen Anweisungsteil aus.
      • 
    
    
    
    So lässt sich eine Mehrfachverzweigung nach beliebigen Bedingungen schreiben, nicht nur nach Gleichheit.
    

    
    Ausprobieren: negativ, positiv oder Null
    
    
    
      Wert von x:
      
      
      
    
    
    
      
    
      
      Ausgabe
    
      
    
      
    
      Hinter jedem case-Ausdruck steht ein Schild mit seinem Ergebnis: grün mit true, rot mit false, grau mit „nicht geprüft“. Gelb markiert ist die Anweisung, die Go ausführt.
      

    
      Das Gleiche mit if
      
    
      Die switch-Anweisung ohne switch-Ausdruck ist eine andere Schreibweise für if, else if und else:
      

      if x < 0 {
    fmt.Println("x ist negativ")
} else if x > 0 {
    fmt.Println("x ist positiv")
} else {
    fmt.Println("x ist Null")
}
      

    
      Mit und ohne switch-Ausdruck nicht mischen
      
    
      Steht ein switch-Ausdruck da, gehört in den case-Abschnitt ein Wert und keine Bedingung. Zu switch x { mit case x < 0: meldet der Compiler cannot convert x < 0 (untyped bool value) to type int. Go würde den Wert von x mit true oder false vergleichen, und das passt vom Typ nicht.
      
  
      
  
      
    
    
  
      
  
      

  
      
  
      
    
      In anderen Sprachen
      
    
      Java, C++ und andere Sprachen aus der Familie von C haben auch eine switch-Anweisung. Sie sieht ähnlich aus und verhält sich in zwei Punkten anders.
      

    
      Fallthrough und break
      
    
      In diesen Sprachen ist die switch-Anweisung nach dem Anweisungsteil eines case-Abschnitts nicht zu Ende. Das Programm führt den Anweisungsteil des nächsten case-Abschnitts gleich mit aus. Es „fällt“ in den nächsten Abschnitt hinein, englisch fallthrough.
      
    
      Wer das nicht will, schreibt ans Ende jedes Anweisungsteils das Schlüsselwort break. Das wird leicht vergessen und danach leicht übersehen.
      
    
      
      
      
      
    
      
    
      
      Wert von x:
      
      
      
    
      
    
      
    
      
      Ausgabe
    
      
    
      
    
      Go beendet die switch-Anweisung nach dem Anweisungsteil von selbst. Ein vergessenes break kann dort keinen Fehler auslösen.
      

    
      Der Typ des switch-Ausdrucks
      
    
        
      
      • Go: Der switch-Ausdruck darf jeden Typ haben, und die case-Ausdrücke dürfen beliebige Ausdrücke sein.
        • 
      
      • Manche andere Sprachen: Der switch-Ausdruck ist auf bestimmte primitive Typen beschränkt, oder die case-Ausdrücke müssen konstant sein. Dort dient switch deshalb meist nur für einfache Vergleiche mit ganzen Zahlen oder Strings.

      Aus der Praxis
      
    
      Die Faustregeln in diesem Schritt stammen vom Mentor. Sie stehen nicht in Abschnitt 5.5.2 des Kurstexts. Go übersetzt jedes Beispiel, auch die drei mit dem Kommentar „falsch“.
      

    
      1. Ein leerer case-Abschnitt tut nichts
      

      switch num {
case 6:          // falsch: für 6 geschieht nichts
case 7:
    text = "Wochenende"
}
      

      switch num {
case 6, 7:       // richtig: beide Werte in einem case-Abschnitt
    text = "Wochenende"
}
      
    
      Wer von Java oder C kommt, schreibt gleiche Fälle gern untereinander und verlässt sich auf den Fallthrough aus Schritt 4. In Go gibt es ihn nicht: Bei num gleich 6 passt der erste case-Abschnitt, sein Anweisungsteil ist leer, und die switch-Anweisung ist zu Ende. text bleibt der leere String.
      
    
      Mehrere Werte mit dem gleichen Anweisungsteil gehören in einen case-Abschnitt, durch Kommas getrennt.
      

    
      2. Der default-case fängt den Wert ab, an den niemand gedacht hat
      

      switch num {
case 1:
    text = "Montag"
case 6, 7:
    text = "Wochenende"
}
fmt.Println(num, "ist", text, "zugeordnet.")   // falsch bei 9: 9 ist  zugeordnet.
      
    
      Ohne default-case tut die switch-Anweisung bei einem unerwarteten Wert nichts. Das Programm läuft weiter, als wäre alles in Ordnung, und gibt hier einen leeren Text aus. Der Fehler fällt erst viel später auf.
      
    
      Die Prüffrage beim Schreiben einer switch-Anweisung: Was geschieht mit einem Wert, der in keinem case-Abschnitt steht? Ist die Antwort „das darf nicht vorkommen“, gehört eine Meldung in den default-case.
      

    
      3. Ohne switch-Ausdruck entscheidet die Reihenfolge
      

      switch {
case t < 25:     // falsch: trifft auch für -5 zu
    fmt.Println("angenehm")
case t < 15:
    fmt.Println("kühl")
case t < 0:
    fmt.Println("frostig")
default:
    fmt.Println("warm")
}
      

      switch {
case t < 0:      // richtig: die engste Bedingung zuerst
    fmt.Println("frostig")
case t < 15:
    fmt.Println("kühl")
case t < 25:
    fmt.Println("angenehm")
default:
    fmt.Println("warm")
}
      
    
      Go nimmt den ersten case-Ausdruck, der true ergibt. Im ersten Programm ist das für jede Temperatur unter 25 der erste Abschnitt. Für −5 gibt es „angenehm“ aus, die Abschnitte „kühl“ und „frostig“ erreicht das Programm nie.
      
    
      Bei Bedingungen, die einander einschließen, steht die engste zuerst. Bei einer switch-Anweisung mit switch-Ausdruck stellt sich die Frage nicht: Dort kann jeder Wert nur in einem case-Abschnitt stehen.
