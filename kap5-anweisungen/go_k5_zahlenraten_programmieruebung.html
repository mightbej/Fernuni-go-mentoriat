Programmierübung: Zahlenraten mit Statistik

Aus dem Ablauf des Zahlenratespiels wird Schritt für Schritt ein Go-Programm. Es braucht fast alle Anweisungen aus Kapitel 5: Konstanten, Variablen, Zuweisungen, if, switch, for und break.

Kurstext v3.0.6, Kapitel 5, Seiten 113–149.

Worum es geht

Diese Übung setzt den Exkurs Von der Problemstellung zum Go-Programm fort. Dort wurde das Zahlenraten in fünf Stufen immer genauer festgelegt. Am Ende stand ein Ablauf, der jeden Schritt nennt. Hier wird dieser Ablauf zum Go-Programm.

Was das Programm tun soll

  • Zahl wählen: Das Programm wählt in jeder Runde eine Zufallszahl von 1 bis 100.
  • Raten lassen: Der Spieler hat höchstens 7 Versuche. Nach jedem Tipp meldet das Programm „zu klein“, „zu groß“ oder „richtig“.
  • Runde beenden: Nach einem Treffer nennt das Programm die Zahl der Versuche. Nach sieben Fehlversuchen nennt es die gesuchte Zahl.
  • Mitzählen: Über alle Runden zählt das Programm die gewonnenen Runden, die verlorenen Runden und die Versuche aus den gewonnenen Runden.
  • Bewerten: Aus dem Durchschnitt der Versuche ergibt sich eine Wertung: Meister, Experte, Fortgeschritten oder Anfänger.
  • Weiterspielen: Nach jeder Runde fragt das Programm, ob der Spieler noch eine Runde will.

Womit das Programm auskommt

Das ganze Programm steht in der Funktion main. Eigene Funktionen kommen nicht vor, sie werden erst in Kapitel 7 behandelt.

Die sieben Schritte

  • Schritt 1 legt den Rahmen an und plant den Aufbau in Worten.
  • Schritt 2 deklariert die Konstanten und die Variablen, die über alle Runden gelten.
  • Schritt 3 schreibt die Rateschleife für eine Runde.
  • Schritt 4 gibt die Statistik aus und bewertet den Durchschnitt.
  • Schritt 5 legt die Schleife für mehrere Runden um alles herum.
  • Schritt 6 zeigt das ganze Programm zum Kopieren.
  • Schritt 7 ordnet jeden Teil des Programms einem Abschnitt des Kurstexts zu.
Das Programm ist mit Go 1.26 übersetzt und gespielt. Auf dieser Seite läuft kein Go. Wer spielen will, kopiert das Programm aus Schritt 6 in eine Datei und startet es selbst.

Rahmen und Aufbau

Jedes Go-Programm beginnt mit dem gleichen Rahmen: der Paketklausel, den Importen und der Funktion main.

package main

import (
    "fmt"
    "math/rand"
)

func main() {
    // hier entsteht das Programm
}
  • fmt: das Paket für Ausgabe und Eingabe. Es wird in Abschnitt 3.3.7, Seite 36, und in Abschnitt 4.2, Seiten 53–58, behandelt.
  • math/rand: das Paket für Zufallszahlen. Es steht nicht im Kurstext. Das Programm braucht daraus eine einzige Funktion, sie wird in Schritt 3 erklärt.

Der Aufbau in Worten

Bevor die erste Anweisung dasteht, lohnt sich ein Plan. Er folgt dem Ablauf aus Stufe 5 des Exkurses:

  1. Die festen Werte bekommen Namen: 7 Versuche, Zahlen von 1 bis 100.
  2. Drei Zähler gelten über alle Runden: Siege, Niederlagen, Summe der Versuche.
  3. Das Programm begrüßt den Spieler.
  4. Für jede Runde wiederholt das Programm:
    • eine Zufallszahl wählen,
    • höchstens siebenmal einen Tipp lesen und vergleichen,
    • die Zähler nachführen,
    • die Statistik und die Wertung ausgeben,
    • fragen, ob noch eine Runde folgen soll.
  5. Das Programm verabschiedet sich.

Zwei Schleifen ineinander

Im Plan stecken zwei Wiederholungen:

  • Äußere Schleife: Sie wiederholt die Runden, bis der Spieler aufhört.
  • Innere Schleife: Sie wiederholt die Tipps einer Runde, höchstens siebenmal.

Die innere Schleife steht im Schleifenrumpf der äußeren. Die Übung baut erst die innere Schleife und legt die äußere in Schritt 5 darum.

Konstanten und Variablen

Zwischen den Importen und der Funktion main stehen die Deklarationen, die für das ganze Programm gelten:

// Konstanten für Spielparameter
const (
    MAX_VERSUCHE = 7
    MIN_ZAHL     = 1
    MAX_ZAHL     = 100
)

// Globale Variablen für Spielstatistik
var (
    anzahlSiege       int
    anzahlNiederlagen int
    gesamtVersuche    int
)

Die drei Konstanten

  • MAX_VERSUCHE = 7: so viele Tipps hat der Spieler in einer Runde.
  • MIN_ZAHL = 1 und MAX_ZAHL = 100: die Grenzen des Zahlenbereichs.

Die Zahlen 7, 1 und 100 kommen im Programm an mehreren Stellen vor. Mit Konstanten steht jeder Wert nur einmal da. Wer das Spiel auf zehn Versuche umstellen will, ändert eine Zeile. Dazu gibt es die Seite Konstanten.

Die drei Zähler

  • anzahlSiege: die Zahl der gewonnenen Runden.
  • anzahlNiederlagen: die Zahl der verlorenen Runden.
  • gesamtVersuche: die Summe der Versuche aus den gewonnenen Runden.

Bei keiner der drei Variablen steht ein Wert. Jede bekommt deshalb den Null-Wert 0. Genau dort soll ein Zähler anfangen.

Warum die Zähler nicht in der Schleife stehen

Die drei Zähler müssen ihren Wert von Runde zu Runde behalten. Stünden ihre Deklarationen im Schleifenrumpf der äußeren Schleife, begännen sie in jeder Runde wieder bei 0.

Hier sind sie als globale Variablen deklariert, also außerhalb von main. So zeigt die Übung auch diese Art der Deklaration. Nötig wäre das nicht: Die drei Deklarationen könnten ebenso in main vor der äußeren Schleife stehen. Zu lokalen und globalen Variablen gibt es die Seite Variablendeklaration, Schritt 3.

Die Begrüßung

Die ersten Anweisungen in main nennen dem Spieler die Regeln:

fmt.Println("🎯 Willkommen beim Zahlenraten-Spiel!")
fmt.Printf("Rate eine Zahl zwischen %d und %d.\n", MIN_ZAHL, MAX_ZAHL)
fmt.Printf("Du hast %d Versuche pro Runde.\n\n", MAX_VERSUCHE)

fmt.Printf setzt an jeder Stelle mit %d einen ganzzahligen Wert ein, der Reihe nach aus den Argumenten hinter dem Text. In der zweiten Zeile sind das die Konstanten MIN_ZAHL und MAX_ZAHL. \n steht für einen Zeilenumbruch.

Rateschleife

Dieser Teil ist eine Runde des Spiels. Im fertigen Programm steht er im Schleifenrumpf der äußeren Schleife und ist dort um zwei Stufen eingerückt.

// Generiere Zufallszahl für diese Runde
zielZahl := rand.Intn(MAX_ZAHL-MIN_ZAHL+1) + MIN_ZAHL

// Lokale Variablen für diese Runde
versuchsZaehler := 0
gewonnen := false

// Schleife für die Rateversuche
for versuchsZaehler < MAX_VERSUCHE {
    versuchsZaehler++

    // Eingabe der geratenen Zahl
    fmt.Printf("Versuch %d/%d - Deine Zahl: ", versuchsZaehler, MAX_VERSUCHE)
    var geratenZahl int
    fmt.Scan(&geratenZahl)

    // Prüfe die geratene Zahl
    if geratenZahl == zielZahl {
        fmt.Printf("🎉 Richtig! Die Zahl war %d!\n", zielZahl)
        fmt.Printf("Du hast %d Versuche gebraucht.\n", versuchsZaehler)

        // Aktualisiere Statistik
        anzahlSiege++
        gesamtVersuche += versuchsZaehler
        gewonnen = true
        break

    } else if geratenZahl < zielZahl {
        fmt.Println("📈 Zu klein! Versuche eine größere Zahl.")
    } else {
        fmt.Println("📉 Zu groß! Versuche eine kleinere Zahl.")
    }
}

// Falls nicht gewonnen: Statistik aktualisieren
if !gewonnen {
    fmt.Printf("😞 Leider verloren! Die Zahl war %d.\n", zielZahl)
    anzahlNiederlagen++
}

Die Zufallszahl

rand.Intn(n) liefert eine zufällige ganze Zahl von 0 bis n − 1. Das Programm braucht eine Zahl von 1 bis 100:

  • MAX_ZAHL-MIN_ZAHL+1 ergibt 100. So viele Zahlen liegen im Bereich.
  • rand.Intn(100) liefert eine Zahl von 0 bis 99.
  • + MIN_ZAHL schiebt den Bereich um 1 nach oben: 1 bis 100.

Zwei Variablen für die Runde

  • versuchsZaehler: zählt die Tipps dieser Runde und beginnt mit 0.
  • gewonnen: eine Flag-Variable. Sie beginnt mit false und hält fest, ob der Spieler getroffen hat.

Beide sind mit := im Schleifenrumpf der äußeren Schleife deklariert. Sie entstehen deshalb in jeder Runde neu, anders als die drei Zähler aus Schritt 2.

Die Schleife

  • Schleifenbedingung: versuchsZaehler < MAX_VERSUCHE. Die Schleife läuft, solange weniger als 7 Tipps abgegeben sind.
  • Erste Anweisung im Schleifenrumpf: versuchsZaehler++. Der Zähler steht damit auf der Nummer des Versuchs, der jetzt beginnt.
  • Eingabe: fmt.Scan(&geratenZahl) liest den Tipp.

Der Vergleich

Eine if-Anweisung mit drei Zweigen vergleicht den Tipp mit der gesuchten Zahl:

  • Gleich: Das Programm gratuliert, erhöht anzahlSiege, addiert die Versuche dieser Runde zu gesamtVersuche und setzt gewonnen auf true. Dann verlässt break die Rateschleife.
  • Kleiner: Das Programm meldet „Zu klein“.
  • Sonst: Der Tipp ist größer. Das Programm meldet „Zu groß“.

Nach der Schleife

Hinter der Schleife ist offen, wie sie geendet hat: durch break nach einem Treffer oder regulär nach dem siebten Fehlversuch. Die Flag-Variable gewonnen entscheidet es. if !gewonnen heißt: wenn nicht gewonnen. Dann nennt das Programm die Zahl und erhöht anzahlNiederlagen.

Das gleiche Muster aus Flag-Variable und break steht im Kurstext in Listing 5.7. Dazu gibt es die Seite break-Anweisung, Schritt 2.

Statistik und Wertung

Nach jeder Runde gibt das Programm den Stand über alle Runden aus. Auch dieser Teil steht im fertigen Programm im Schleifenrumpf der äußeren Schleife, gleich hinter der Rateschleife.

// Statistik-Ausgabe
gesamtSpiele := anzahlSiege + anzahlNiederlagen

fmt.Println("\n╔════════════════════════════╗")
fmt.Println("║      📊 STATISTIK 📊       ║")
fmt.Println("╚════════════════════════════╝")
fmt.Printf("Gesamt gespielt: %d\n", gesamtSpiele)
fmt.Printf("Gewonnen: %d\n", anzahlSiege)
fmt.Printf("Verloren: %d\n", anzahlNiederlagen)

// Berechne Durchschnitt nur wenn Siege vorhanden
if anzahlSiege > 0 {
    durchschnitt := float64(gesamtVersuche) / float64(anzahlSiege)
    fmt.Printf("Durchschn. Versuche: %.2f\n", durchschnitt)

    // Kategorisierung mit Switch
    var kategorie string
    switch {
    case durchschnitt <= 3.0:
        kategorie = "🏆 Meister - Hervorragend!"
    case durchschnitt <= 4.0:
        kategorie = "⭐ Experte - Sehr gut!"
    case durchschnitt <= 5.5:
        kategorie = "👍 Fortgeschritten - Gut gemacht!"
    default:
        kategorie = "🌱 Anfänger - Weiter üben!"
    }
    fmt.Printf("Kategorie: %s\n", kategorie)
} else {
    fmt.Println("Noch keine Siege!")
}

Der Durchschnitt

  • Nur mit Siegen: Der Durchschnitt ist die Summe der Versuche geteilt durch die Zahl der Siege. Ohne Sieg gibt es nichts zu teilen. Die if-Anweisung if anzahlSiege > 0 fängt diesen Fall ab, der else-Zweig meldet „Noch keine Siege!“.
  • Mit Konversion: gesamtVersuche und anzahlSiege haben den Typ int. Go teilt ganze Zahlen ohne Rest: 7 Versuche in 2 gewonnenen Runden ergäben 3. Erst float64(…) macht aus beiden Werten Gleitkommazahlen, und die Division ergibt 3,5.
  • Mit zwei Nachkommastellen: %.2f gibt eine Gleitkommazahl mit zwei Stellen hinter dem Punkt aus.

Zur Division ganzer Zahlen gibt es die Seite Typkonvertierung, Schritt 4.

Die Wertung

Eine switch-Anweisung ohne switch-Ausdruck bewertet den Durchschnitt. Go nimmt den ersten case-Ausdruck, der true ergibt:

Durchschnitt der VersucheWertung
Der Durchschnitt liegt bei höchstens 3,0.Meister
Der Durchschnitt liegt über 3,0 und bei höchstens 4,0.Experte
Der Durchschnitt liegt über 4,0 und bei höchstens 5,5.Fortgeschritten
Der Durchschnitt liegt über 5,5.Anfänger

Die Reihenfolge der case-Abschnitte ist hier entscheidend. Ein Durchschnitt von 2,5 erfüllt alle drei Bedingungen. Weil durchschnitt <= 3.0 zuerst geprüft wird, lautet die Wertung „Meister“. Dazu gibt es die Seite switch-Anweisung, Schritt 3.

Zwei Einzelheiten

  • var kategorie string: Die Variable ist ausführlich und ohne Wert deklariert. Ihren Wert bekommt sie erst in der switch-Anweisung.
  • gesamtSpiele: Die Zahl der gespielten Runden wird nicht eigens mitgezählt. Sie ist die Summe aus Siegen und Niederlagen.

Mehrere Runden

Jetzt kommt die äußere Schleife um die Teile aus Schritt 3 und Schritt 4. Sie steht in main hinter der Begrüßung:

for {
    // hier steht die Rateschleife aus Schritt 3
    // hier steht die Statistik aus Schritt 4

    fmt.Print("\nNochmal spielen? (j/n): ")
    var antwort string
    fmt.Scan(&antwort)

    if antwort == "n" || antwort == "N" {
        break
    }

    fmt.Print("\n--- Neue Runde ---\n")
}

fmt.Println("\n👋 Vielen Dank fürs Spielen! Bis zum nächsten Mal!")

Eine Schleife ohne Bedingung

Wie viele Runden gespielt werden, entscheidet der Spieler am Ende jeder Runde. Am Anfang der Schleife gibt es deshalb nichts zu prüfen. for { ohne Schleifenbedingung wiederholt den Schleifenrumpf, bis ein break die Schleife verlässt. Dazu gibt es die Seite for-Anweisung mit for-Klausel, Schritt 4.

Die Frage am Ende der Runde

  • var antwort string: nimmt die Antwort des Spielers auf.
  • antwort == "n" || antwort == "N": Die Bedingung ist erfüllt, wenn der Spieler ein kleines oder ein großes n eingibt. Der Operator || bedeutet „oder“.
  • break: verlässt die äußere Schleife. Das Programm macht mit der Verabschiedung weiter.

Jede andere Eingabe startet eine neue Runde, auch ein Tippfehler.

Zwei break, zwei Schleifen

Das Programm enthält zwei break. Jedes verlässt nur die Schleife, in der es unmittelbar steht:

  • Das break nach dem Treffer steht in der Rateschleife und beendet die Runde. Die äußere Schleife läuft weiter.
  • Das break nach der Antwort „n“ steht nur in der äußeren Schleife und beendet das Spiel.

Dazu gibt es die Seite break-Anweisung, Schritt 4.
