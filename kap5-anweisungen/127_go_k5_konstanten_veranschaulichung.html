🎯 Was sind Konstanten?

Konstanten sind Bezeichner, die für einen festen, unveränderlichen Wert stehen. Im Gegensatz zu Variablen kann der Wert einer Konstante nach der Deklaration nicht mehr geändert werden.

⚠️ Wichtig: Einer Konstanten muss bei der Deklaration immer ein Wert zugewiesen werden, da dieser initiale Wert unveränderlich ist.

Syntax der Deklaration

const maxAnzahl int = 500 // explizite Typangabe const maxAnzahl = 500 // Typ wird abgeleitet (int)

⚖️ Konstante vs. Variable

Merkmal Konstante Variable
Schlüsselwort const var
Initialer Wert ✓ Pflicht bei Deklaration Optional
Veränderbarkeit ✗ Unveränderlich ✓ Veränderlich
Typableitung ✓ Möglich ✓ Möglich
Wann verwenden? Feste Werte, die sich nicht ändern Werte, die sich ändern können/sollen

🎯 Wann sollte man Konstanten verwenden?

1️⃣ Verständlichkeit

Aussagekräftige Namen statt komplizierter Zahlenwerte

umfang := 2 * math.Pi * radius

Besser lesbar als:
umfang := 2 * 3.14159... * radius

2️⃣ Performanz

Häufig benötigte Werte nicht wiederholt berechnen

const Log10E = 1 / Ln10 // Nur einmal berechnet!

3️⃣ Zentrale Wartung

Werte an einer Stelle ändern statt im gesamten Code

const maxAnzahl = 500 // Bei Änderung nur hier!

4️⃣ Bedeutungserkennung

Gleiche Werte mit unterschiedlicher Bedeutung unterscheiden

const monateImJahr = 12 const stundenAufUhr = 12

🤔 Beispiel zur Bedeutungserkennung

Angenommen, Sie müssen im Code herausfinden, wo sich die Berechnung ändert, wenn ein Jahr plötzlich 13 Monate hätte (hypothetisch):

  • Ohne Konstante: Sie müssen jede Stelle mit dem Wert 12 prüfen und entscheiden, ob es sich um Monate oder etwas anderes handelt.
  • Mit Konstante: Sie suchen einfach nach monateImJahr und finden alle relevanten Stellen sofort!

🔬 Expertenwissen: Untyped Constants

📖 Was sind Untyped Constants?

In Go haben Konstanten und Literale (wie 736 oder 0.6589) zunächst keinen konkreten Typ, sondern den speziellen Typ untyped integer bzw. untyped float. Der konkrete Typ wird erst bei der Verwendung durch den Kontext bestimmt.

Typ-Anpassung je nach Kontext

var a uint8 = 20 var b int64 = 20 fmt.Println(a + 88) // 88 wird zu uint8 fmt.Println(b + 88) // 88 wird zu int64 fmt.Printf("Der Typ ist %T.\n", 88) // Ausgabe: Der Typ ist int.

✨ Vorteil: Hohe Präzision bei Konstanten

Der Go-Compiler führt Berechnungen mit untyped Konstanten mit einer Präzision von mindestens 256 Bit durch!

  • math.Pi ist mit 65 Dezimalziffern definiert
  • float64 kann nur ca. 16 Dezimalziffern repräsentieren
  • Berechnungen zur Compile-Zeit nutzen die volle Präzision
  • Erst bei der Verwendung zur Laufzeit wird konvertiert

Beispiel: Hohe Präzision

const ( Pi = 3.14159265358979323846264338327950288419716939937510582097494459 // 65 Dezimalziffern! ) // Berechnung zur Compile-Zeit mit 256 Bit Präzision: const umfangEinheitskreis = 2 * Pi * 1 // Erst bei Zuweisung zu float64 wird konvertiert: var ergebnis float64 = umfangEinheitskreis

✅ Best Practices

✓ Empfohlen

  • Konstanten für wiederkehrende Werte verwenden
  • Sprechende Namen wählen (z.B. maxAnzahl)
  • Verwandte Konstanten gruppieren
  • Bei Deklaration Typ weglassen, wenn ableitbar

✗ Vermeiden

  • "Magic Numbers" direkt im Code verwenden
  • Konstanten ohne Initialisierung (nicht möglich!)
  • Versuch, Konstanten zu ändern (Compile-Fehler)
  • Konstanten für Werte, die sich ändern könnten

💡 Faustregel:

Wenn ein Wert im Code mehr als einmal vorkommt und eine spezifische Bedeutung hat → Konstante verwenden!
