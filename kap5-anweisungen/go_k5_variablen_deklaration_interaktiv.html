Variablendeklaration in Go

Eine Deklaration erzeugt eine Variable und gibt ihr einen Namen, einen Typ und einen Anfangswert. Die Seite zeigt die ausführliche und die kurze Form, lokale und globale Variablen und die Meldung des Compilers bei einer ungenutzten Variable.

Kurstext v3.0.6, Abschnitt 5.1, Seiten 113–123.

Worum es geht

Eine Variable ist ein Speicherort, der mit einem Wert belegt ist. Bevor ein Programm eine Variable verwenden kann, muss es sie deklarieren. Die Deklaration erledigt drei Aufgaben auf einmal:

  • Erzeugen: Go stellt den Speicher für eine Variable eines bestimmten Typs bereit. Der Typ lässt sich danach nicht mehr ändern.
  • Belegen: Die Variable bekommt einen Anfangswert, den Initialwert.
  • Benennen: Die Variable wird mit einem neuen Bezeichner verbunden, ihrem Namen. Über den Namen greift das Programm später auf die Variable zu.

Go hat dafür zwei Schreibweisen:

var foo int = 42   // ausführliche Variablendeklaration
foo := 42          // kurze Variablendeklaration

In einem Programm steht nur eine der zwei Zeilen. Beide erzeugen die gleiche Variable: Sie heißt foo, hat den Typ int und den Wert 42.

Ausführliche Deklaration

Die ausführliche Variablendeklaration hat vier Teile:

var foo int = 42
  • var: das Schlüsselwort. Es leitet die Deklaration ein.
  • foo: der Bezeichner, also der Name der Variable. Er ist Pflicht.
  • int: der Typ der Variable.
  • = 42: der Initialwert. Das ist der Wert, den die Variable bei ihrer Erzeugung bekommt.

Der Typ oder der Wert darf fehlen

  • Ohne Typ: Go ermittelt den Typ aus dem Initialwert. Für ein Literal ist ein Standardtyp festgelegt, englisch default type. Das Integer-Literal 42 hat den Standardtyp int, das Floating-Point-Literal 9.95 den Standardtyp float64.
  • Ohne Wert: Go belegt die Variable mit dem Null-Wert ihres Typs, englisch zero value.

Beides zugleich darf nicht fehlen: Aus var foo allein kann Go keinen Typ ermitteln.

Mehrere Variablen in einer Deklaration


var tag, monat, jahr int = 24, 12, 2006
var name, note, bestanden = "Peter", 1.7, true
var a, b, c int

    
    
      
  • Erste Zeile: drei Variablen vom Typ int mit den Werten 24, 12 und 2006.
    • 
      
  • Zweite Zeile: Der Typ fehlt. Go legt ihn je Variable nach ihrem Initialwert fest: name bekommt string, note bekommt float64, bestanden bekommt bool.
    • 
      
  • Dritte Zeile: Die Werte fehlen. Alle drei Variablen bekommen den Null-Wert 0.
    • 
    

    
Folgen mehrere Zeilen mit Deklarationen aufeinander, genügt ein var mit runden Klammern:


var (
    tag, monat, jahr      int = 24, 12, 2006
    name, note, bestanden     = "Peter", 1.7, true
    a, b, c               int
)

Kurze Deklaration

    
Meist steht bei einer Deklaration der Initialwert da und der Typ fehlt. Für diesen häufigen Fall hat Go eine kürzere Schreibweise, die kurze Variablendeklaration, englisch short variable declaration:


var foo = 42   // ausführliche Variablendeklaration
foo := 42      // kurze Variablendeklaration

    
Das Zeichen := heißt Deklarationsoperator. An ihm erkennt Go die kurze Deklaration, das Schlüsselwort var entfällt.

    
Für die kurze Deklaration gilt:

    
    
      
  • Der Initialwert ist Pflicht. Auch der Wert 0 muss dastehen: a := 0.
    • 
      
  • Ein Typ lässt sich nicht angeben. Die Variable bekommt immer den Standardtyp ihres Initialwerts.
    • 
      
  • Mehrere Variablen gehen auch: tag, monat, jahr := 24, 12, 2006.
    • 
    


    
:= und = nicht verwechseln

    
    
      
  • x := 8 ist eine Deklaration. Sie erzeugt eine neue Variable, verbindet sie mit dem neuen Bezeichner x und belegt sie mit 8.
    • 
      
  • x = 10 ist eine Zuweisung. Sie gibt der Variable x den Wert 10. Die Variable muss vorher deklariert sein.
    • 
    

    
In der Sprache Pascal ist := der Zuweisungsoperator. Wer von Pascal kommt, muss hier umlernen.

    Die Mischform aus Deklaration und Zuweisung
    
    
    Die Zeile x, y := 10, 20 aus der Demo ist eine Besonderheit von Go. Steht links von := mehr als ein Bezeichner, darf ein Teil davon schon deklariert sein:
    
    
      
      
    • Schon deklarierte Variable: Sie bekommt den neuen Wert zugewiesen.
      • 
      
    • Neuer Bezeichner: Go deklariert eine neue Variable.
      • 
    
    
    
    Mindestens ein Bezeichner links muss neu sein. Wozu diese Mischform gut ist, wird in Abschnitt 7.1.2 bei den Funktionen mit mehreren Rückgabewerten erklärt.
    
  
    
  
    
    
    
  
    
  
    

  
    
  
    
    
    Lokal und global
    
    
    Wo eine Deklaration steht, entscheidet darüber, wo der Bezeichner der Variable gilt.
    
    
      
      
    • Lokale Variable: Sie ist in einer Funktion deklariert. Ihr Bezeichner gilt nur in dem Block, in dem die Deklaration steht, zum Beispiel im Rumpf der Funktion.
      • 
      
    • Globale Variable: Sie ist außerhalb aller Funktionen deklariert und gehört zum Paket. Ihr Bezeichner gilt in allen Funktionen des Pakets. Sie heißt auch package-level Variable.
      • 
    
    
    
    Für eine globale Variable ist nur die ausführliche Deklaration mit var erlaubt.
    

    
    Ausprobieren: Anweisung für Anweisung
    
    
    Das Programm hat eine globale Variable klima und zwei lokale Variablen mit dem gleichen Namen wetter, eine in main und eine in f.

Der rote Kasten zeigt die globale Variable, die zwei blauen Kästen zeigen die lokalen Variablen. Ein gelb umrandeter Kasten gehört zu der Funktion, die gerade läuft.

      Was der Lauf zeigt
      
    
        
      
      • Eine globale Variable teilen sich alle Funktionen. main setzt klima auf "kalt", und f gibt diesen Wert aus. Danach setzt f die Variable auf "warm", und main gibt diesen Wert aus.
        • 
      
      • Jede Funktion hat ihre eigene lokale Variable. Die zwei Variablen wetter haben den gleichen Namen und wissen nichts voneinander. f macht aus ihrem "Regen" den "Regenschauer", die Variable von main behält "Sonne".
        • 
      
      • Einen Namenskonflikt gibt es nicht, weil der Bezeichner wetter aus f nur im Rumpf von f gilt.
        • 
    
      

    
      Wo die Deklaration stehen muss
      
    
        
      
      • Lokale Variable: Die Deklaration steht vor der ersten Verwendung. Sonst meldet der Compiler undefined: a.
        • 
      
      • Globale Variable: Die Deklaration darf im Quellcode auch hinter der ersten Verwendung stehen, sogar am Ende der Datei. Go verarbeitet alle globalen Deklarationen, bevor main beginnt. Der Übersicht wegen stehen globale Variablen trotzdem am Anfang.
        • 
      
      • Kurze Deklaration außerhalb einer Funktion: Zu klima := "kalt" in Zeile 5 meldet der Compiler syntax error: non-declaration statement outside function body.
        • 
    
      
  
      
  
      
    
    
  
      
  
      

  
      
  
      
    
      Welche Form wann
      
    
      Ob eine Variable ausführlich oder kurz deklariert ist, ändert an der Variable nichts. Es ist eine Frage des Stils. Fast immer sind beide Formen erlaubt.

      Die Empfehlungen
      
    
        
      
      • Lokale Variable mit Initialwert: die kurze Deklaration. Sie ist kurz und flexibel, die meisten lokalen Variablen werden so deklariert.
        • 
      
      • Lokale Variable, deren Anfangswert keine Rolle spielt: var mit Typ und ohne Wert. Die Variable bekommt ihren Wert später durch eine Zuweisung.
        • 
      
      • Lokale Variable mit einem anderen Typ als dem ihres Initialwerts: var mit Typ und Wert, zum Beispiel var klein int8 = 42. Mit klein := 42 bekäme die Variable den Typ int.
        • 
      
      • Mehrere Initialwerte in einer Deklaration: nur dort, wo es dem Lesen hilft, zum Beispiel bei kurzen Gruppen, die zusammengehören.
        • 
    
      
    
      Im Kurstext steht der Typ manchmal da, obwohl er sich aus dem Initialwert ergibt. Das ist Absicht: Einsteiger sollen den Typ lesen können.
      

    
      Wann der Typ dastehen sollte
      
    
      Bei einem Literal sieht der Leser den Typ sofort. Bei einem Ausdruck sieht er ihn nicht immer:
      

      a := 219
b := 100
c := a / b   // c hat den Typ int und den Wert 2
      
    
      a und b sind ganze Zahlen, also ist a / b der Ganzzahlquotient 2. Wer den Code liest, erwartet leicht 2.19.
      
    
        
      
      • Mit var c int = a / b steht der Typ da. Der Leser sieht, dass eine ganze Zahl herauskommt.
        • 
      
      • Mit var c float64 = a / b meldet der Compiler cannot use a / b (value of type int) as float64 value in variable declaration. War 2.19 gewollt, fällt der Fehler so beim Übersetzen auf.
        • 
    
      
    
      Das Gleiche gilt für den Rückgabewert einer Funktion: Bei x := math.Exp2(8) muss der Leser in der Dokumentation des Pakets math nachsehen, dass x den Typ float64 bekommt. Der Wert ist 256.
      
    
      Wie Go ganze Zahlen teilt, zeigt die Seite Typkonvertierung, Schritt 4.
      
  
      
  
      
    
    
  
      
  
      

  
      
  
      
    
      Ungenutzte Variablen
      
    
      Go übersetzt ein Programm nicht, wenn eine lokale Variable deklariert ist und nie gelesen wird.
      
    
      „Nicht benutzt“ heißt hier: Das Programm greift nie lesend auf die Variable zu. Eine Zuweisung an die Variable zählt nicht. Ein Wert, den niemand liest, kann den Ablauf des Programms nicht beeinflussen. Die Deklaration ist dann nutzlos.

      Ausgabe
    
        
    
        
    
        Gelb markiert sind die Zeilen, in denen sich das gewählte Programm vom ersten unterscheidet. Die vier Programme sind Ausschnitte ohne package und import.
        

    
        Warum Go so streng ist
        
    
        Andere Sprachen geben bei einer ungenutzten Variable nur eine Warnung aus und übersetzen das Programm trotzdem. Go macht daraus einen Fehler. Der Gedanke dahinter: Eine ungenutzte Variable deutet oft auf ein Problem im Code hin, und der Programmierer soll sich gleich darum kümmern.
        

    
        Der leere Bezeichner _
        
    
        Lästig wird die Meldung beim Entwickeln: Wer eine Ausgabe zum Testen auskommentiert, hat plötzlich eine ungenutzte Variable. Dafür gibt es einen Behelf.
        
    
          
      
        • _ = b weist den Wert von b dem leeren Bezeichner _ zu. Damit ist b einmal gelesen. Der Wert wird sofort verworfen, am Ablauf ändert sich nichts.
          • 
      
        • _, _ = a, b erledigt das für mehrere Variablen auf einmal.
          • 
    
        

    
        Globale Variablen
        
    
        Die Meldung gibt es nur für lokale Variablen. Eine globale Variable darf ungenutzt bleiben. Das ist kein Ausweg: Eine Variable wird nur dann global deklariert, wenn das Programm es braucht.
        

    
        Im Kurstext steht die Meldung als b declared but not used. Go 1.26 schreibt declared and not used: b. Gemeint ist das Gleiche.
