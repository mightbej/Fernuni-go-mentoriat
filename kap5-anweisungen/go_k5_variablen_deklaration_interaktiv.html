📝 Go Variablendeklaration

Ausführliche vs. kurze Deklaration, lokale vs. globale Variablen

1️⃣ Ausführliche Variablendeklaration (var)

Vollständige Deklaration

Mit Schlüsselwort var, Bezeichner, Typ und Initialwert:

var foo int = 42 // explizite Angabe von Typ und Wert
Bestandteile einer Variablendeklaration:
  • var – Schlüsselwort
  • foo – Bezeichner (Name der Variable)
  • int – Datentyp
  • = 42 – Initialwert

Typ weglassen

Der Typ wird automatisch aus dem Initialwert abgeleitet:

var foo = 42 // Typ int (Standardtyp für Integer-Literale) var bar = 9.95 // Typ float64 (Standardtyp für Float-Literale) var text = "Hallo" // Typ string var ok = true // Typ bool
💡 Standardtypen (Default Types):
• Integer-Literale → int
• Float-Literale → float64
• String-Literale → string
• Boolean-Literale → bool

Wert weglassen (Zero Value)

Die Variable wird automatisch mit dem Null-Wert (zero value) ihres Typs initialisiert:

var bar int // implizite Belegung mit 0 var x float64 // implizite Belegung mit 0.0 var s string // implizite Belegung mit "" var b bool // implizite Belegung mit false
int, int8, int16, ...
0
float32, float64
0.0
bool
false
string
""
✅ Vorteil: Keine uninitialisierte Variablen wie in C!
Jede Variable hat nach der Deklaration immer einen definierten Wert.

Mehrere Variablen gleichzeitig

Go erlaubt die Deklaration mehrerer Variablen in einer Anweisung:

var tag, monat, jahr int = 24, 12, 2006 var name, note, bestanden = "Peter", 1.7, true var a, b, c int // alle drei mit 0 initialisiert

Kompakte Block-Notation:

var ( tag, monat, jahr int = 24, 12, 2006 name, note, bestanden = "Peter", 1.7, true a, b, c int )
💡 Tipp: Block-Notation verwenden, wenn mehrere Zeilen mit Deklarationen aufeinanderfolgen.

2️⃣ Kurze Variablendeklaration (:=)

Deklarationsoperator :=

Kompakte Syntax für Variablendeklaration mit Initialwert (nur in Funktionen!):

foo := 42 // entspricht: var foo = 42
Eigenschaften der kurzen Deklaration:
  • ✅ Kein var Schlüsselwort nötig
  • ✅ Sehr kompakt und häufig verwendet
  • ✅ Typ wird automatisch abgeleitet
  • ⚠️ Initialwert MUSS angegeben werden
  • ⚠️ Nur in Funktionen erlaubt (nicht global!)
// Mehrere Variablen gleichzeitig tag, monat, jahr := 24, 12, 2006 name, note, bestanden := "Peter", 1.7, true a, b, c := 0, 0, 0 // Zero-Werte müssen explizit sein!

:= vs. =

⚠️ Wichtiger Unterschied!

:= – Deklarationsoperator (erzeugt NEUE Variable)
= – Zuweisungsoperator (ändert existierende Variable)

Deklaration (:=)

x := 8 // Neue Variable x

Erzeugt eine neue Variable x und weist ihr den Wert 8 zu.

Zuweisung (=)

x = 10 // x muss existieren!

Weist der existierenden Variable x den neuen Wert 10 zu.

x := 8 // x wird deklariert und mit 8 initialisiert x = 10 // x wird mit 10 überschrieben x := 15 // ❌ FEHLER: x bereits deklariert!

3️⃣ Lokale vs. Globale Variablen

Gültigkeitsbereiche (Scope)

Eigenschaft Lokale Variable Globale Variable
Deklaration Innerhalb einer Funktion Außerhalb von Funktionen
Gültigkeitsbereich Nur in der Funktion Im gesamten Paket
Syntax var oder := Nur var
Ungenutzt ❌ Compiler-Fehler ✅ Erlaubt
package main import "fmt" var klima string // GLOBALE Variable (package-level) func f() { wetter := "Regen" // LOKALE Variable in f fmt.Println(klima + ", " + wetter) klima = "warm" // Globale Variable ändern } func main() { wetter := "Sonne" // LOKALE Variable in main klima = "kalt" // Globale Variable ändern fmt.Println(klima + ", " + wetter) f() }
Visualisierung der Gültigkeitsbereiche:
Package-Level (global): klima
Funktion f(): wetter (= "Regen")
Funktion main(): wetter (= "Sonne")
💡 Wichtig:
• Beide Funktionen haben ihre eigene lokale Variable wetter
• Diese sind unabhängig voneinander!
• Beide teilen sich die globale Variable klima

4️⃣ Ungenutzte Variablen

Compiler-Fehlermeldung

Go verlangt, dass alle lokalen Variablen mindestens einmal lesend verwendet werden:

func main() { var a, b int a = 5 b = a * 100 fmt.Println(a) } // ❌ Compiler-Fehler: "b declared but not used"
⚠️ "not used" bedeutet:
Die Variable wird nirgendwo lesend verwendet.
Zuweisungen allein reichen nicht!

Workaround: Leerer Bezeichner _

Bei temporär auskommentiertem Code kann man Werte an _ zuweisen:

func main() { var a, b int a = 5 b = a * 100 fmt.Println(a) _ = b // ✅ Workaround: Wert wird gelesen und verworfen //fmt.Println("ausführliche Ausgabe: ", b) }
💡 Leerer Bezeichner _:
• Zuweisungen an _ werden vom Compiler akzeptiert
• Der Wert wird sofort verworfen
• Nützlich beim Auskommentieren von Code während der Entwicklung
• Mehrere Variablen: _, _ = a, b
✅ Globale Variablen:
Können ungenutzt bleiben (keine Fehlermeldung!)

5️⃣ Best Practices

Wann welche Deklarationsform?

✅ Kurze Form (:=)

  • Am häufigsten verwendet
  • Kompakt und klar
  • In Funktionen
  • Mit Initialwert
count := 0 name := "Max"

✅ var ohne Wert

  • Zero-Value gewollt
  • Wert unwichtig
  • Später befüllt
var sum int var found bool

✅ var mit Typ

  • Typ != Standardtyp
  • Typ explizit wichtig
  • Lesbarkeit
var pi float64 = 3.14 var x int64 = 100

✅ Globale Variablen

  • Nur mit var
  • := nicht erlaubt!
  • Am Dateianfang
var config string var debug = true
📋 Faustregeln:

1. Standardfall: Kurze Deklaration :=
2. Zero-Value: var name typ
3. Expliziter Typ: var name typ = wert
4. Global: Nur var erlaubt
5. Mehrere Variablen: Block-Notation mit var ( ... )
