🔀 if-Anweisungen in Go

Bedingte Anweisungen und Verzweigungen

FernUni Hagen - Kurs 01613 - Kurstext v3.0.6, Abschnitt 5.5.1, Seiten 129–132

🎯 Was sind bedingte Anweisungen?

Eine bedingte Anweisung (conditional statement) ermöglicht es, von der rein sequenziellen Befehlsausführung abzuweichen. Die Ausführung eines Codeabschnitts wird von einer Bedingung abhängig gemacht, die erst zur Programmlaufzeit ausgewertet wird.

💡 Prinzip:

WENN eine Bedingung erfüllt ist, DANN führe bestimmten Code aus, SONST führe anderen Code aus (oder tue nichts).

Bedingung prüfen
↓
true → Code A
false → Code B

📝 Grundlegende if-Anweisung

Die einfachste Form einer if-Anweisung in Go:

if bedingung { // Code wird nur ausgeführt, wenn bedingung true ist }

Syntaktische Struktur

Element Beschreibung Pflicht?
if Schlüsselwort ✓ Ja
Boolescher Ausdruck Bedingung, die true oder false ergibt ✓ Ja
{ } Block Code in geschweiften Klammern ✓ Ja (immer!)
Klammern um Bedingung (bedingung) ✗ Nein (nicht idiomatisch)

Praktisches Beispiel

var alter int = 17 if alter < 18 { fmt.Println("Du bist minderjährig.") }

⚠️ Wichtig in Go:

  • Block ist PFLICHT: Auch bei nur einer Anweisung muss { } verwendet werden!
  • Öffnende Klammer: Muss in derselben Zeile wie if stehen!
  • Keine Klammern: Bedingung nicht in ( ) setzen (nicht idiomatisch)

🔄 if-else: Verzweigung

Mit else kann ein alternativer Code-Pfad definiert werden, der ausgeführt wird, wenn die Bedingung false ist:

if bedingung { // if-Zweig: Code bei true } else { // else-Zweig: Code bei false }

📌 Wichtig:

Genau ein Zweig wird ausgeführt: Entweder der if-Zweig ODER der else-Zweig.

Beispiel: Volljährigkeit prüfen

var alter int = 20 if alter >= 18 { fmt.Println("Du bist volljährig.") } else { fmt.Println("Du bist minderjährig.") }

Ergebnis: Genau eine Ausgabe wird erscheinen (hier: "Du bist volljährig.")

var alter int = 20 if alter >= 18 { fmt.Println("Du bist volljährig.") } // Kein else → bei false passiert nichts

Ergebnis: Entweder eine Ausgabe oder gar keine (hier: "Du bist volljährig.")

🎋 Mehrfachverzweigungen: else if

Durch else if können mehrere Bedingungen nacheinander geprüft werden:

if bedingung1 { // if-Zweig } else if bedingung2 { // else-if-Zweig 1 } else if bedingung3 { // else-if-Zweig 2 } else { // else-Zweig (optional) }

⚠️ Reihenfolge ist wichtig!

  • Bedingungen werden von oben nach unten geprüft
  • Sobald eine Bedingung true ist, wird der entsprechende Zweig ausgeführt
  • Alle nachfolgenden Zweige werden übersprungen (auch wenn ihre Bedingungen true wären!)
  • Maximal ein Zweig wird ausgeführt

Beispiel: Notenberechnung

var punkte int = 85 if punkte >= 90 { fmt.Println("Note: Sehr gut") } else if punkte >= 75 { fmt.Println("Note: Gut") // ← Dieser Zweig wird ausgeführt } else if punkte >= 60 { fmt.Println("Note: Befriedigend") } else if punkte >= 50 { fmt.Println("Note: Ausreichend") } else { fmt.Println("Note: Nicht bestanden") }

✅ Ausgabe:

Note: Gut

Erklärung: 85 ist zwar auch ≥ 60 und ≥ 50, aber die erste zutreffende Bedingung ist punkte >= 75, daher wird nur dieser Zweig ausgeführt.

🗓️ Praxisbeispiel: Schaltjahr-Berechnung

Das Programm aus dem Kurstext zeigt eine typische Anwendung von Mehrfachverzweigungen.

Quelle: Die Schaltjahr-Regel folgt Listing 5.2 schaltjahr.go aus dem Kurstext „Imperative Programmierung“ (Kurs 01613) der FernUniversität in Hagen, Abschnitt 5.5.1.

📖 Gregorianische Schaltjahrregel:

Alle durch 4 teilbaren Jahre sind Schaltjahre, mit der Ausnahme, dass durch 100 teilbare Jahre keine Schaltjahre sind. Davon sind jedoch wiederum die durch 400 teilbaren Jahre ausgenommen, welche immer Schaltjahre sind.

// Schaltjahr-Regel des Gregorianischen Kalenders if jahr%400 == 0 { schaltjahr = true // Durch 400 teilbar → immer Schaltjahr } else if jahr%100 == 0 { schaltjahr = false // Durch 100 teilbar → kein Schaltjahr } else if jahr%4 == 0 { schaltjahr = true // Durch 4 teilbar → Schaltjahr } else { schaltjahr = false // Sonst kein Schaltjahr }

Warum ist die Reihenfolge wichtig?

✅ Richtig (wie oben)

Jahr 1700:

  1. 1700 % 400 == 0? Nein
  2. 1700 % 100 == 0? Ja → schaltjahr = false ✓
  3. Restliche Zweige werden übersprungen

Ergebnis: Kein Schaltjahr (korrekt!)

❌ Falsch (andere Reihenfolge)

if jahr%4 == 0 { schaltjahr = true } else if jahr%100 == 0 { schaltjahr = false }

Jahr 1700: 1700 % 4 == 0? Ja → schaltjahr = true

Ergebnis: Schaltjahr (falsch!)

🌍 Unterschiede zu anderen Sprachen

1. Block ist Pflicht

Java/C++ (Block optional)

if (alter >= 18) System.out.println("Volljährig"); // OK

Go (Block Pflicht!)

if alter >= 18 { fmt.Println("Volljährig") // { } Pflicht! }

✅ Vorteil in Go:

Vermeidet typische Fehler beim späteren Hinzufügen weiterer Anweisungen. Die Struktur ist immer konsistent.

2. Keine Klammern um Bedingung

Java/C++ (Klammern Pflicht)

if (x > 10) { // ( ) Pflicht ... }

Go (Klammern unüblich)

if x > 10 { // Keine ( ) ... }

⚠️ Idiomatic Go:

Klammern um die Bedingung sind syntaktisch möglich, aber nicht idiomatisch und sollten vermieden werden.

3. Öffnende Klammer in derselben Zeile

❌ Nicht erlaubt in Go

if x > 10 { // Compile-Fehler! fmt.Println(x) }

✅ Richtig in Go

if x > 10 { // { in selber Zeile fmt.Println(x) }

4. Begrifflichkeiten

Sprache Bezeichnung
Go, Java, C++ if-statement / if-else-statement
Pascal (historisch) if-then-else-Anweisung (mit then-Schlüsselwort)

✅ Best Practices

✓ Empfohlen

  • Immer Blöcke { } verwenden (Pflicht!)
  • Keine Klammern um Bedingung
  • { in derselben Zeile wie if
  • Bedingungen von spezifisch zu allgemein prüfen
  • Früh returnen (siehe spätere Kapitel)
  • Komplexe Bedingungen in Variablen auslagern

✗ Vermeiden

  • { in neuer Zeile (Compile-Fehler!)
  • Klammern um Bedingung (nicht idiomatisch)
  • Verschachtelte if ohne Notwendigkeit
  • Sehr lange, komplexe Bedingungen
  • Falsche Reihenfolge bei Mehrfachverzweigungen

Beispiel: Klare Bedingungen

// Bedingung in Variable auslagern var istSchaltjahr bool = jahr%400 == 0 || (jahr%4 == 0 && jahr%100 != 0) if istSchaltjahr { fmt.Println("Schaltjahr") }

Vorteil: Lesbar und selbsterklärend durch aussagekräftigen Variablennamen.

// Komplexe Bedingung direkt im if if jahr%400 == 0 || (jahr%4 == 0 && jahr%100 != 0) { fmt.Println("Schaltjahr") }

Problem: Schwerer zu lesen und zu verstehen, besonders bei noch komplexeren Bedingungen.

📚 Zusammenfassung

Konzept Beschreibung
if-Anweisung Ermöglicht bedingte Ausführung von Code
if-Zweig Wird bei true ausgeführt
else-Zweig Wird bei false ausgeführt (optional)
else-if-Zweig Weitere Bedingungsprüfung (Mehrfachverzweigung)
Ausführung Maximal ein Zweig wird ausgeführt
Reihenfolge Von oben nach unten, erste zutreffende Bedingung gewinnt
Block Immer mit { }, auch bei einer Anweisung!
Klammern Keine ( ) um Bedingung (idiomatisch)
