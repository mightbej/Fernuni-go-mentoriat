Frage 1 von 13
Was ist das Ergebnis der folgenden Anweisung?
x := 10 x *= 3

Erklärung:

Der Operator *= multipliziert die Variable mit dem rechten Wert. x *= 3 ist äquivalent zu x = x * 3, also x = 10 * 3 = 30.

Frage 2 von 13
Welche der folgenden Aussagen über ++ und -- in Go sind richtig? (Mehrfachauswahl)

Erklärung:

In Go ist x++ eine Anweisung (kein Ausdruck!) und äquivalent zu x += 1. Go unterstützt nur Post-Increment/-Decrement und diese können nicht in Ausdrücken verwendet werden. Pre-Increment (++x) existiert in Go nicht.

Frage 3 von 13
Welche kombinierte Zuweisungsoperatoren gibt es in Go? (Mehrfachauswahl)

Erklärung:

Go bietet kombinierte Zuweisungsoperatoren für alle binären Operatoren mit multiplikativem oder additivem Charakter: *=, /=, %=, +=, -=. Bitweise Operatoren wie &= existieren auch, aber **= und //= gibt es in Go nicht.

Frage 4 von 13
Was macht die folgende Tupel-Zuweisung?
a, b = b, a

Erklärung:

Die Tupel-Zuweisung a, b = b, a vertauscht die Werte der beiden Variablen. Zuerst werden alle Werte auf der rechten Seite ausgewertet und zwischengespeichert, dann werden sie zugewiesen. So erhält a den (alten) Wert von b und b den (alten) Wert von a.

Frage 5 von 13
Welcher Code ist NICHT erlaubt in Go?

Erklärung:

y = x++ ist in Go nicht erlaubt, da x++ eine Anweisung und kein Ausdruck ist. Ausdrücke können ausgewertet und ihr Wert einer Variablen zugewiesen werden, Anweisungen nicht. Die anderen drei Varianten sind alle gültig.

Frage 6 von 13
Was ist das Ergebnis nach Ausführung dieses Codes?
x := 20 x -= 5 x /= 3

Erklärung:

Schritt für Schritt: x := 20 → x = 20. Dann x -= 5 → x = 20 - 5 = 15. Schließlich x /= 3 → x = 15 / 3 = 5.

Frage 7 von 13
Welche der folgenden sind "Simple Statements" in Go? (Mehrfachauswahl)

Erklärung:

Simple Statements in Go sind: kurze Variablendeklarationen, Zuweisungen, Inkrement/Dekrement, Funktionsaufrufe und die leere Anweisung. if-Anweisungen gehören zu den Kontrollfluss-Anweisungen, nicht zu den Simple Statements.

Frage 8 von 13
Wann sollte man Tupel-Zuweisungen verwenden?

Erklärung:

Tupel-Zuweisungen sollten verwendet werden, wenn die Variablen in einem inhaltlichen Zusammenhang stehen (z.B. x-y-z-Koordinaten) und die zuzuweisenden Ausdrücke einfach sind. Bei komplexen Ausdrücken oder unzusammenhängenden Variablen ist es aus Lesbarkeitsgründen besser, separate Zuweisungen zu verwenden.

Frage 9 von 13
Was ist das Ergebnis dieses Codes?
x := 17 x %= 5

Erklärung:

Der Operator %= berechnet den Rest der Division. x %= 5 ist äquivalent zu x = x % 5. 17 geteilt durch 5 ergibt 3 Rest 2, also ist das Ergebnis x = 2.

Frage 10 von 13
Wie viele Anweisungen sind nötig, um zwei Werte OHNE Tupel-Zuweisung zu vertauschen?

Erklärung:

Ohne Tupel-Zuweisung werden 3 Anweisungen mit einer Hilfsvariable benötigt: tmp := a, a = b, b = tmp. Mit Tupel-Zuweisung genügt eine einzige Anweisung: a, b = b, a.

Frage 11 von 13
Welche der folgenden Kettenzuweisungen ist in Go erlaubt?

Erklärung:

In Go sind Kettenzuweisungen wie x = y = z = 5 nicht erlaubt. Das ist eine bewusste Design-Entscheidung für bessere Lesbarkeit. Jede Variable muss separat zugewiesen werden: x = 5; y = 5; z = 5 oder mit Tupel-Zuweisung: x, y, z = 5, 5, 5.

Frage 12 von 13
Was passiert bei diesem Code?
const MaxWert = 100 MaxWert = 200

Erklärung:

Konstanten (const) können nach der Deklaration nicht mehr geändert werden. Der Versuch, einer Konstante einen neuen Wert zuzuweisen, führt zu einem Compile-Fehler: "cannot assign to MaxWert (declared const)". Verwende var statt const, wenn der Wert änderbar sein soll.

Frage 13 von 13
Welche Zuweisungen sind in Go erlaubt? (Mehrfachauswahl)
var x int = 10 var y string = "Hallo" var z bool = true

Erklärung:

Erlaubt: x = 20 (int zu int), y = "Welt" (string zu string), z = false (bool zu bool). Nicht erlaubt: x = "20" (string zu int), z = 1 (int zu bool), x = 3.14 (float zu int). Go verlangt exakte Typ-Übereinstimmung - automatische Konvertierungen gibt es nicht!
