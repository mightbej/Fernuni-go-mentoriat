🔄 for-Anweisung mit for-Klausel

Die kompakte und mächtige Schleifenkonstruktion in Go

📚 Einführung

In Go gibt es eine besonders elegante Form der Schleife: die for-Anweisung mit for-Klausel. Diese Konstruktion fasst alle wichtigen Elemente einer zählenden Schleife in einer kompakten und übersichtlichen Syntax zusammen.

Das Problem: Wiederholte Berechnungen

Angenommen, wir möchten die Quadratzahlen von 1 bis 10 berechnen. Mit einer for-Anweisung mit Bedingung würden wir schreiben:

// Mit for-Bedingung (funktioniert, aber umständlich) i := 1 for i <= 10 { fmt.Printf("%2[1]v * %2[1]v ist %3v\n", i, i*i) i++ }
💡 Beobachtung: Wir brauchen drei separate Schritte:
  • Variable initialisieren (vor der Schleife)
  • Bedingung prüfen (in der for-Anweisung)
  • Variable hochzählen (im Schleifenrumpf)

✨ Die Lösung: for-Anweisung mit for-Klausel

Go bietet eine kompakte Syntax, die alle drei Schritte elegant zusammenfasst:

package main import "fmt" func main() { for i := 1; i <= 10; i++ { fmt.Printf("%2[1]v * %2[1]v ist %3v\n", i, i*i) } }
✓ Ergebnis: Beide Varianten erzeugen die exakt gleiche Ausgabe, aber die for-Klausel ist deutlich übersichtlicher und idiomatischer in Go!

Ausgabe beider Programme

1 * 1 ist 1 2 * 2 ist 4 3 * 3 ist 9 4 * 4 ist 16 5 * 5 ist 25 6 * 6 ist 36 7 * 7 ist 49 8 * 8 ist 64 9 * 9 ist 81 10 * 10 ist 100

🔧 Die drei Komponenten der for-Klausel

Die for-Klausel besteht aus drei Teilen, die durch Semikolons getrennt sind:

1️⃣ Init-Anweisung

i := 1

Wird einmalig zu Beginn ausgeführt. Typischerweise zur Deklaration und Initialisierung der Laufvariable.

2️⃣ Schleifenbedingung

i <= 10

Wird vor jedem Durchlauf geprüft. Bestimmt, ob die Schleife weiterläuft.

3️⃣ Post-Anweisung

i++

Wird nach jedem Durchlauf ausgeführt. Typischerweise zum Hochzählen der Laufvariable.

📝 Syntax:
for <Init-Anweisung>; <Schleifenbedingung>; <Post-Anweisung> { ... }

Wichtige Details zu den Komponenten

Init-Anweisung:
  • Muss eine einfache Anweisung (simple statement) sein
  • Typisch: Kurze Variablendeklaration mit :=
  • Wird genau einmal zu Beginn ausgeführt
  • Kommt danach nicht mehr zum Tragen
Post-Anweisung:
  • Muss eine einfache Anweisung sein
  • Aber: Keine kurze Variablendeklaration erlaubt!
  • Typisch: Inkrement (i++) oder Dekrement (i--)
  • Wird nach jedem Schleifendurchlauf ausgeführt
⚠️ Wichtig: Die Post-Anweisung wird immer erst nach der Ausführung des Schleifenrumpfes ausgeführt, also nach Abschluss eines Durchlaufs!

⚙️ Ausführungsablauf der for-Klausel

Schauen wir uns Schritt für Schritt an, wie die for-Klausel abgearbeitet wird:

Schritt 1: Init-Anweisung
i := 1
(nur einmal zu Beginn)
↓
Schritt 2: Bedingung prüfen
i <= 10
true? → weiter / false? → Ende
↓ (wenn true)
Schritt 3: Schleifenrumpf ausführen
fmt.Printf(...)
↓
Schritt 4: Post-Anweisung
i++
↓
⟲ Zurück zu Schritt 2

Beispiel-Durchlauf: Quadratzahlen von 1 bis 10

So läuft unsere Quadratzahlen-Schleife konkret ab:

Phase Wert von i Bedingung i ≤ 10 Aktion
Init 1 - Variable i wird deklariert und initialisiert
Durchlauf 1 1 true Ausgabe: "1 * 1 ist 1", dann i++ → i = 2
Durchlauf 2 2 true Ausgabe: "2 * 2 ist 4", dann i++ → i = 3
... weitere Durchläufe ...
Durchlauf 10 10 true Ausgabe: "10 * 10 ist 100", dann i++ → i = 11
Prüfung 11 false Schleife endet
🔍 Wichtige Beobachtung: Nach dem letzten Durchlauf (i = 10) wird noch einmal die Post-Anweisung ausgeführt (i → 11), bevor die Bedingung erneut geprüft wird und die Schleife endet.

🎯 Die Laufvariable

Die in der Init-Anweisung deklarierte Variable wird als Laufvariable (oder Kontrollvariable) bezeichnet.

Gültigkeitsbereich (Scope)

Außerhalb der Schleife: // i existiert hier NICHT
Innerhalb der for-Anweisung: for i := 1; i <= 10; i++ { // i ist hier gültig ✓ }
// i existiert hier NICHT mehr
📏 Gültigkeitsbereich: Die Laufvariable ist eine lokale Variable der Schleife. Ihr Gültigkeitsbereich erstreckt sich über:
  • Die gesamte for-Klausel (Init, Bedingung, Post)
  • Den gesamten Schleifenrumpf
  • Nach Beendigung der Schleife existiert sie nicht mehr!

Typische Bezeichner für Laufvariablen

In der Praxis werden sehr kurze Namen verwendet:

✓ Empfohlen

for i := 0; i < 10; i++ { ... } for j := 0; j < n; j++ { ... } for k := 0; k < m; k++ { ... }

i, j, k: Kurz und prägnant. Auf den ersten Blick als Laufvariablen erkennbar.

✗ Unüblich

for counter := 0; counter < 10; counter++ { ... } for index := 0; index < n; index++ { ... } for loopVar := 0; loopVar < m; loopVar++ { ... }

Zu ausführlich: Der Bezeichner ist länger als nötig für eine Variable mit sehr beschränktem Scope.

💡 Grundsatz: Je beschränkter der Gültigkeitsbereich einer Variablen ist, desto kürzer sollte ihr Bezeichner sein. Da Laufvariablen einen sehr lokalen Scope haben, sind i, j, k völlig ausreichend und idiomatisch!

🎓 Expertenwissen: Mehrere Variablen

Die for-Klausel erlaubt es, mehrere Variablen gleichzeitig zu verwenden:

Mehrere Variablen in Init-Anweisung

// Mehrere Variablen deklarieren und initialisieren for i, j := 0, 100; i < j; i, j = i+1, j-5 { fmt.Println("i, j:", i, j) }
🔍 Analyse:
  • Init: i, j := 0, 100 – Kurze Variablendeklaration für beide Variablen
  • Bedingung: i < j – Solange i kleiner als j ist
  • Post: i, j = i+1, j-5 – Tupel-Zuweisung für beide Variablen

Ausgabe des Programms

i, j: 0 100 i, j: 1 95 i, j: 2 90 i, j: 3 85 i, j: 4 80 i, j: 5 75 i, j: 6 70 i, j: 7 65 i, j: 8 60 i, j: 9 55 i, j: 10 50 i, j: 11 45 i, j: 12 40 i, j: 13 35 i, j: 14 30 i, j: 15 25 i, j: 16 20
📝 Letzte Ausgabe: Die Schleife endet mit der Zeile i, j: 16 20, denn danach gilt: 17 ist nicht mehr kleiner als 15 (j = 20 - 5 = 15).
✓ Anwendung: Solche Konstruktionen mit mehreren Laufvariablen werden häufig beim Arbeiten mit höherdimensionalen Arrays eingesetzt.

🎓 Expertenwissen: Optionale Komponenten

In Go sind alle drei Komponenten der for-Klausel optional! Dies zeigt, dass Go eigentlich nur eine Schleifenform hat, die aber verschiedene Schleifentypen abdeckt.

1. Weglassen von Init- und Post-Anweisung

Mit unnützen Semikolons

for ; i <= 10; { // ... }

Syntaktisch korrekt, aber umständlich.

Alternative Syntax (for-Bedingung)

for i <= 10 { // ... }

Eleganter: Die Semikolons dürfen wegfallen!

💡 Erkenntnis: Die for-Anweisung mit Bedingung (die wir im vorherigen Abschnitt kennengelernt haben) ist nichts anderes als eine syntaktisch vereinfachte for-Anweisung mit for-Klausel!

2. Weglassen der Schleifenbedingung → Endlosschleife

for { // Implizite Bedingung: true // Diese Schleife läuft unendlich! }
⚠️ Endlosschleife: Wenn die Schleifenbedingung weggelassen wird, interpretiert Go dies als for true { ... }. Die Schleife läuft endlos und muss auf andere Weise beendet werden (z.B. mit break oder os.Exit(0)).

Anwendungsfall: Event-Loop

Endlosschleifen sind besonders nützlich für Programme mit Event-Loops:

for { // Kontinuierlich Daten einlesen data := readData() if data == "exit" { break // Schleife beenden } processData(data) }

Zusammenfassung: Eine Schleife, viele Formen

Syntax Entspricht Verwendung
for i := 0; i < 10; i++ { } for-Klausel (vollständig) Zählende Schleifen
for i < 10 { } while-Schleife (andere Sprachen) Bedingte Schleifen
for { } Endlosschleife Event-Loops, Server
✓ Design-Philosophie von Go: Statt mehrerer verschiedener Schleifentypen (while, do-while, for, foreach) gibt es nur das for-Schlüsselwort. Dieses ist aber so flexibel, dass es alle Schleifenarten abdecken kann!

🌍 Vergleich mit anderen Programmiersprachen

Wie sehen for-Schleifen in anderen Sprachen aus?

🔷 Go

for i := 0; i < 10; i++ { fmt.Println(i) }

Semikolons zwischen den Komponenten. Keine Klammern um die for-Klausel!

🟨 JavaScript

for (let i = 0; i < 10; i++) { console.log(i); }

Sehr ähnlich zu Go, aber mit Klammern um die for-Klausel.

🐍 Python

for i in range(10): print(i)

Komplett anderer Ansatz mit range()-Funktion. Keine explizite for-Klausel.

☕ Java

for (int i = 0; i < 10; i++) { System.out.println(i); }

Ähnlich zu Go/JavaScript, aber mit expliziter Typangabe (int).

🔷 C++

for (int i = 0; i < 10; i++) { std::cout << i << std::endl; }

Identische Syntax zu Java. Klammern und explizite Typangabe erforderlich.

💎 Ruby

(0..9).each do |i| puts i end

Iterativer Ansatz mit Blöcken. Keine klassische for-Schleife.

🎯 Go's Ansatz: Go kombiniert die Übersichtlichkeit der C-artigen Syntax mit der Flexibilität, verschiedene Schleifentypen abzudecken – alles mit nur einem Schlüsselwort: for

✅ Best Practices

  • Verwende kurze Namen (i, j, k) für Laufvariablen in einfachen Schleifen
  • Deklariere Laufvariablen in der Init-Anweisung mit :=, nicht davor
  • Bevorzuge for-Klausel für zählende Schleifen – sie ist kompakter und idiomatischer als for-Bedingung
  • Nutze i++ in der Post-Anweisung für Inkremente, nicht im Schleifenrumpf
  • Vermeide Modifikationen der Laufvariable im Schleifenrumpf – das macht den Code unübersichtlich
  • Achte auf die Schleifenbedingung – verwende < oder <= je nach gewünschtem Verhalten
  • Nutze mehrere Laufvariablen nur wenn wirklich nötig – halte es einfach
  • Bei komplexen Schleifen sind aussagekräftigere Namen als i, j erlaubt
⚠️ Häufiger Fehler: Die Laufvariable außerhalb der Schleife verwenden wollen:
for i := 0; i < 10; i++ { // ... } fmt.Println(i) // ❌ FEHLER: i ist hier nicht mehr gültig!

📋 Zusammenfassung

  • ✓ Die for-Anweisung mit for-Klausel fasst Init, Bedingung und Post in einer Zeile zusammen
  • ✓ Syntax: for Init; Bedingung; Post { }
  • ✓ Die Init-Anweisung wird einmalig zu Beginn ausgeführt
  • ✓ Die Bedingung wird vor jedem Durchlauf geprüft
  • ✓ Die Post-Anweisung wird nach jedem Durchlauf ausgeführt
  • ✓ Die Laufvariable ist eine lokale Variable der Schleife
  • ✓ Typische Namen: i, j, k
  • ✓ Alle drei Komponenten sind optional – ermöglicht verschiedene Schleifenformen
  • ✓ Go hat nur for als Schleifenschlüsselwort, aber große Flexibilität
