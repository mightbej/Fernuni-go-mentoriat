Konstanten in Go

Eine Konstante ist ein Name für einen festen Wert. Die Seite zeigt, wie Go eine Konstante deklariert, wozu sie dient und welchen Typ sie hat.

Kurstext v3.0.6, Abschnitt 5.2, Seiten 124–126.

Worum es geht

Eine Konstante verbindet einen Namen mit einem Wert, der sich im ganzen Programm nicht ändert. Beispiel: const monateImJahr = 12.

Konstanten kamen im Kurstext schon dreimal vor, bevor sie in Abschnitt 5.2 vollständig behandelt werden:

  • Abschnitt 2.2, Seite 9, der Begriff: Eine Konstante ist eine Variable, deren Wert nie verändert wird. Das Beispiel dort ist die Zahl Pi. Der Wert, der wörtlich im Programm steht, heißt Literal. Dazu gibt es die Seite Variablen, Typen und Speicher, Schritt 2.
  • Abschnitt 3.3.3, Seiten 29–30, die erste Konstante in Go: Im ersten Go-Programm des Kurstexts steht die Deklaration const nullpunkt float64 = -273.15.
  • Abschnitt 4.1, Seiten 45–52, der konstante Ausdruck: Ein Ausdruck aus Literalen und Konstanten hat einen festen Wert. Der Compiler rechnet ihn schon beim Übersetzen aus. Beispiel: 8 + 7.

Die Seite geht in vier Schritten vor:

  • Schritt 1 zeigt die Deklaration: mit Typ, ohne Typ, mehrere Konstanten in einer Klammer. Dazu kommt der Vergleich mit der Variable.
  • Schritt 2 nennt die vier Zwecke, für die im Kurstext eine Konstante empfohlen wird.
  • Schritt 3 ist eine Aufgabe zum vierten Zweck: In einem Programm steht fünfmal die Zahl 12, und nur dreimal sind die Monate im Jahr gemeint.
  • Schritt 4 behandelt das Expertenwissen 5.6: Eine Konstante ohne Typangabe hat noch keinen der Typen int, uint8 oder float64.
Die Programme auf dieser Seite sind mit Go 1.26 ausgeführt. Ausgaben und Meldungen des Compilers stammen aus diesen Läufen. Auf der Seite selbst läuft kein Go.

Die Deklaration

Eine Konstante wird fast so deklariert wie eine Variable in der ausführlichen Form. Es gibt zwei Unterschiede:

  • Schlüsselwort: Die Deklaration beginnt mit const, bei einer Variable mit var.
  • Wert: Der Wert muss in der Deklaration stehen. Er lässt sich später nicht ändern.

Wie bei der Variable darf der Typ fehlen. Die ausführliche Deklaration einer Variable zeigt die Seite Variablendeklaration.

Vier Möglichkeiten zum Ausprobieren

Jeder Knopf zeigt eine Möglichkeit, maxAnzahl zu deklarieren. Darunter steht, was Go daraus macht: eine Ausgabe oder eine Meldung des Compilers.

Auszug aus dem Paket math von Go, im Kurstext in Abschnitt 5.2 abgedruckt.

    
In der Zeile Log2E = 1 / Ln2 steht rechts eine Rechnung mit einer anderen Konstante. Das ist erlaubt, weil 1 / Ln2 ein konstanter Ausdruck ist: Der Compiler kennt beide Werte und rechnet das Ergebnis beim Übersetzen aus.

Wozu eine Konstante

    
Im Kurstext werden vier Zwecke genannt. Zu jedem gehört dort eine Konstante als Beispiel.


    
1. Der Name ist verständlicher als die Zahl

    
Beispiel ist math.Pi. Die zwei Zeilen berechnen denselben Umfang eines Kreises:


umfang := 2 * math.Pi * radius
umfang := 2 * 3.141592653589793 * radius

    
In der ersten Zeile sagt der Name, welche Zahl gemeint ist. In der zweiten muss der Leser die Ziffernfolge erkennen und auf Tippfehler prüfen.


    
2. Ein häufig gebrauchter Wert wird nicht jedes Mal neu berechnet

    
Beispiel ist math.Log10E, der Logarithmus der eulerschen Zahl zur Basis 10, etwa 0,43429. Das Paket math deklariert ihn als Log10E = 1 / Ln10. Der Compiler rechnet die Division einmal beim Übersetzen aus. Ein Programm, das den Wert hundertmal braucht, dividiert kein einziges Mal.


    
3. Der Wert lässt sich an einer Stelle ändern

    
Beispiel ist const maxAnzahl = 500. Steht im Programm überall der Name, genügt für einen neuen Höchstwert eine Änderung in der Deklaration. Steht überall die Zahl 500, muss jede Stelle einzeln geändert werden, und eine vergessene Stelle rechnet mit dem alten Wert weiter.


    
4. Der Name sagt, was die Zahl bedeutet

    
Beispiel ist const monateImJahr = 12. Dieser Wert ändert sich nie, eine zentrale Stelle zum Ändern braucht er also nicht. Die Konstante lohnt sich aus einem anderen Grund: In einem Programm kann die Zahl 12 an mehreren Stellen stehen und Verschiedenes bedeuten.

    
    
      
  • Monate im Jahr: jahresgehalt := monatsgehalt * 12
    • 
      
  • Stunden auf der Uhr: stunde = stunde - 12
    • 
    

    
Wer überall monateImJahr schreibt, findet später alle Stellen, an denen die Monate gemeint sind, und nur diese. Schritt 3 zeigt das an einem Programm.

  

  

    
    
  

  


  

  

    
Die Zahl 12 suchen

    
Die Aufgabe stammt aus dem Kurstext: Angenommen, ein Jahr hätte 13 Monate. An welchen Stellen muss sich das Programm ändern?

    
Das Programm rechnet drei Werte aus:

    
    
      
  • Jahresgehalt: Das Monatsgehalt von 3000 wird mit der Zahl der Monate multipliziert.
    • 
      
  • Monatsbeitrag: Ein Jahresbeitrag von 1560 wird durch die Zahl der Monate geteilt.
    • 
      
  • Stunde auf der Uhr: Aus 15 Uhr wird 3 Uhr, weil das Zifferblatt nur 12 Stunden hat.
    • 
    

    
Die Demo zeigt zwei Programme. Im einen steht die Zahl der Monate als Literal 12, im anderen als Konstante monateImJahr.

    

      
      
    

    

      
      
      
      
    

    
Jede Zahl 12 im Programm ist ein Knopf: Ein Klick macht aus ihr eine 13, ein zweiter Klick wieder eine 12.

    
    
    
    
      Treffer der Suche
      Ausgabe des Programms
    
    
    
    

    
    Was die Aufgabe zeigt
    
    
      
      
    • Mit Literal: Die Suche nach 12 findet fünf Stellen. Bei jeder muss der Leser entscheiden, ob die Monate gemeint sind oder die Uhr.
      • 
      
    • Mit Konstante: Die Suche nach monateImJahr findet die Deklaration und die drei Stellen, an denen die Monate gemeint sind. Geändert wird nur die Deklaration.
      • 
    
    

    
    Faustregeln
    
    
      
      
    • Bedeutung: Ein Wert, der im Programm etwas Bestimmtes bedeutet und mehrfach vorkommt, bekommt eine Konstante.
      • 
      
    • Name: Der Name nennt die Bedeutung, zum Beispiel monateImJahr. Ein Name wie zwoelf hilft nicht.
      • 
      
    • Gruppe: Konstanten, die zusammengehören, stehen in einer Klammer.
      • 
      
    • Variable: Ein Wert, der sich im Lauf des Programms ändert, ist eine Variable.

    Nicht-typisierte Konstanten
    
    
    Dieser Schritt gehört zum Expertenwissen 5.6 des Kurstexts. Er beantwortet die Frage aus Schritt 1: Welchen Typ hat const maxAnzahl = 500?
    

    
    Auch ein Literal ist eine Konstante
    
    
    In Go heißt jeder Ausdruck mit festem Wert Konstante. Dazu gehören die Literale 736 und 0.6589.
    
    
    Ein solches Literal hat noch keinen der Typen, die eine Variable haben kann. Es hat einen eigenen Typ:
    
    
      
      
    • untyped integer: Das ist der Typ eines Integer-Literals wie 736.
      • 
      
    • untyped float: Das ist der Typ eines Floating-Point-Literals wie 0.6589.
      • 
    
    
    
    Das englische Wort dafür ist „untyped constant“, im Kurstext steht „nicht-typisierte Konstante“.
    

    
    Der Typ richtet sich nach der Umgebung
    
    
    Ein Wert vom Typ untyped integer nimmt den Typ an, den die Stelle verlangt, an der er steht. Verlangt die Stelle keinen bestimmten Typ, wird er zu int. Dieser Typ heißt Standardtyp.
    
    
    Das Programm verwendet das Literal 88 an drei Stellen. Jeder Knopf wählt eine davon:
    
    
    
      
      
      
    
    
    
      
    
      
      Typ von 88 an dieser Stelle
    
      
    
      

    
      Eine benannte Konstante ohne Typ
      
    
      Für eine benannte Konstante gilt dasselbe wie für das Literal, das ihr zugewiesen wird:
      
    
        
      
      • Ohne Typangabe: const maxAnzahl = 500 hat den Typ untyped integer. Der Typ passt sich erst bei der Verwendung an.
        • 
      
      • Mit Typangabe: const maxAnzahl int = 500 hat den Typ int und behält ihn.
        • 
    
      
    
      Der Unterschied zeigt sich, sobald die Konstante auf einen anderen Typ trifft:
      

      const ohneTyp = 500
const mitTyp int = 500

var x float64 = ohneTyp // erlaubt: 500 wird zu float64
var y float64 = mitTyp  // Fehler beim Übersetzen
      
    
      
      Meldung des Compilers zur letzten Zeilecannot use mitTyp (constant 500 of type int) as float64 value in variable declaration
    
      
    
      So war es schon in Schritt 3: Die Konstante monateImJahr hat dort keine Typangabe. Sie wird mit dem float64-Wert monatsgehalt multipliziert und an anderer Stelle als int ausgegeben.
      

    
      Der Compiler rechnet genauer als float64
      
    
      Eine nicht-typisierte Konstante ist an keinen Wertebereich gebunden, wie ihn int32 oder float64 haben. Daraus folgt:
      
    
        
      
      • Genauigkeit beim Übersetzen: Der Compiler rechnet mit nicht-typisierten Konstanten auf mindestens 256 Bit genau.
        • 
      
      • Viele Ziffern: math.Pi ist deshalb mit mehr als 60 Dezimalziffern deklariert. Ein float64 hält nur etwa 16 Dezimalziffern.
        • 
      
      • Rechnung nur aus Konstanten: Ein Ausdruck wie 2 * math.Pi enthält nur Konstanten. Der Compiler rechnet ihn mit der hohen Genauigkeit aus.
        • 
      
      • Verwendung: Erst wenn das Ergebnis mit einer Variable zusammentrifft, wird es an deren Typ angepasst, zum Beispiel an float64. Dabei gehen die überzähligen Ziffern verloren.
        •
