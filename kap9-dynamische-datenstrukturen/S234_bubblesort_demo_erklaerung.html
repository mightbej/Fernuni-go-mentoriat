S234: Bubblesort auf Verbund-Arrays

Erklaerung der Demo: Ablauf, Kernidee und verwendete Konzepte.

Einleitung

Die Demo sortiert ein Personen-Array nach Namen. Dazu vergleicht Bubblesort benachbarte Elemente und vertauscht sie bei falscher Reihenfolge.

Fokus

Algorithmusverhalten sichtbar machen: Vergleiche, Vertauschungen, Durchlaeufe.

Datenmodell

Ein Person-Verbund mit Name und Telefonnummer wird im Array verarbeitet.

Lernziel

Standard- und optimierte Variante sicher unterscheiden.

Was geschieht im Programm?

  • Ein unsortiertes Personen-Array wird aufgebaut.
  • Die Standard-Bubblesort-Funktion durchlaeuft das Array mehrfach.
  • Nach jedem Vergleich koennen zwei benachbarte Eintraege getauscht werden.
  • Zaehler protokollieren Vergleiche und Vertauschungen.
  • Eine optimierte Version bricht ab, sobald ein Durchlauf ohne Tausch endet.
Grundprinzip Bubblesort for i von 0 bis n-2: swapped = false for j von 0 bis n-2-i: wenn arr[j] > arr[j+1]: tauschen swapped = true wenn swapped == false: abbrechen

Welche Konzepte werden benutzt?

Verbund + Array

Sortiert wird nicht nur ein primitiver Wert, sondern ein Feld innerhalb eines Verbunds.

Komplexitaet

Standardfall: quadratischer Aufwand O(n^2), daher fuer grosse Datenmengen teuer.

Optimierung

Early-Exit reduziert Arbeit bei bereits (fast) sortierten Eingaben.

Einordnung

Die Demo zeigt den Preis einfacher Sortierung. Im Kapitelkontext liefert sie den Kontrast: Listen und Baeume verbessern genau dort, wo starre Arrays teuer werden.
