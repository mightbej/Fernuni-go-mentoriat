Verkettete Listen in Go

In einem sortierten Array rücken beim Einfügen viele Elemente einen Platz weiter. In einer verketteten Liste ändern sich zwei Zeiger, und jedes Element bleibt an seinem Platz im Speicher.

Kurstext v3.0.6, Abschnitt 9.1 und 9.2, Seiten 227–236.

Worum es geht

Eine dynamische Datenstruktur ändert sich, während das Programm läuft: Sie wächst mit jedem Element, das dazukommt. Ein Array kann das nicht, seine Länge steht bei der Übersetzung fest.

Die erste dynamische Datenstruktur des Kurstexts ist die einfach verkettete Liste. Jedes Element ist ein Verbund mit einem Wert und einem Zeiger auf das nächste Element. Im Kurstext steht dafür ein Güterzug: Jeder Wagon hängt mit einer Kupplung am nächsten.

Was dazugehört

  • Abschnitt 8.3.1, rekursive Verbund-Typen: Die Lektion Rekursive Verbund-Typen zeigt einen Verbund mit einem Zeiger auf den eigenen Typ und eine Schleife, die bis nil läuft. Darauf baut diese Lektion auf.
  • Abschnitt 8.2.4, Zeiger auf Verbünde: Die Lektion Zeiger auf Verbünde zeigt &person{…} und die Kurzschreibweise p.feld.
  • Abschnitt 7.4, Zeiger und nil: Die Lektion Zeiger in Go.
  • Kapitel 6, Arrays: Die Lektion Arrays in Go.

Die Schritte

  • Schritt 1: Du fügst einen Wert in ein sortiertes Array ein und zählst, wie viele Elemente weiterrücken.
  • Schritt 2: Du hängst ein Element in eine Kette ein. Zwei Zuweisungen genügen, ihre Reihenfolge entscheidet.
  • Schritt 3: Die zwei Verbund-Typen der Liste und die Liste im Hauptspeicher.
  • Schritt 4: Eine Schleife läuft von Element zu Element, bis der Zeiger nil ist.
  • Schritt 5: Du baust mit elementEinfügen die Liste des Kurstexts auf, Wert für Wert.
  • Schritt 6: Liste und Array im Vergleich.

Schritt 1: Einfügen im Array

Erst vorhersagen, dann ausprobieren
  1. Ein Array enthält sortiert die sechs Werte 3, 35, 42, 99, 111 und 176. Der Wert 1 soll dazu, das Array soll sortiert bleiben. Wie viele Elemente bekommen einen neuen Platz?
    AuflösungAlle sechs. Jedes rückt einen Platz nach hinten, das letzte zuerst.

Im Kurstext steht dafür ein Schrank mit Schubladen: In jeder Schublade liegen die Unterlagen einer Versicherung, sortiert nach der Versicherungsnummer. Kommt ein Vertrag mit einer kleinen Nummer dazu, wandern die Unterlagen aller größeren Nummern eine Schublade weiter.

Einem sortierten Array geht es genauso. Das Array hier hat acht Plätze, sechs sind belegt. Wähle den Wert, der dazukommt.

Was daran stört

  • Aufwand: Im ungünstigsten Fall rücken alle Elemente weiter, im Durchschnitt die Hälfte.
  • Große Elemente: Ist jedes Element ein Verbund mit vielen Feldern, schreibt das Programm bei jedem Weiterrücken alle Felder neu.
  • Feste Länge: Das Einfügen geht nur, solange das Array freie Plätze hat.

Am Ende von Abschnitt 9.1 steht ein erster Ausweg: Im Array liegen nur der Schlüsselwert und ein Zeiger auf einen Verbund mit den übrigen Daten. Dann rücken nur diese kleinen Elemente weiter. Die verkettete Liste geht einen Schritt weiter und kommt ohne Weiterrücken aus.

Schritt 2: Zwei Zuweisungen

Im Kurstext steht für die verkettete Liste ein Güterzug. Auf jedem Wagon steht ein Container mit einer Nummer, und die Wagons sind nach dieser Nummer sortiert: 3, 35, 42, 99, 111, 176. Ein weiterer Container mit der Nummer 50 soll mit.

Ein Eisenbahner lädt dafür keinen Container um. Er trennt den Zug hinter dem Wagon 42, hängt einen Wagon mit dem neuen Container an und kuppelt den Rest des Zugs wieder an.

So übersetzt sich der Zug in das Programm:

  • Wagon: Ein Element der Liste.
  • Containernummer: Der Wert des Elements.
  • Kupplung: Ein Zeiger im Element. Er enthält die Adresse des nächsten Elements.
  • Letzter Wagon: Sein Zeiger ist nil, es folgt kein Element.
Erst vorhersagen, dann ausprobieren
  1. Der neue Wagon 50 soll zwischen die Wagons 42 und 99. Im Programm sind dafür zwei Zeiger zu setzen. Angenommen, zuerst bekommt der Wagon 42 den neuen Wagon angekuppelt. Was geschieht im Programm mit dem Wagon 99?
    AuflösungDas Programm findet ihn nicht mehr. Die Adresse des Wagons 99 stand nur im Zeiger des Wagons 42, und dort steht jetzt die Adresse des neuen Wagons. Bei der Eisenbahn stünde der Rest des Zugs noch auf dem Gleis. Im Speicher ist ein Element ohne Adresse nicht wiederzufinden.

Die zwei Demos zeigen einen kurzen Zug als Kette mit den drei Elementen 35, 42 und 99. Das neue Element mit dem Wert 50 gehört hinter das Element 42. Der Zeiger aktuelles zeigt schon auf dieses Element.

      Schritt 3: Der Typ der Liste

      Erst vorhersagen, dann ausprobieren
      1. Eine Liste enthält die Werte 2, 8, 12 und 17 in dieser Reihenfolge. Liegen ihre Elemente auch im Hauptspeicher in dieser Reihenfolge?
        AuflösungDas muss nicht sein. Jedes Element liegt dort, wo beim Erzeugen Platz war. Die Reihenfolge der Liste steht allein in den Zeigern.

      Die Liste des Kurstexts braucht zwei Verbund-Typen:

      // Verbund-Typ für ein Listen-Element
type listenElement struct {
    wert     int
    nächstes *listenElement
}

// Verbund-Typ für eine Liste
type sortierteListe struct {
    kopf *listenElement
}
      • listenElement: Ein Element der Liste, im Bild des Kurstexts ein Wagon. Das Feld wert ist die Containernummer, das Feld nächstes die Kupplung. Der Typ ist ein rekursiver Verbund-Typ.
      • sortierteListe: Die Liste selbst, im Bild des Kurstexts die Lokomotive. Ihr einziges Feld kopf zeigt auf das erste Element. Bei einer leeren Liste ist kopf gleich nil.

      Eine leere Liste entsteht so:

      liste := &sortierteListe{} // leere Liste erzeugen

      Die Variable liste ist ein Zeiger auf einen Verbund ohne Namen. Einen solchen Verbund nennt der Kurstext anonyme Variable. Auch jedes Element der Liste ist eine anonyme Variable, erzeugt mit &listenElement{wert: neuerWert}.

      Die Liste im Hauptspeicher

      Das Bild zeigt die Liste, nachdem das Programm des Kurstexts die Werte 8, 17, 12 und 2 eingefügt hat. Oben steht die Liste als Kette, darunter stehen die Blöcke im Hauptspeicher des Modells. Die Adressen sind erfunden.

      • Größe: Ein int und ein Zeiger belegen im Modell je 8 Zellen. Ein listenElement belegt 16 Zellen, eine sortierteListe 8.
      • Reihenfolge im Speicher: Die Elemente liegen in der Reihenfolge, in der sie erzeugt wurden: 8, 17, 12, 2.
      • Reihenfolge der Liste: Sie ergibt sich aus den Zeigern. kopf enthält 248, dort liegt die 2. Deren Feld nächstes enthält 200, dort liegt die 8. So geht es weiter bis zum Element 17 mit nil.

      Schritt 4: Durchlaufen

      Erst vorhersagen, dann ausprobieren
      1. In einem Array führt a[2] ohne Umweg zum dritten Element. Wie kommt ein Programm zum dritten Element einer verketteten Liste?
        AuflösungNur über die zwei Elemente davor. Es beginnt bei kopf und folgt zweimal dem Feld nächstes.

      Die Funktion listeAusgeben gibt alle Werte der Liste aus. Sie bekommt einen Zeiger auf die Liste. Ihre Variable element ist ein Zeiger, der von Element zu Element wandert.

      Die Liste enthält hier die Werte 2, 8, 12 und 17, wie in Schritt 3.

        Ausgabe

        Die Funktion längeDerListe läuft auf die gleiche Art durch die Liste und zählt dabei:

        // liefert die Länge der Liste (d.h. die Anzahl ihrer Elemente) zurück
func längeDerListe(liste *sortierteListe) int {
    länge := 0
    element := liste.kopf
    for element != nil {
        länge++
        element = element.nächstes
    }
    return länge
}

        Wie lang die Liste ist, steht in keinem Feld. Das Programm erfährt es nur, indem es alle Elemente besucht.

        Schritt 5: Einfügen

        Erst vorhersagen, dann ausprobieren
        1. Die Liste enthält 2, 8, 12, 17 und 23. Der Wert 20 soll dazu. Bei welchem Element bleibt der Zeiger aktuelles stehen?
          AuflösungBeim Element 17. Sein Nachfolger 23 ist nicht kleiner als 20, also gehört das neue Element zwischen 17 und 23.

        Die Funktion elementEinfügen fügt einen Wert so ein, dass die Liste aufsteigend sortiert bleibt. Sie unterscheidet zwei Fälle:

        • Am Anfang: Die Liste ist leer, oder der neue Wert ist kleiner oder gleich dem Wert im Kopf. Dann wird das neue Element der Kopf der Liste.
        • Weiter hinten: Der Zeiger aktuelles beginnt beim Kopf und rückt weiter, solange es einen Nachfolger gibt und dessen Wert kleiner ist als der neue Wert. Danach folgen die zwei Zuweisungen aus Schritt 2.
        func elementEinfügen(liste *sortierteListe, neuerWert int) {
    if liste.kopf == nil || neuerWert <= liste.kopf.wert {
        // neues Element vor dem bisherigen Listen-Kopf einfügen
        neues := &listenElement{wert: neuerWert} // Element erzeugen
        neues.nächstes = liste.kopf
        liste.kopf = neues
        return
    }

    aktuelles := liste.kopf
    for aktuelles.nächstes != nil &&
        aktuelles.nächstes.wert < neuerWert {
        aktuelles = aktuelles.nächstes
    }

    // neues Element zwischen dem aktuellen Element und
    // seinem Nachfolger einfügen
    neues := &listenElement{wert: neuerWert} // Element erzeugen
    neues.nächstes = aktuelles.nächstes
    aktuelles.nächstes = neues
}

        Im Kurstext meldet die Funktion mit fmt.Printf außerdem, wohin das Element kommt. Diese Zeilen fehlen hier, die Demo zeigt die Meldungen als Ausgabe.

        In beiden Bedingungen kommt es auf die Reihenfolge an. Go wertet || und && von links aus und hört auf, sobald das Ergebnis feststeht. So liest das Programm liste.kopf.wert nur, wenn kopf auf ein Element zeigt. Das steht in der Lektion Wahrheitswerte und Kurzschluss-Auswertung.

        Die Liste des Kurstexts entsteht

        Das Programm fügt nacheinander die Werte 8, 17, 12, 2, 23, 20, 17, 5 und 14 ein. Eine Anweisung der Demo ist ein ganzer Aufruf. Gelb ist das neue Element, grün umrandet das Element, bei dem aktuelles stehen geblieben ist.

          Ausgabe

          Der Wert 17 kommt zweimal vor. Die Liste darf gleiche Werte enthalten. Das zweite Element 17 steht vor dem ersten, weil die Schleife nur weiterrückt, solange der Nachfolger kleiner ist.

          Schritt 6: Liste und Array

          FrageSortiertes ArraySortierte verkettete Liste
          Was geschieht beim Einfügen?Die Elemente hinter der Stelle rücken einen Platz weiter, im Durchschnitt die Hälfte.Zwei Zeiger bekommen einen neuen Wert. Kein Element wechselt seinen Platz im Speicher.
          Wie findet das Programm die Stelle?Das Programm kann jeden Index ohne Umweg lesen. Deshalb geht die binäre Suche aus Abschnitt 8.4.1.Das Programm läuft vom Kopf aus von Element zu Element, im Durchschnitt durch die halbe Liste.
          Wie viele Elemente passen hinein?Die Länge steht bei der Übersetzung fest.Die Liste wächst mit jedem Element und belegt nur den Speicher, den sie gerade braucht.
          Was kostet ein Element an Speicher?Ein Element belegt nur seine eigenen Zellen.Zu jedem Element kommt ein Zeiger, im Modell 8 Zellen.

          Das Einfügen selbst ist in der Liste billig, das Suchen der Stelle nicht. Im Kurstext folgt deshalb in Abschnitt 9.3 der binäre Suchbaum, in dem auch das Suchen schnell geht.

          Zum Weiterdenken

          Im Kurstext werden weitere Operationen genannt und nicht ausgeführt. Zu diesen Aufgaben gibt es hier keine Lösung.

          • Suchen: Schreibe eine Funktion istWertInListe(liste *sortierteListe, suchwert int) bool. Wann darf die Schleife in einer sortierten Liste vorzeitig aufhören?
          • Löschen: Schreibe eine Funktion, die das erste Element mit einem bestimmten Wert aus der Liste nimmt. Welcher Zeiger bekommt einen neuen Wert, und welcher Fall braucht eine eigene Behandlung?
          • Umdrehen: Schreibe eine Funktion, die die Liste umdreht: Das erste Element wird das letzte, das zweite das vorletzte.

          Nächste Schritte

          • Abschnitt 9.3: Die Lektion Binäre Suchbäume in Go. Dort hat jeder Verbund zwei Zeiger.
          • Exkurs: Die Lektion Blockchain: eine verkettete Liste mit Fingerabdruck macht aus der Liste ein Kassenbuch: Jeder neue Block zeigt auf seinen Vorgänger und trägt dessen Fingerabdruck.
          • Laufzeit: Der Exkurs Wie die Laufzeit mit der Datenmenge wächst.
