Variable in Mathematik und Informatik

Das Wort „Variable“ bedeutet in der Mathematik und in der Informatik Verschiedenes. Links steht die Gleichung aus dem Kurstext, rechts ein Programm mit drei Anweisungen.

Jede Variable hat einen Typ. Der Typ legt zwei Eigenschaften fest:

  • Werte: Der Typ sagt, welche Werte die Variable annehmen kann.
  • Operatoren: Der Typ sagt, mit welchen Operatoren man solche Werte verknüpfen darf.

Eine Zeichenkette lässt sich nicht multiplizieren, und zwei ganze Zahlen lassen sich nicht aneinanderhängen. Welche Operation erlaubt ist, hängt also am Typ.

Zwei Typen in einer Rechnung: die Konversion

In einer Rechnung können zwei Typen aufeinandertreffen. Beispiel: Die Variable n hat den Typ ganze Zahl und den Wert 17. Die Variable y hat den Typ Gleitkommazahl und den Wert 0,5. Das Programm soll n + y ausrechnen.

Die Addition gibt es für ganze Zahlen und für Gleitkommazahlen, aber jeweils nur für zwei Werte desselben Typs. Der Wert von n wird deshalb erst in den anderen Typ überführt: Aus der ganzen Zahl 17 wird die Gleitkommazahl 17,0. Danach ergibt die Addition 17,5. Die Variable n selbst behält ihren Typ und ihren Wert.

Das Überführen eines Werts in einen anderen Typ heißt Konversion.

Wer die Konversion vornimmt, hängt von der Programmiersprache ab:

  • Implizit: In manchen Sprachen nimmt der Rechner die Konversion von selbst vor, ohne dass sie im Programm steht. Die Programme werden kurz, enthalten aber leicht versteckte Fehler.
  • Explizit: In einer streng typisierten Sprache schreibt der Programmierer die Konversion ins Programm. Go ist eine streng typisierte Sprache.

Zusammengesetzte Typen

Aus einfachen Typen lassen sich größere Typen bauen. Im Kurstext werden zwei Arten genannt:

  • Vektor: Ein Vektor reiht mehrere Werte desselben Typs aneinander. Beispiel: fünf Messwerte, jeder eine ganze Zahl.
  • Datenverbund: Ein Datenverbund fasst Werte zusammen, die zusammengehören und verschiedene Typen haben dürfen. Beispiel: die Angaben zu einer Person.

Ein Klick auf ein Element oder auf ein Feld zeigt seinen Typ und wozu es gehört.

Eine Variable ist Speicherplatz

Jede Variable belegt im Rechner Speicherplatz. Der Speicherplatz besteht aus binären Speicherelementen. Ein binäres Speicherelement kann genau zwei Werte annehmen: 0 oder 1.

Die Variable hier belegt acht Speicherelemente. Über jedem steht seine Wertigkeit: Eine 1 an dieser Stelle zählt so viel, wie darübersteht.

Was die Demo zeigt:

  • Beschreiben: Ein Speicherelement hat erst einen definierten Wert, wenn es beschrieben wurde. Danach lässt es sich immer wieder neu beschreiben.
  • Zuweisen: Eine Zuweisung an die Variable beschreibt alle ihre Speicherelemente auf einmal.
  • Lesen: Dieselbe Folge aus 0 und 1 bedeutet je nach Typ etwas anderes. Der Typ sagt, wie die Folge zu lesen ist.
Bei einem einfachen Typ steht fest, wie viele Speicherelemente eine Variable belegt. Hier sind es acht. Andere Typen belegen 16, 32 oder 64.

Die Deklaration

Bevor ein Programm eine Variable benutzt, deklariert es sie. Die Deklaration legt fest:

  • Name: Die Variable bekommt einen Namen. Jeden Namen gibt es nur einmal.
  • Typ: Die Deklaration nennt den Typ der Variable. Aus dem Typ ergibt sich, wie viele Speicherelemente die Variable braucht.
  • Speicherplatz: Der Rechner stellt diese Speicherelemente bereit. Das Fachwort dafür ist „allokieren“. Über den Namen spricht das Programm den Speicherplatz an.
  • Anfangswert: Oft bekommt die Variable gleich einen ersten Wert. Fehlt er, stehen in den Speicherelementen noch die Werte aus ihrer vorherigen Nutzung. Die Variable heißt dann undefiniert. Für diesen Zustand stehen in der Demo die Fragezeichen.
