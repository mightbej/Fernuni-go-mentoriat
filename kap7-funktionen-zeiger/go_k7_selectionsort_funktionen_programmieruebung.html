Programmierübung: Selection Sort mit Funktionen

Selection Sort sucht in jeder Runde das kleinste Element des Rests und tauscht es nach vorn. Diese Übung macht aus der Suche die Funktion findMin und aus dem Tausch die Funktion swap.

Kurstext v3.0.6, Abschnitt 7.1 und 7.2, Seiten 163–170. Selection Sort kommt im Kurstext nicht vor.

Worum es geht

Die Programmierübung Sortieren mit Selection Sort endet mit diesem Kern:

for pos := 0; pos < len(a)-1; pos++ {
    minIndex := pos
    for i := pos + 1; i < len(a); i++ {
        if a[i] < a[minIndex] {
            minIndex = i
        }
    }
    if minIndex != pos {
        a[pos], a[minIndex] = a[minIndex], a[pos]
    }
}

Eine Runde hat zwei Teile. Jeder Teil wird eine Funktion:

  • Die Suche nach dem kleinsten Element ab dem Index pos wird zur Funktion findMin. Sie nimmt die ganze innere Schleife auf.
  • Der Tausch zweier Elemente wird zur Funktion swap.

Die äußere Schleife in main schrumpft auf drei Zeilen.

Schritt 1: Die Suche als Funktion

Erst vorhersagen, dann ausprobieren
  1. Das Array ist [42 7 19 88 3 25 71 14 60 9]. Was liefert findMin(a, 0)?
    Auflösung4. Die Funktion liefert den Index des kleinsten Elements und nicht seinen Wert. Die 3 steht am Index 4.
// liefert den Index des kleinsten Elements ab dem Index pos
func findMin(a [10]int, pos int) int {
    minIndex := pos
    for i := pos + 1; i < len(a); i++ {
        if a[i] < a[minIndex] {
            minIndex = i
        }
    }
    return minIndex
}
  • Parameter: das Array und der Index pos, ab dem gesucht wird.
  • Lokale Variable: minIndex ist der Kandidat. Die Variable gehört jetzt der Funktion und ist in main nicht sichtbar.
  • Rückgabe: ein int, der Index des kleinsten Elements. Mit dem Index kann der Aufrufer tauschen, mit dem Wert allein könnte er es nicht.

Die Funktion liest das Array und ändert es nicht. Dass sie eine Kopie bekommt, stört das Ergebnis deshalb nicht.

Schritt 2: Der Tausch als Funktion

Erst vorhersagen, dann ausprobieren
  1. Bubble Sort tauscht immer zwei Nachbarn. Wie viele Indizes braucht die Funktion swap für Selection Sort?
    AuflösungZwei. Selection Sort tauscht das Element am Index pos mit dem kleinsten Element, und das kann an jedem Index dahinter stehen.
// liefert eine Kopie des Arrays, in der die Elemente
// an den Indizes i und j getauscht sind
func swap(a [10]int, i int, j int) [10]int {
    a[i], a[j] = a[j], a[i]
    return a
}

Die Funktion bekommt eine Kopie des Arrays. Sie gibt ihre geänderte Kopie zurück, und der Aufrufer weist sie zu. Eine Runde lautet damit:

minIndex := findMin(a, pos)
if minIndex != pos {
    a = swap(a, pos, minIndex)
}

Die Zeilen lesen sich so: Suche das kleinste Element ab pos. Steht es nicht schon am Index pos, dann tausche es dorthin.

Schritt 3: Runde für Runde

Erst vorhersagen, dann ausprobieren
  1. Das Programm läuft neun Runden und tauscht siebenmal. Wie viele Elemente kopiert der Rechner für die Aufrufe von findMin und swap?
    Auflösung230. Neun Aufrufe von findMin kopieren je 10 Elemente. Sieben Aufrufe von swap kopieren je 20: zehn hin und zehn zurück.

Die Demo führt das ganze Sortieren aus, einen Aufruf nach dem anderen. Sie zeigt für jeden Aufruf den Rahmen der Funktion mit ihrer Kopie des Arrays und zählt die kopierten Elemente mit.

    Ausgabe

    Die Demo zeigt die Schleifen nicht Anweisung für Anweisung, sie zeigt jeden Aufruf einer Funktion. Wie findMin das Minimum Vergleich für Vergleich findet, zeigt Schritt 2 der Programmierübung zu Kapitel 6.

    Schritt 4: Das ganze Programm

    package main

import "fmt"

// liefert den Index des kleinsten Elements ab dem Index pos
func findMin(a [10]int, pos int) int {
    minIndex := pos
    for i := pos + 1; i < len(a); i++ {
        if a[i] < a[minIndex] {
            minIndex = i
        }
    }
    return minIndex
}

// liefert eine Kopie des Arrays, in der die Elemente
// an den Indizes i und j getauscht sind
func swap(a [10]int, i int, j int) [10]int {
    a[i], a[j] = a[j], a[i]
    return a
}

func main() {
    a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9}
    fmt.Println("Start:", a)

    for pos := 0; pos < len(a)-1; pos++ {
        minIndex := findMin(a, pos)
        if minIndex != pos {
            a = swap(a, pos, minIndex)
        }
        fmt.Printf("Nach Runde %d: %v\n", pos+1, a)
    }

    fmt.Println("Sortiert:", a)
}

    Ausgabe

    Start: [42 7 19 88 3 25 71 14 60 9] Nach Runde 1: [3 7 19 88 42 25 71 14 60 9] Nach Runde 2: [3 7 19 88 42 25 71 14 60 9] Nach Runde 3: [3 7 9 88 42 25 71 14 60 19] Nach Runde 4: [3 7 9 14 42 25 71 88 60 19] Nach Runde 5: [3 7 9 14 19 25 71 88 60 42] Nach Runde 6: [3 7 9 14 19 25 71 88 60 42] Nach Runde 7: [3 7 9 14 19 25 42 88 60 71] Nach Runde 8: [3 7 9 14 19 25 42 60 88 71] Nach Runde 9: [3 7 9 14 19 25 42 60 71 88] Sortiert: [3 7 9 14 19 25 42 60 71 88]

    Die Bilanz

    • Lesbarkeit: In main steht nur noch die äußere Schleife. Jede Runde nennt ihre zwei Teile beim Namen.
    • Aufwand: Das Programm vergleicht 45-mal und tauscht siebenmal, wie das Programm aus Kapitel 6. Dazu kommen die Kopien: 9 · 10 + 7 · 20 = 230 kopierte Elemente.
    • Vergleich mit Bubble Sort: Das Programm mit isGreater und swap kopiert 910 Elemente. Selection Sort ruft seine Funktionen viel seltener auf.

    Die Programmierübung Selection Sort mit Zeigern schafft die Kopien ab.
