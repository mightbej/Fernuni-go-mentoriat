Das Kopier-Problem: Arrays als Argument

Eine Funktion bekommt ein Array als Kopie. Wer zwei Elemente mit einer Funktion tauschen will, kopiert dafür das ganze Array hin und zurück. Die Seite zählt, wie viele Elemente das beim Sortieren sind.

Kurstext v3.0.6, Abschnitt 7.2, Seiten 169–170, und Abschnitt 7.3, Seiten 171–172.

Worum es geht

In Abschnitt 7.2 des Kurstexts steht: Bei jedem Funktionsaufruf mit einem Array als Argument erstellt der Rechner eine Kopie des ganzen Arrays, und das kostet Rechenzeit und Speicherplatz. Dieser Exkurs rechnet das an einem Beispiel aus.

Das Beispiel ist eine Funktion swap. Sie tauscht zwei Elemente eines Arrays. Die Sortierprogramme aus Kapitel 6 tauschen mit einer Tupel-Zuweisung in main. Wer den Tausch in eine Funktion auslagert, stößt auf die Kopie.

Was dazugehört

  • Abschnitt 7.2, Wertübergabe: Die Lektion Funktionen in Go zeigt in Schritt 5 Listing 7.1 mit der Funktion negToZeroValue.
  • Abschnitt 7.3, Zeiger als Parameter: Die Lektion Zeiger in Go zeigt in Schritt 1 Listing 7.2 mit der Funktion negToZeroPointer.
  • Kapitel 6, Sortieren: Die Programmierübungen Sortieren mit Bubble Sort und Sortieren mit Selection Sort sortieren das Array dieser Seite.

Die Schritte

  • Schritt 1: Du führst einen Aufruf von swap aus und zählst die kopierten Elemente.
  • Schritt 2: Du wählst die Länge des Arrays und siehst, wie viele Elemente ein ganzes Sortieren kopiert.
  • Schritt 3: Die Fassung mit einem Zeiger kopiert eine Adresse und kein Element.
Die Seite zählt Elemente, die das Programm nach den Regeln von Go kopiert. Wie lange das auf einem bestimmten Rechner dauert, misst sie nicht. Ein Compiler darf eine Kopie einsparen, wenn das Ergebnis das gleiche bleibt.

Schritt 1: Ein Tausch, zwei Kopien

Erst vorhersagen, dann ausprobieren
  1. Die Funktion swap(a [10]int, i int, j int) [10]int tauscht zwei Elemente und gibt das Array zurück. Wie viele Elemente kopiert der Rechner für die Zeile a = swap(a, 0, 1)?
    Auflösung20. Beim Aufruf kopiert er zehn Elemente in den Parameter. Bei der Zuweisung der Rückgabe kopiert er zehn Elemente zurück.
  2. Was gibt fmt.Println(a) aus, wenn in main nur swap(a, 0, 1) steht, ohne a = davor?
    Auflösung[42 7 19 88 3 25 71 14 60 9]. Die Funktion hat ihre Kopie geändert, und die Rückgabe ist verworfen. Das Array in main ist unverändert.

Die Funktion bekommt das Array als Kopie. Ihr Tausch ändert die Kopie. Damit main etwas davon hat, gibt die Funktion die geänderte Kopie zurück, und main weist sie der Variable a zu.

    Ausgabe

    Die Funktion ändert zwei Elemente. Kopiert hat der Rechner dafür zwanzig.

    Der Hauptspeicher unter den Rahmen zeigt, was das im Modell heißt: Ein int belegt 8 Zellen, das Array a also die 80 Zellen von 100 bis 179. Für den Parameter der Funktion kommen die 80 Zellen von 180 bis 259 dazu, und der Rechner füllt sie mit einer Kopie. Die Adressen sind erfunden.

    Schritt 2: Wie viel kopiert wird

    Erst vorhersagen, dann ausprobieren
    1. Ein Array hat 1000 Elemente. Selection Sort tauscht höchstens 999-mal. Wie viele Elemente kopiert swap dafür höchstens?
      Auflösung999 · 2000 = 1.998.000. Jeder Aufruf kopiert 1000 Elemente hin und 1000 zurück.

    Ein Aufruf von swap kopiert das Array zweimal. Bei einem Array der Länge n sind das 2 · n Elemente. Ein Sortierprogramm ruft swap viele Male auf. Lagert es auch den Vergleich oder die Suche nach dem Minimum in eine Funktion aus, kopiert jeder dieser Aufrufe das Array noch einmal.

    • Selection Sort mit findMin und swap: n − 1 Runden. In jeder Runde kopiert findMin n Elemente, und swap kopiert höchstens einmal 2 · n Elemente.
    • Bubble Sort mit isGreater und swap: n · (n − 1) / 2 Vergleiche. Jeder Vergleich kopiert in isGreater n Elemente. Auf jeden Vergleich folgt höchstens ein Tausch mit 2 · n Elementen.

    Wähle die Länge des Arrays:

    Die Zahlen sind Obergrenzen: So viel kopiert das Programm, wenn auf jeden Vergleich und in jeder Runde ein Tausch folgt. Für das Array der Programmierübungen mit zehn Elementen sind es weniger:

    • Bubble Sort: 45 Vergleiche und 23 Tausche. Das sind 45 · 10 + 23 · 20 = 910 kopierte Elemente.
    • Selection Sort: 9 Runden und 7 Tausche. Das sind 9 · 10 + 7 · 20 = 230 kopierte Elemente.

    Die Zahl der kopierten Elemente wächst schneller als die Länge des Arrays. Was das bedeutet, zeigt der Exkurs Laufzeit und Datenmenge.

    Schritt 3: Mit einem Zeiger

    Erst vorhersagen, dann ausprobieren
    1. Die Funktion swap(pa *[10]int, i int, j int) bekommt die Adresse des Arrays. Wie viele Elemente kopiert der Rechner für den Aufruf swap(&a, 0, 1)?
      AuflösungKeines. Er kopiert eine Adresse und die zwei Indizes.

    Die Fassung mit einem Zeiger ändert drei Stellen:

    • Parameter: pa *[10]int ist ein Zeiger auf ein Array und kein Array.
    • Rückgabe: Sie entfällt. Die Funktion ändert das Array ihres Aufrufers.
    • Aufruf: swap(&a, 0, 1) übergibt die Adresse von a. Die Zuweisung a = … entfällt.

    Im Rumpf steht pa[i]. Das ist die Kurzschreibweise für (*pa)[i] aus Hinweis 7.4 des Kurstexts.

      Ausgabe

      Im Hauptspeicher unter den Rahmen belegt der Parameter pa jetzt 8 Zellen, die Zellen 180 bis 187. In ihnen steht die Zahl 100, die Adresse des Arrays. Das Array selbst gibt es nur einmal, in den Zellen 100 bis 179. Für ein Array mit einer Million Elementen wären es auch 8 Zellen.

      Der Vergleich

      Frageswap mit einer Kopieswap mit einem Zeiger
      Was bekommt die Funktion?Sie bekommt eine Kopie des Arrays.Sie bekommt die Adresse des Arrays.
      Wie viele Elemente kopiert ein Aufruf?Er kopiert 2 · n Elemente.Er kopiert kein Element.
      Welches Array ändert die Funktion?Sie ändert ihre Kopie.Sie ändert das Array des Aufrufers.
      Was muss der Aufrufer tun?Er weist die Rückgabe zu: a = swap(a, 0, 1).Er übergibt die Adresse: swap(&a, 0, 1).
      Was geschieht ohne diese Sorgfalt?Fehlt a =, bleibt das Array unverändert, und Go meldet nichts.Fehlt &, übersetzt Go das Programm nicht.
      Auch der Zeiger wird kopiert, denn Go kennt nur call-by-value. Die Kopie einer Adresse ist aber immer gleich groß, gleich wie lang das Array ist.
