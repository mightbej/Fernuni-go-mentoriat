Ausgangspunkt: Selection Sort aus dem vorigen Kapitel

Das ist der Code aus Selection Sort (ohne Funktionen). Jetzt zerlegen wir ihn in benannte Funktionen:

package main import "fmt" func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pos := 0; pos < len(a)-1; pos++ { min := pos for i := pos + 1; i < len(a); i++ { if a[i] < a[min] { min = i } } if min != pos { a[pos], a[min] = a[min], a[pos] } fmt.Printf("Nach Runde %d: %v\n", pos+1, a) } fmt.Println("Sortiert:", a) }
Neues Ziel: Wir verändern den Algorithmus nicht. Wir zerlegen ihn nur in benannte Teilaufgaben, genau wie bei Bubble Sort.

Wiederholung: Was ist eine Funktion?

Eine Funktion ist ein benannter Programmbaustein. Sie kann Werte übernehmen, etwas berechnen oder ausführen und optional Werte zurückgeben.

Bestandteil Beispiel Bedeutung
Funktionsname findMin Benannter Teilschritt des Programms
Parameter a [10]int, start int Werte, die die Funktion beim Aufruf bekommt
Rückgabetyp int Typ des Ergebnisses
return return minIdx liefert das Ergebnis zurück
Wichtig: In diesem Block geht es um Funktionen. Zeiger und Rekursion folgen später.

Selection Sort verstehen: Die innere Schleife

Der Kern von Selection Sort ist: Finde das Minimum-Element ab einer Position (in unserem Code: ab Position pos).

min := pos for i := pos + 1; i < len(a); i++ { if a[i] < a[min] { min = i } } // min zeigt jetzt auf das kleinste Element von pos bis zum Ende
Dieser Ablauf wiederholt sich: Die innere Schleife durchsucht den unsortierten Teil und findet das Minimum-Index. Das ist perfekt für eine Funktion.

Erste Auslagerung: Minimum-Funktion

Wir lagern die Suche nach dem Minimum aus:

func findMin(a [10]int, pos int) int { min := pos for i := pos + 1; i < len(a); i++ { if a[i] < a[min] { min = i } } return min }

Schleifen in Funktionen

Diese Funktion gibt den Index des kleinsten Elements zurück, ab einer Start-Position:

min := findMin(a, pos)

Zweite Auslagerung: Tauschfunktion

Das Tauschen zweier Elemente ist auch wiederverwendbar.

a[pos], a[min] = a[min], a[pos]

Da Arrays in Go als Wert übergeben werden, gibt die Funktion das geänderte Array zurück.

func swap(a [10]int, i int, j int) [10]int { a[i], a[j] = a[j], a[i] return a }
Didaktischer Punkt: Diese Funktion hat zwei Indizes. Sie tauscht zwei beliebige Positionen, nicht nur benachbarte.
a = swap(a, pos, min)

Refactoring: Selection Sort liest sich jetzt klarer

Die Sortierlogik mit Funktionen wird deutlich verständlicher:

Vorher

min := pos for i := pos + 1; i < len(a); i++ { if a[i] < a[min] { min = i } } a[pos], a[min] = a[min], a[pos]

Nachher

min := findMin(a, pos) a = swap(a, pos, min)
Interpretation: Finde das Minimum ab Position pos, dann tausche es mit Position pos.
Wichtig: Der Code ist jetzt viel prägnanter. Wer Selection Sort nicht kennt, versteht die Absicht sofort.

Vollständiger Code: Selection Sort mit Funktionen

package main import "fmt" func findMin(a [10]int, pos int) int { min := pos for i := pos + 1; i < len(a); i++ { if a[i] < a[min] { min = i } } return min } func swap(a [10]int, i int, j int) [10]int { a[i], a[j] = a[j], a[i] return a } func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pos := 0; pos < len(a)-1; pos++ { min := findMin(a, pos) a = swap(a, pos, min) fmt.Printf("Nach Runde %d: %v\n", pos+1, a) } fmt.Println("Sortiert:", a) }
Vergleich zu Bubble Sort: Selection Sort hat eine andere Struktur: statt mehrfach zu vergleichen, suchen wir gezielt das Minimum. Mit Funktionen wird dieser unterschiedliche Algorithmus genauso deutlich wie Bubble Sort.
