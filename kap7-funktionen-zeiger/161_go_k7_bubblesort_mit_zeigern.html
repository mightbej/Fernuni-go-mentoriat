Ausgangspunkt: Bubble Sort mit Funktionen

Das ist der Stand aus dem vorigen Block. Der Bubble-Sort-Algorithmus wurde bereits in Funktionen zerlegt, aber die Tauschfunktion muss das Array zurückgeben:

package main import "fmt" func isGreater(a [10]int, i int) bool { return a[i] > a[i+1] } func swap(a [10]int, i int) [10]int { a[i], a[i+1] = a[i+1], a[i] return a } func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pass := 0; pass < len(a)-1; pass++ { for i := 0; i < len(a)-1-pass; i++ { if isGreater(a, i) { a = swap(a, i) } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }
Das Unbehagen: Wir tauschen nur zwei benachbarte Elemente, aber die Funktion muss das gesamte Array kopieren und zurückgeben:
if isGreater(a, i) { a = swap(a, i) // Ganzes Array wird kopiert! }

Dieser Kopieraufwand ist abhängig von der Array-Größe – bei 1000 Elementen wird die Funktion 1000 Werte kopieren, obwohl sie nur 2 Positionen verändert. Das ist reine Verschwendung.

Neue Frage: Kann die Funktion das Original-Array direkt verändern, ohne es kopieren und zurückgeben zu müssen?

Was sind Zeiger?

Ein Zeiger ist eine Variable, die die Speicheradresse einer anderen Variable speichert. In Go werden Zeiger mit dem Stern * gekennzeichnet.

Konzept Beispiel Bedeutung
Variable x := 42 enthält einen Wert
Zeiger-Typ *int Zeiger auf einen int
Zeiger-Variable p := &x enthält die Adresse von x
Zeigeradresse 0xc0000180b0 RAM-Adresse im Speicher

Neue Begriffe dieses Blocks

Zeiger (Pointer)
Speicheradresse
Adressoperator &

Der Adressoperator: &

Mit & (Adressoperator) erhält man die Speicheradresse einer Variable.

x := 42 p := &x // p ist ein Zeiger auf x fmt.Println(p) // gibt etwa 0xc0000180b0 aus
Was passiert:
  • x speichert den Wert 42 im Speicher
  • &x gibt die Adresse dieses Speicherplatzes zurück
  • p speichert diese Adresse

Für Arrays funktioniert es genauso:

a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} pa := &a // pa ist ein Zeiger auf das Array
Wichtig: pa zeigt auf das Original-Array, nicht auf eine Kopie. Eine Änderung über pa verändert a direkt.

Der Dereferenzoperator: *

Mit * (Dereferenzoperator) greift man auf den Wert zu, auf den ein Zeiger zeigt.

x := 42 p := &x // p zeigt auf x fmt.Println(*p) // gibt 42 aus
Duales System:
  • &x: "Gib mir die Adresse von x"
  • *p: "Gib mir den Wert, auf den p zeigt"

Man kann über einen Zeiger auch Werte ändern:

x := 42 p := &x *p = 100 // x hat jetzt den Wert 100 fmt.Println(x) // gibt 100 aus
Das ist der Kern der Sache: Eine Funktion, die einen Zeiger bekommt, kann das Original-Objekt verändern.

Vergleichsfunktion (bleibt gleich)

Die Vergleichsfunktion ändert nichts am Array. Sie braucht also keinen Zeiger, nur den Wert.

func isGreater(a [10]int, i int) bool { return a[i] > a[i+1] }
Überlegung: Wir lesen nur, ändern nicht. Deshalb bleibt diese Funktion wie sie ist.

Im Code wird sie genauso aufgerufen:

if isGreater(a, i) { // ... }

Tauschfunktion mit Zeiger-Parameter

Jetzt kommt der eigentliche Unterschied. Die Tauschfunktion bekommt einen Zeiger auf das Array:

Alte Version (call-by-value)

func swap(a [10]int, i int) [10]int { a[i], a[i+1] = a[i+1], a[i] return a }

Neue Version (call-by-reference mit Zeiger)

func swap(a *[10]int, i int) { a[i], a[i+1] = a[i+1], a[i] }
Schreibweise:
  • *[10]int: "Zeiger auf ein Array von 10 int"
  • Der Parameter a ist jetzt ein Zeiger
  • Keine Rückgabe mehr nötig!

Was ändert sich?

Zeiger-Parameter
Keine Rückgabe
Direktes Verändern
Go-Syntax: a[i] funktioniert auch auf Zeigern!
Go-Feature: In Go kann man auf Array-Elementen über einen Zeiger auch ohne explizites Dereferenzieren zugreifen. a[i] funktioniert, als wäre a ein Array (Go dereferenziert automatisch).

Call-by-reference in der main()

Der Aufruf ändert sich, weil wir nun einen Zeiger übergeben müssen:

Alte Version

a = swap(a, i)

Neue Version

swap(&a, i)
Was passiert:
  • &a gibt die Adresse des Arrays an
  • swap erhält diese Adresse
  • swap verändert das Original-Array
  • Keine Zuweisung nötig!
Aspekt call-by-value (alt) call-by-reference (neu)
Parameter-Typ [10]int *[10]int
Übergabe swap(a, i) swap(&a, i)
Rückgabewert [10]int keine
Zuweisung nach Aufruf a = result nicht nötig
Original verändern? Nein (Kopie verändern) Ja (direkt)

Vollständiger Code: Bubble Sort mit Zeigern

package main import "fmt" func isGreater(a [10]int, i int) bool { return a[i] > a[i+1] } func swap(a *[10]int, i int) { a[i], a[i+1] = a[i+1], a[i] } func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pass := 0; pass < len(a)-1; pass++ { for i := 0; i < len(a)-1-pass; i++ { if isGreater(a, i) { swap(&a, i) } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }
Vergleich zur alten Lösung: Der Code liest sich sehr ähnlich. Der große Unterschied liegt in der Technik: Die Funktion arbeitet nun mit einer Referenz zum Original, nicht mit einer Kopie.
Didaktischer Gewinn: Dies ist der Übergang von imperativem zu referentiellem Denken. Funktionen manipulieren nun externe Zustände.
