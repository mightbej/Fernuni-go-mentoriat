Ausgangspunkt: Bubble Sort ist bekannt

Wir greifen den bisherigen Bubble-Sort-Code auf. Die Studenten kennen bereits Arrays, Indizes, Schleifen, Bedingungen und Tauschen per Mehrfachzuweisung.

package main import "fmt" func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pass := 0; pass < len(a)-1; pass++ { for i := 0; i < len(a)-1-pass; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }
Neues Ziel: Wir verändern den Algorithmus nicht. Wir zerlegen ihn nur in benannte Teilaufgaben.

Wiederholung: Was ist eine Funktion?

Eine Funktion ist ein benannter Programmbaustein. Sie kann Werte übernehmen, etwas berechnen oder ausführen und optional Werte zurückgeben.

Bestandteil Beispiel Bedeutung
Funktionsname isGreater Benannter Teilschritt des Programms
Parameter a [10]int, i int Werte, die die Funktion beim Aufruf bekommt
Rückgabetyp bool Typ des Ergebnisses
return return a[i] > a[i+1] liefert das Ergebnis zurück
Wichtig: In diesem Block geht es nur um Funktionen. Zeiger und Rekursion folgen später.

Erste Auslagerung: Vergleichsfunktion

Im Bubble Sort kommt immer wieder dieselbe Frage vor: Ist das linke Element größer als das rechte?

if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] }

Diesen Vergleich können wir als Funktion ausdrücken:

func isGreater(a [10]int, i int) bool { return a[i] > a[i+1] }

Was wird hier wiederholt?

Rückgabewert

Funktionsaufruf als Ausdruck

Der Code im Bubble Sort wird dadurch lesbarer:

if isGreater(a, i) { a[i], a[i+1] = a[i+1], a[i] }

Zweite Auslagerung: Tauschfunktion

Auch der Tausch benachbarter Elemente ist ein wiederkehrender Teilschritt.

a[i], a[i+1] = a[i+1], a[i]

Da Arrays in Go als Wert übergeben werden, gibt die Funktion das geänderte Array zurück.

func swap(a [10]int, i int) [10]int { a[i], a[i+1] = a[i+1], a[i] return a }
Didaktischer Punkt: Diese Funktion verändert nicht automatisch das ursprüngliche Array in main. Deshalb muss das Ergebnis wieder zugewiesen werden.
a = swap(a, i)

Refactoring: Bubble Sort liest sich jetzt anders

Die eigentliche Sortierlogik bleibt gleich. Aber die beiden elementaren Operationen sind jetzt benannt.

Vorher

if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] }

Nachher

if isGreater(a, i) { a = swap(a, i) }
Interpretation: Wenn das linke Element größer ist, tausche die beiden benachbarten Elemente.
Wichtig: Funktionen verbessern hier nicht die Laufzeit. Sie verbessern die Struktur und Lesbarkeit.

Signaturen am Bubble-Sort-Beispiel

Die Signatur beschreibt, welche Typen eine Funktion als Eingabe bekommt und welche Typen sie zurückliefert.

Warum muss swap das Array zurückgeben?

Go übergibt Argumente grundsätzlich per Wert. Beim Aufruf von swap(a, i) bekommt die Funktion eine Kopie des Arrays.

Ort Array Was passiert?
main a enthält das ursprüngliche Array
swap a als Parameter ist eine lokale Kopie
return a geänderte Kopie wird an main zurückgegeben
a = swap(a, i) a in main wird durch das zurückgegebene Array ersetzt
Ausblick: Später lösen wir dieses Problem eleganter mit Zeigern. Hier bleiben wir bewusst bei Funktionen ohne Zeiger.

Vollständiger Code: Bubble Sort mit Funktionen

package main import "fmt" func isGreater(a [10]int, i int) bool { return a[i] > a[i+1] } func swap(a [10]int, i int) [10]int { a[i], a[i+1] = a[i+1], a[i] return a } func main() { a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9} fmt.Println("Start:", a) for pass := 0; pass < len(a)-1; pass++ { for i := 0; i < len(a)-1-pass; i++ { if isGreater(a, i) { a = swap(a, i) } } fmt.Printf("Nach Pass %d: %v\n", pass+1, a) } fmt.Println("Sortiert:", a) }
Diskussionsfrage: Ist der Code jetzt wirklich besser? Fachlich ja, weil die Absicht klarer wird. Technisch noch nicht optimal, weil Arrays kopiert werden.

Meta-Seite: Was haben wir gelernt?

Thema Erkenntnis
Funktionen Sie zerlegen ein Programm in benannte, wiederverwendbare Teilschritte.
Parameter Eine Funktion bekommt Werte über ihre Parameter.
Rückgabewerte Eine Funktion kann ein Ergebnis zurückliefern, das weiterverarbeitet werden muss.
Funktionsaufruf als Ausdruck isGreater(a, i) kann direkt in einer if-Bedingung stehen.
Call-by-value Die Funktion arbeitet mit Kopien der übergebenen Werte.
Grenze dieser Lösung Bei Arrays ist das Kopieren umständlich und bei großen Arrays ineffizient.
