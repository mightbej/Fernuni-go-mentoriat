Programmierübung: Quicksort Schritt für Schritt

Quicksort sortiert, indem es ein Array um einen Vergleichswert aufteilt und die Teile auf die gleiche Weise weiter aufteilt. Die Übung baut das Programm in fünf Stufen auf: erst mit fünf einzelnen Variablen, am Ende als rekursive Funktion mit Zeiger.

Kurstext v3.0.6, Abschnitt 7.5, Seiten 185–193. Quicksort kommt im Kurstext nicht vor.

Worum es geht

Bubble Sort und Selection Sort vergleichen immer wieder fast alle Elemente miteinander. Quicksort geht anders vor. Es wählt ein Element als Vergleichswert. Dieses Element heißt Pivot, das ist das englische Wort für Drehpunkt. Dann teilt es die übrigen Elemente in zwei Gruppen:

  • Links: alle Elemente, die kleiner sind als das Pivot.
  • Rechts: alle Elemente, die größer oder gleich sind.

Das Pivot kommt zwischen die zwei Gruppen. Dort steht es schon an seinem endgültigen Platz, denn links davon steht nur Kleineres und rechts nur Größeres. Dieser Vorgang heißt Aufteilen, englisch partition.

Ein Beispiel mit dem Array der Bubble-Sort-Übungen. Das Pivot ist das erste Element, 42:

Pivotkleiner als 42größer als 42

Danach sind zwei kleinere Aufgaben übrig: den linken Teil sortieren und den rechten Teil sortieren. Für beide Teile gilt das gleiche Verfahren. Jeder Teil bekommt sein eigenes Pivot und wird wieder aufgeteilt. Das geht so weiter, bis jeder Teil nur noch ein Element hat oder leer ist. Dann ist das ganze Array sortiert.

Wie die Übung aufgebaut ist

Jede Stufe nimmt ein Mittel von Go dazu, in der Reihenfolge des Kurses:

  • Stufe 1, fünf Variablen: einmal aufteilen mit der Tupel-Zuweisung aus Abschnitt 5.3. Die Entscheidungen triffst du selbst.
  • Stufe 2, ein Array: Index und for-Schleife aus Kapitel 6. Jetzt entscheidet das Programm.
  • Stufe 3, eine Funktion: Das Aufteilen wird die Funktion partition, Abschnitt 7.1 und 7.2.
  • Stufe 4, Zeiger und Bereiche: partition bekommt einen Zeiger auf das Array und teilt einen Bereich auf, Abschnitt 7.3 und 7.4.
  • Stufe 5, Rekursion: Die Funktion quickSort ruft sich für beide Teile selbst auf, Abschnitt 7.5.
Quicksort stammt von Tony Hoare, 1959. Es kommt im Kurstext nicht vor. Die Übung ist eine Ergänzung des Mentors und verwendet nur, was der Kurs bis Abschnitt 7.5 gezeigt hat.

Schritt 1: Fünf Variablen

Erst vorhersagen, dann ausprobieren
  1. Die fünf Variablen haben die Werte 42, 7, 19, 88 und 3. Das Pivot ist a mit 42. Welche Werte stehen nach dem Aufteilen links von 42, welche rechts?
    AuflösungLinks stehen 7, 19 und 3, rechts steht 88. In welcher Reihenfolge die drei kleineren Werte links stehen, ist beim Aufteilen noch offen.
  2. Warum steht in Zeile 7 d, e = e, d und nicht zwei Zeilen d = e und e = d?
    AuflösungNach d = e haben beide Variablen den Wert 3, die 88 ist verloren. Die Tupel-Zuweisung wertet erst beide Ausdrücke rechts aus und weist dann zu.

Das Programm teilt die fünf Werte einmal auf. Es braucht dafür nur zwei Anweisungen, beide sind Tupel-Zuweisungen:

  • Zeile 7: e ist kleiner als 42 und steht rechts von d mit 88. d und e tauschen ihre Werte. Jetzt stehen die drei kleineren Werte in b, c und d.
  • Zeile 9: Das Pivot tauscht mit dem letzten kleineren Wert, mit d. Jetzt steht 42 zwischen den kleineren und den größeren Werten.

    Ausgabe

    Was dieser Stufe fehlt

    Welche Werte kleiner sind als 42, steht nur in den Kommentaren. Die Entscheidungen hast du getroffen, das Programm vergleicht nichts. Für andere Werte müsstest du andere Tausche hinschreiben, und für zehn oder hundert Werte bräuchtest du zehn oder hundert Variablen.

    Das Programm soll selbst vergleichen. Dafür muss es die Werte der Reihe nach durchgehen können, und das geht mit einem Array und einem Index. Das ist Stufe 2.

    Schritt 2: Ein Array

    Erst vorhersagen, dann ausprobieren
    1. Am Ende der Schleife hat left den Wert 4. Was bedeutet diese 4?
      AuflösungDie Elemente an den Indizes 1 bis 3 sind kleiner als das Pivot, das sind drei Elemente. Am Index 4 beginnen die größeren. Das Pivot gehört deshalb an den Index left-1, also 3.

    Die fünf Werte stehen jetzt im Array a. Das Pivot ist a[0]. Zwei Variablen tragen das Aufteilen:

    • i: Die Schleife geht mit i vom Index 1 bis zum letzten Index und vergleicht jedes Element mit dem Pivot.
    • left: ein Index, der die Grenze markiert. Links von left, ab Index 1, stehen nur Elemente, die kleiner sind als das Pivot. left ist der Platz für das nächste kleinere Element.

    Findet die Schleife ein kleineres Element, tauscht es mit dem Element am Index left, und left rückt eins weiter. Nach der Schleife tauscht das Pivot mit dem Element am Index left-1, dem letzten kleineren Element.

    In der Demo ist grün, was schon links von der Grenze steht. Gelb ist das Element am Index i, das die Schleife gerade ansieht.

      Ausgabe

      Das Ergebnis ist das gleiche wie in Stufe 1: [3 7 19 42 88]. Neu ist, dass das Programm selbst vergleicht. Es teilt jedes Array mit fünf Elementen auf, ohne dass eine Zeile geändert werden muss.

      Bei 7 und 19 tauscht ein Element mit sich selbst, weil i und left gleich sind. Das schadet nicht.

      Was dieser Stufe fehlt

      Das Aufteilen steht mitten in main. Für den linken und den rechten Teil müsste es noch einmal dastehen, und für deren Teile wieder. Das Aufteilen soll deshalb eine Funktion werden. Das ist Stufe 3.

      Schritt 3: Eine Funktion

      Erst vorhersagen, dann ausprobieren
      1. main ruft partition(a) auf und gibt danach a aus. Was steht da?
        AuflösungDas unveränderte Array [42 7 19 88 3]. Die Funktion hat eine Kopie aufgeteilt, und ihr Ergebnis hat niemand aufgefangen.

      Das Aufteilen aus Stufe 2 steht jetzt in der Funktion partition. Sie bekommt das Array als Parameter und liefert zwei Ergebnisse: das aufgeteilte Array und den Index des Pivots.

      // teilt das Array um das Pivot a[0] auf und liefert
// das aufgeteilte Array und den Index des Pivots
func partition(a [5]int) ([5]int, int) {
    pivot := a[0]
    left := 1
    for i := 1; i < len(a); i++ {
        if a[i] < pivot {
            a[i], a[left] = a[left], a[i]
            left++
        }
    }
    a[0], a[left-1] = a[left-1], a[0]
    return a, left - 1
}

      Warum liefert die Funktion das Array zurück? In Go bekommt eine Funktion eine Kopie ihres Arguments, auch bei einem Array. Das ist die Wertübergabe aus Abschnitt 7.2. Die Funktion teilt ihre Kopie auf. Das Array in main bleibt, wie es war.

      Ausgabe

      Was dieser Stufe fehlt

      • Die Kopie: Jeder Aufruf kopiert das ganze Array hin und zurück. Bei fünf Elementen fällt das nicht auf, bei vielen schon. Die Lektion Das Kopier-Problem zeigt das an Bubble Sort.
      • Das ganze Array: Die Funktion teilt immer das ganze Array auf. Quicksort muss aber auch den linken Teil allein aufteilen können, zum Beispiel nur die Indizes 0 bis 2.

      Beides löst Stufe 4: ein Zeiger auf das Array und zwei Grenzen für den Bereich.

      Schritt 4: Zeiger und Bereiche

      Erst vorhersagen, dann ausprobieren
      1. Das Array hat jetzt zehn Elemente. Der erste Aufruf partition(&a, 0, 9) bringt 42 an den Index 6. Wie viele Elemente sind kleiner als 42?
        AuflösungSechs: 7, 19, 3, 25, 14 und 9. Sie stehen danach an den Indizes 0 bis 5.
      2. Nach drei Aufrufen von partition ist das Array noch nicht sortiert. Warum nicht?
        AuflösungJeder Aufruf bringt nur sein Pivot an den richtigen Platz. Die Teile links und rechts davon sind nur grob geordnet und müssten selbst wieder aufgeteilt werden.

      Zwei Dinge ändern sich gegenüber Stufe 3:

      • Ein Zeiger: partition bekommt mit pa *[10]int die Adresse des Arrays. Sie arbeitet damit auf dem Array von main und muss nichts zurückgeben außer dem Index des Pivots. Das Tauschen steht jetzt in der Funktion swap, wie in der Programmierübung Bubble Sort mit Zeigern.
      • Ein Bereich: Die Parameter start und end geben den ersten und den letzten Index des Bereichs an. Das Pivot ist pa[start], und left beginnt bei start + 1.
      // tauscht in dem Array, auf das pa zeigt,
// die Elemente an den Indizes i und j
func swap(pa *[10]int, i, j int) {
    pa[i], pa[j] = pa[j], pa[i]
}

// teilt den Bereich von start bis end um das Pivot
// pa[start] auf und liefert den Index des Pivots
func partition(pa *[10]int, start, end int) int {
    pivot := pa[start]
    left := start + 1
    for i := start + 1; i <= end; i++ {
        if pa[i] < pivot {
            swap(pa, i, left)
            left++
        }
    }
    swap(pa, start, left-1)
    return left - 1
}

      Die Schleife läuft jetzt bis i <= end, denn end ist der letzte Index des Bereichs und gehört dazu.

      main ruft partition dreimal von Hand auf: für das ganze Array, für den linken Teil und für den rechten Teil. Grün sind die Elemente, deren Platz feststeht. Gelb ist der Bereich, den der letzte Aufruf aufgeteilt hat.

        Ausgabe

        Was dieser Stufe fehlt

        Nach drei Aufrufen stehen 9, 42 und 88 an ihrem Platz. Übrig sind die Bereiche 0 bis 1, 3 bis 5 und 7 bis 8. Jeder davon braucht wieder einen Aufruf, und deren Teile wieder. Wie viele Aufrufe es werden, hängt von den Werten ab. Von Hand lässt sich das nicht hinschreiben.

        Die Lösung: Eine Funktion quickSort teilt ihren Bereich auf und ruft sich dann für beide Teile selbst auf. Das ist Stufe 5.

        Schritt 5: Rekursion

        Erst vorhersagen, dann ausprobieren
        1. Ein Aufruf quickSort(pa, 3, 3) soll den Bereich vom Index 3 bis zum Index 3 sortieren. Was ist zu tun?
          AuflösungNichts. Der Bereich hat ein Element, und ein einzelnes Element ist sortiert. Die Funktion kehrt sofort zurück.
        2. Wie kann ein Aufruf mit start größer als end entstehen, zum Beispiel quickSort(pa, 0, -1)?
          AuflösungWenn das Pivot ganz links landet, ist der linke Teil leer. Der Aufruf für den linken Teil bekommt dann start und p-1, also einen Bereich ohne Element.

        Die Funktion quickSort sortiert den Bereich von start bis end. Sie hat drei Teile:

        • Das Ende, Zeilen 2 bis 4: Hat der Bereich höchstens ein Element, kehrt die Funktion sofort zurück. Das ist der Fall, wenn start >= end gilt.
        • Aufteilen, Zeile 5: partition aus Stufe 4 bringt das Pivot an seinen Platz p.
        • Zwei rekursive Aufrufe, Zeilen 6 und 7: erst für den linken Teil von start bis p-1, dann für den rechten Teil von p+1 bis end. Das Pivot selbst gehört zu keinem Teil, sein Platz steht fest.

        Jeder Aufruf hat einen eigenen Rahmen mit pa, start, end und p. Die Rahmen stehen in der Reihenfolge der Aufrufe nebeneinander, der jüngste Aufruf steht zuletzt. Ein Schritt der Demo ist ein Aufruf, ein Aufteilen oder eine Rückkehr. partition und swap zeigt die Demo nicht.

          Ausgabe

          Einordnung nach Abschnitt 7.5 des Kurstexts

          • Kaskadenartige Rekursion: Ein Aufruf enthält zwei rekursive Aufrufe, wie die Fibonacci-Zahlen in Abschnitt 7.5.3. Die Lektion Rekursion in Go zeigt sie in Schritt 3. Bubble Sort rekursiv war dagegen linear rekursiv.
          • Keine Endrekursion: Nach dem ersten rekursiven Aufruf folgt noch der zweite. Der Aufruf muss deshalb warten und seinen Rahmen behalten.
          • Terminierung: Jeder rekursive Aufruf bekommt einen kleineren Bereich, denn das Pivot fällt jedes Mal heraus. Irgendwann hat jeder Bereich höchstens ein Element, dann gibt es keinen Aufruf mehr.

          Für das Array der Übung läuft quickSort 13-mal. Sechs Aufrufe teilen auf, sieben finden einen Bereich mit höchstens einem Element und kehren sofort zurück. Das ganze Programm mit Ausgaben steht im nächsten Schritt.

          Ausblick: Aufteilen nach Hoare

          Die Übung teilt mit einem einzigen Index left auf. Tony Hoare, der Erfinder von Quicksort, hat zwei Indizes verwendet, die von beiden Seiten aufeinander zulaufen:

          • left läuft von links nach rechts, bis es ein Element findet, das größer ist als das Pivot.
          • right läuft von rechts nach links, bis es ein Element findet, das nicht größer ist als das Pivot.
          • Tausch: Beide Elemente stehen auf der falschen Seite und tauschen. Dann laufen beide Indizes weiter, bis sie sich kreuzen.
          func partition(pa *[10]int, start, end int) int {
    pivot := pa[start]
    left := start + 1
    right := end
    for left <= right {
        for left <= end && pa[left] <= pivot {
            left++
        }
        for pa[right] > pivot {
            right--
        }
        if left < right {
            swap(pa, left, right)
        }
    }
    swap(pa, start, right)
    return right
}

          Dieses Aufteilen tauscht nur Paare, die beide auf der falschen Seite stehen. Das Pivot 42 landet auch hier am Index 6, die Elemente links davon stehen in anderer Reihenfolge: [14 7 19 9 3 25 42 71 60 88]. Die Funktion quickSort bleibt gleich. Es ist aber schwerer zu durchschauen, deshalb teilt die Übung mit einem einzigen Index auf.
