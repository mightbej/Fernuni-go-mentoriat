Programmierübung: Bubble Sort mit Zeigern

Die Funktionen isGreater und swap bekommen einen Zeiger auf das Array. Das Programm sortiert wie vorher und kopiert dabei kein Element mehr.

Kurstext v3.0.6, Abschnitt 7.3 und 7.4, Seiten 171–180. Bubblesort steht im Kurstext in Abschnitt 8.4.2, Seiten 225–226.

Worum es geht

Die Programmierübung Bubble Sort mit Funktionen endet mit zwei Funktionen, die das Array als Kopie bekommen:

func isGreater(a [10]int, i int) bool {
    return a[i] > a[i+1]
}

func swap(a [10]int, i int) [10]int {
    a[i], a[i+1] = a[i+1], a[i]
    return a
}

Daran stören zwei Punkte:

  • Der Umweg: swap ändert eine Kopie und gibt sie zurück. Der Aufrufer muss a = swap(a, i) schreiben. Vergisst er a =, sortiert das Programm nicht, und Go meldet nichts.
  • Der Aufwand: Für zehn Elemente kopiert das Programm 910 Elemente.

Diese Übung übergibt den zwei Funktionen die Adresse des Arrays.

Was dazugehört

  • Abschnitt 7.3, Zeiger als Funktionsparameter: Die Lektion Zeiger in Go führt in Schritt 1 Listing 7.2 aus. Die Funktion negToZeroPointer ist das Muster für diese Übung.
  • Abschnitt 7.4.1, Seiteneffekt: Schritt 3 der gleichen Lektion zeigt die Funktion incr.
  • Die Kopien gezählt: Der Exkurs Das Kopier-Problem.

Schritt 1: swap mit einem Zeiger

Erst vorhersagen, dann ausprobieren
  1. Die Funktion swap(pa *[10]int, i int) hat keine Rückgabe. Woran sieht der Aufrufer nach swap(&a, 0), dass sie etwas getan hat?
    AuflösungAn seinem Array: a[0] und a[1] haben den Platz getauscht. Die Funktion wirkt durch einen Seiteneffekt.
// tauscht in dem Array, auf das pa zeigt,
// die Nachbarn an den Indizes i und i+1
func swap(pa *[10]int, i int) {
    pa[i], pa[i+1] = pa[i+1], pa[i]
}

Gegenüber dem Programm mit einer Kopie ändern sich vier Stellen:

  • Parameter: pa *[10]int ist ein Zeiger auf ein Array vom Typ [10]int.
  • Rumpf: pa[i] ist die Kurzschreibweise für (*pa)[i], also für das Element i des Arrays, auf das pa zeigt.
  • Rückgabe: Sie entfällt, mit ihr die return-Anweisung.
  • Aufruf: swap(&a, i). Der Adressoperator & liefert die Adresse von a. Die Zuweisung a = … entfällt.

Die Funktion ändert eine Variable, die außerhalb ihres Rumpfs deklariert ist. Im Kurstext heißt das Seiteneffekt.

Wer & vergisst und swap(a, i) schreibt, bekommt eine Meldung des Compilers: cannot use a (variable of type [10]int) as *[10]int value in argument to swap. Der Fehler aus dem Programm mit der Kopie, das vergessene a =, blieb unbemerkt.

Schritt 2: isGreater mit einem Zeiger

Erst vorhersagen, dann ausprobieren
  1. isGreater liest zwei Elemente und ändert nichts. Braucht die Funktion einen Zeiger, damit das Programm richtig sortiert?
    AuflösungNein. Zum Lesen genügt die Kopie, das Ergebnis ist das gleiche. Der Zeiger spart hier nur die Kopie von zehn Elementen je Aufruf.

isGreater ändert das Array nicht. Das Programm mit der Kopie liefert deshalb das richtige Ergebnis. Es kopiert aber bei jedem der 45 Vergleiche zehn Elemente, zusammen 450. Für das Programm mit einem Zeiger sprechen zwei Gründe:

  • Aufwand: Der Aufruf kopiert eine Adresse und kein Element.
  • Einheitlichkeit: Beide Funktionen bekommen das Array auf die gleiche Art.
// liefert true, wenn das Element am Index i
// größer ist als sein rechter Nachbar
func isGreater(pa *[10]int, i int) bool {
    return pa[i] > pa[i+1]
}

Die zwei Programme im Vergleich:

ProgrammAufruf in mainKopierte Elemente bei 45 Vergleichen
isGreater(a [10]int, i int) boolisGreater(a, i)Die Aufrufe kopieren 450 Elemente.
isGreater(pa *[10]int, i int) boolisGreater(&a, i)Die Aufrufe kopieren kein Element.
Ein Zeiger gibt der Funktion die Möglichkeit, das Array zu ändern. Am Aufruf isGreater(&a, i) sieht man nicht, ob sie es tut. Das steht im Rumpf der Funktion und in ihrem Kommentar.

Schritt 3: Ein Durchgang

Erst vorhersagen, dann ausprobieren
  1. Wie viele Arrays gibt es, während swap läuft?
    AuflösungEines, das Array a in main. Im Rahmen von swap steht nur seine Adresse.

Die Demo führt den ersten Durchgang aus. In den Rahmen der zwei Funktionen steht jetzt kein Array mehr. Dort steht der Zeiger pa mit der Adresse von a.

Unter den Rahmen steht der Hauptspeicher des Modells: je Variable ein Block mit ihren Zellen, ihrem Typ und ihrem Inhalt. Das Array a belegt die 80 Zellen von 100 bis 179, denn ein int belegt 8 Zellen. Der Zeiger pa belegt 8 Zellen, und in ihnen steht die Zahl 100, die Adresse des Arrays. Die Adressen sind erfunden.

    Ausgabe

    Die Demo zeigt die Schleife nicht Anweisung für Anweisung, sie zeigt jeden Aufruf einer Funktion.

    Schritt 4: Das ganze Programm

    package main

import "fmt"

// liefert true, wenn das Element am Index i
// größer ist als sein rechter Nachbar
func isGreater(pa *[10]int, i int) bool {
    return pa[i] > pa[i+1]
}

// tauscht in dem Array, auf das pa zeigt,
// die Nachbarn an den Indizes i und i+1
func swap(pa *[10]int, i int) {
    pa[i], pa[i+1] = pa[i+1], pa[i]
}

func main() {
    a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9}
    fmt.Println("Start:", a)

    for durchgang := 0; durchgang < len(a)-1; durchgang++ {
        for i := 0; i < len(a)-1-durchgang; i++ {
            if isGreater(&a, i) {
                swap(&a, i)
            }
        }
        fmt.Printf("Nach Durchgang %d: %v\n", durchgang+1, a)
    }

    fmt.Println("Sortiert:", a)
}
