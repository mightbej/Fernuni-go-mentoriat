Programmierübung: Selection Sort mit Zeigern

Die Funktionen findMin und swap bekommen einen Zeiger auf das Array. Das Programm sortiert wie vorher und kopiert dabei kein Element mehr.

Kurstext v3.0.6, Abschnitt 7.3 und 7.4, Seiten 171–180. Selection Sort kommt im Kurstext nicht vor.

Worum es geht

Die Programmierübung Selection Sort mit Funktionen endet mit einer Runde aus drei Zeilen:

minIndex := findMin(a, pos)
if minIndex != pos {
    a = swap(a, pos, minIndex)
}

Beide Funktionen bekommen das Array als Kopie. swap muss ihre Kopie zurückgeben, und main muss sie zuweisen. Für zehn Elemente kopiert das Programm 230 Elemente.

Diese Übung übergibt den zwei Funktionen die Adresse des Arrays. Das Verfahren bleibt gleich.

Was dazugehört

  • Abschnitt 7.3, Zeiger als Funktionsparameter: Die Lektion Zeiger in Go führt in Schritt 1 Listing 7.2 aus.
  • Das gleiche mit Bubble Sort: Die Programmierübung Bubble Sort mit Zeigern stellt isGreater und swap um.
  • Die Kopien gezählt: Der Exkurs Das Kopier-Problem.

Schritt 1: swap mit einem Zeiger

Erst vorhersagen, dann ausprobieren
  1. Aus a = swap(a, pos, minIndex) wird swap(&a, pos, minIndex). Welche zwei Zeichenfolgen sind verschwunden, welches Zeichen ist dazugekommen?
    AuflösungVerschwunden ist a =, weil die Funktion nichts mehr zurückgibt. Dazugekommen ist &, weil die Funktion die Adresse des Arrays braucht.
// tauscht in dem Array, auf das pa zeigt,
// die Elemente an den Indizes i und j
func swap(pa *[10]int, i int, j int) {
    pa[i], pa[j] = pa[j], pa[i]
}
  • Parameter: pa *[10]int ist ein Zeiger auf ein Array vom Typ [10]int.
  • Rumpf: pa[i] ist die Kurzschreibweise für (*pa)[i].
  • Rückgabe: Sie entfällt. Die Funktion ändert das Array ihres Aufrufers. Das ist ein Seiteneffekt.

Schritt 2: findMin mit einem Zeiger

Erst vorhersagen, dann ausprobieren
  1. findMin liest das Array und ändert es nicht. Was gewinnt das Programm, wenn auch diese Funktion einen Zeiger bekommt?
    AuflösungEs spart in jeder Runde die Kopie von zehn Elementen, zusammen 90. Am Ergebnis ändert sich nichts.
// liefert den Index des kleinsten Elements ab dem Index pos
func findMin(pa *[10]int, pos int) int {
    minIndex := pos
    for i := pos + 1; i < len(*pa); i++ {
        if pa[i] < pa[minIndex] {
            minIndex = i
        }
    }
    return minIndex
}

Drei Stellen sind anders als im Programm mit der Kopie:

  • Parameter: pa *[10]int.
  • Länge: len(*pa). Der Stern führt vom Zeiger zum Array, und len liefert dessen Länge.
  • Elemente: pa[i] und pa[minIndex] in der Kurzschreibweise.

Die Rückgabe bleibt. Die Funktion liefert weiter einen Index, und ein Index ist ein int. Ein Zeiger als Parameter und eine Rückgabe schließen sich nicht aus, das zeigt auch die Funktion incr in Abschnitt 7.4.1 des Kurstexts.

Schritt 3: Runde für Runde

Erst vorhersagen, dann ausprobieren
  1. In Runde 2 liefert findMin(&a, 1) den Wert 1. Was tut das Programm dann?
    AuflösungNichts. minIndex ist gleich pos, die 7 steht schon am richtigen Platz. swap wird nicht aufgerufen.

Die Demo führt das ganze Sortieren aus, einen Aufruf nach dem anderen. In den Rahmen der zwei Funktionen steht kein Array. Dort steht der Zeiger pa mit der Adresse von a.

Unter den Rahmen steht der Hauptspeicher des Modells: je Variable ein Block mit ihren Zellen, ihrem Typ und ihrem Inhalt. Das Array a belegt die 80 Zellen von 100 bis 179, denn ein int belegt 8 Zellen. Der Zeiger pa belegt 8 Zellen, und in ihnen steht die Zahl 100, die Adresse des Arrays. Die Adressen sind erfunden.

    Schritt 4: Das ganze Programm

    package main

import "fmt"

// liefert den Index des kleinsten Elements ab dem Index pos
func findMin(pa *[10]int, pos int) int {
    minIndex := pos
    for i := pos + 1; i < len(*pa); i++ {
        if pa[i] < pa[minIndex] {
            minIndex = i
        }
    }
    return minIndex
}

// tauscht in dem Array, auf das pa zeigt,
// die Elemente an den Indizes i und j
func swap(pa *[10]int, i int, j int) {
    pa[i], pa[j] = pa[j], pa[i]
}

func main() {
    a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9}
    fmt.Println("Start:", a)

    for pos := 0; pos < len(a)-1; pos++ {
        minIndex := findMin(&a, pos)
        if minIndex != pos {
            swap(&a, pos, minIndex)
        }
        fmt.Printf("Nach Runde %d: %v\n", pos+1, a)
    }

    fmt.Println("Sortiert:", a)
}
