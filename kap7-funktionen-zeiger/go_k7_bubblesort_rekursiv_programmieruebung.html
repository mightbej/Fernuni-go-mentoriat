Programmierübung: Bubble Sort rekursiv

Die äußere Schleife von Bubble Sort wird zu einem rekursiven Aufruf: Die Funktion macht einen Durchgang und ruft sich dann für ein Element weniger selbst auf.

Kurstext v3.0.6, Abschnitt 7.5, Seiten 185–193. Bubblesort steht im Kurstext in Abschnitt 8.4.2, Seiten 225–226.

Worum es geht

Die Programmierübung Bubble Sort mit Zeigern sortiert mit zwei Schleifen in main:

for durchgang := 0; durchgang < len(a)-1; durchgang++ {
    for i := 0; i < len(a)-1-durchgang; i++ {
        if isGreater(&a, i) {
            swap(&a, i)
        }
    }
}

Die äußere Schleife wiederholt den gleichen Durchgang für einen immer kürzeren Anfang des Arrays. Eine solche Wiederholung lässt sich auch rekursiv schreiben. Diese Übung baut dafür eine Funktion bubbleSort, die sich selbst aufruft.

Die Funktionen isGreater und swap bleiben, wie sie sind. Die innere Schleife bleibt eine Schleife.

Schritt 1: Die Idee

Erst vorhersagen, dann ausprobieren
  1. Ein Durchgang über zehn Elemente bringt das größte Element an den Index 9. Welche Aufgabe bleibt danach übrig?
    AuflösungDie ersten neun Elemente sortieren. Das ist die gleiche Aufgabe mit einem Element weniger.

Rekursion führt eine Aufgabe auf eine kleinere Aufgabe der gleichen Art zurück. Für das Sortieren mit Bubble Sort heißt das:

  • Die Aufgabe: Sortiere die ersten n Elemente des Arrays.
  • Ein Durchgang: Vergleiche die Nachbarn vom Index 0 bis zum Index n − 2 und tausche, wo das linke Element größer ist. Danach steht das größte der n Elemente am Index n − 1.
  • Die kleinere Aufgabe: Sortiere die ersten n − 1 Elemente des Arrays.
  • Das Ende: Für n gleich 1 oder 0 ist nichts zu tun. Ein einzelnes Element ist sortiert.

Die Funktion braucht dafür zwei Parameter: einen Zeiger auf das Array und die Zahl n. Die Länge des Arrays steht fest im Typ [10]int. Wie viele Elemente noch zu sortieren sind, sagt n.

Schritt 2: Die Funktion

Erst vorhersagen, dann ausprobieren
  1. main ruft bubbleSort(&a, 10) auf. Wie oft läuft die Funktion bubbleSort insgesamt?
    AuflösungZehnmal: mit n gleich 10, 9, 8 und so weiter bis 1. Der Aufruf mit n gleich 1 endet sofort.

Die Funktion hat drei Teile:

  • Das Ende, Zeilen 2 bis 4: Für n <= 1 kehrt die Funktion sofort zurück. Hier steht kein rekursiver Aufruf.
  • Ein Durchgang, Zeilen 5 bis 9: die innere Schleife aus dem Programm mit zwei Schleifen. An der Stelle von len(a)-1-durchgang steht n-1.
  • Der rekursive Aufruf, Zeile 10: bubbleSort(pa, n-1). Das Argument ist um 1 kleiner als der eigene Parameter.

Im rekursiven Aufruf steht pa und nicht &pa: pa ist schon die Adresse des Arrays, und die Funktion gibt sie weiter.

Unter den Rahmen steht der Hauptspeicher des Modells. Das Array a belegt die 80 Zellen von 100 bis 179. Jeder Aufruf von bubbleSort bekommt 16 neue Zellen: 8 für pa mit der Zahl 100, der Adresse des Arrays, und 8 für n. Das Array gibt es nur einmal, die Zeiger aller Aufrufe enthalten die gleiche Adresse. Die Adressen sind erfunden.

    Schritt 3: Schleife oder Rekursion

    Erst vorhersagen, dann ausprobieren
    1. Ist bubbleSort endrekursiv?
      AuflösungJa. Die Funktion ruft sich höchstens einmal auf, und dieser Aufruf ist ihre letzte Operation. Danach rechnet sie nichts mehr.

    Beide Programme vergleichen und tauschen in der gleichen Reihenfolge. Sie unterscheiden sich darin, wie sie die Durchgänge wiederholen:

    FrageMit zwei SchleifenRekursiv
    Was zählt die Durchgänge?Die Variable durchgang zählt von 0 bis 8.Der Parameter n fällt von 10 bis 1.
    Wie weit läuft ein Durchgang?Die innere Schleife läuft bis i < len(a)-1-durchgang.Die innere Schleife läuft bis i < n-1.
    Wann ist Schluss?Die Bedingung der äußeren Schleife ist nicht mehr erfüllt.Die Bedingung n <= 1 ist erfüllt.
    Wie viele Vergleiche und Tausche?Es sind 45 Vergleiche und 23 Tausche.Es sind 45 Vergleiche und 23 Tausche.
    Was bleibt gespeichert?Zwei Variablen: durchgang und i.Für jeden der zehn Aufrufe ein Wert von pa und von n.

    Einordnung nach Abschnitt 7.5 des Kurstexts

    • Direkte Rekursion: bubbleSort ruft sich selbst auf.
    • Lineare Rekursion: Ein Aufruf enthält höchstens einen rekursiven Aufruf. Für zehn Elemente läuft die Funktion zehnmal.
    • Endrekursion: Der rekursive Aufruf ist die letzte Operation. Auf dem Rückweg hat kein Aufruf mehr etwas zu tun.
    • Terminierung: Jeder rekursive Aufruf bekommt n-1. Bei n <= 1 gibt es keinen Aufruf mehr.
    Das rekursive Programm ist hier nicht besser als die Schleife. Es zeigt an einem bekannten Programm, wie eine Schleife und ein rekursiver Aufruf einander entsprechen. Wo Rekursion die naheliegende Lösung ist, zeigen im Kurstext die Türme von Hanoi und später die Bäume in Kapitel 9.

    Schritt 4: Das ganze Programm

    package main

import "fmt"

// liefert true, wenn das Element am Index i
// größer ist als sein rechter Nachbar
func isGreater(pa *[10]int, i int) bool {
    return pa[i] > pa[i+1]
}

// tauscht in dem Array, auf das pa zeigt,
// die Nachbarn an den Indizes i und i+1
func swap(pa *[10]int, i int) {
    pa[i], pa[i+1] = pa[i+1], pa[i]
}

// sortiert die ersten n Elemente des Arrays, auf das pa zeigt
func bubbleSort(pa *[10]int, n int) {
    if n <= 1 {
        return
    }
    for i := 0; i < n-1; i++ {
        if isGreater(pa, i) {
            swap(pa, i)
        }
    }
    fmt.Printf("n = %2d: %v\n", n, *pa)
    bubbleSort(pa, n-1)
}

func main() {
    a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9}
    fmt.Println("Start:", a)
    bubbleSort(&a, len(a))
    fmt.Println("Sortiert:", a)
}

    • Was geschieht, wenn die drei Zeilen mit if n <= 1 fehlen? Die Lektion Rekursion in Go zeigt in Schritt 5 eine Funktion ohne Ende.
