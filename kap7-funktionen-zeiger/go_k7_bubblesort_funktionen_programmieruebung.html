Programmierübung: Bubble Sort mit Funktionen

Das Sortierprogramm aus Kapitel 6 steht ganz in main. Diese Übung gibt zwei Teilaufgaben einen Namen: Der Vergleich wird zur Funktion isGreater, der Tausch zur Funktion swap.

Kurstext v3.0.6, Abschnitt 7.1 und 7.2, Seiten 163–170. Bubblesort steht im Kurstext in Abschnitt 8.4.2, Seiten 225–226.

Worum es geht

Die Programmierübung Sortieren mit Bubble Sort endet mit diesem Kern:

for durchgang := 0; durchgang < len(a)-1; durchgang++ {
    for i := 0; i < len(a)-1-durchgang; i++ {
        if a[i] > a[i+1] {
            a[i], a[i+1] = a[i+1], a[i]
        }
    }
}

Das Verfahren bleibt, wie es ist. Neu ist die Gliederung: Zwei Stücke des Programms wandern in eigene Funktionen.

  • Der Vergleich a[i] > a[i+1] wird zur Funktion isGreater.
  • Der Tausch a[i], a[i+1] = a[i+1], a[i] wird zur Funktion swap.

Dabei zeigt sich, was die Wertübergabe für ein Array bedeutet: Jede der zwei Funktionen bekommt eine Kopie des Arrays.

Was dazugehört

  • Das Verfahren: Die Programmierübung Sortieren mit Bubble Sort erklärt Durchgang, Vergleich und Tausch.
  • Abschnitt 3.4 und 7.1, Funktionen: Die Lektion Funktionen in Go zeigt Parameter, Rückgabe und Signatur.
  • Abschnitt 7.2, Wertübergabe: Schritt 5 der gleichen Lektion führt Listing 7.1 aus.
Die Funktionen machen das Programm nicht schneller. Sie machen es lesbarer: if isGreater(a, i) sagt, was geprüft wird.

Schritt 1: Der Vergleich als Funktion

Erst vorhersagen, dann ausprobieren
  1. Welchen Typ hat der Ausdruck a[i] > a[i+1]?
    Auflösungbool. Ein Vergleich liefert true oder false. Das ist der Rückgabe-Typ der Funktion.

Bubble Sort stellt immer wieder die gleiche Frage: Ist das linke Element größer als sein rechter Nachbar? Die Funktion isGreater beantwortet sie.

// liefert true, wenn das Element am Index i
// größer ist als sein rechter Nachbar
func isGreater(a [10]int, i int) bool {
    return a[i] > a[i+1]
}
  • Parameter: Die Funktion braucht das Array und den Index des linken Elements.
  • Rückgabe: Sie liefert einen Wert vom Typ bool.
  • Signatur: Die Parameter-Typen sind [10]int und int, der Rückgabe-Typ ist bool.

Ein Funktionsaufruf mit einer Rückgabe ist ein Ausdruck. Er darf deshalb als Bedingung in der if-Anweisung stehen:

if isGreater(a, i) {
    a[i], a[i+1] = a[i+1], a[i]
}

Die Länge 10 steht im Typ des Parameters. Die Funktion nimmt nur Arrays vom Typ [10]int an. Ein Array mit zwölf Elementen hat einen anderen Typ.

Kurstext v3.0.6, Abschnitt 3.4 und Abschnitt 7.1, Seiten 163–165. Die Funktion isGreater ist ein eigenes Beispiel.

Schritt 2: Der Tausch als Funktion

Erst vorhersagen, dann ausprobieren
  1. In main steht swap(a, i) ohne a = davor. Go übersetzt das Programm. Was gibt es am Ende aus?
    AuflösungDas unsortierte Array. Jeder Aufruf tauscht in einer Kopie, und die Rückgabe ist verworfen.

Auch der Tausch bekommt einen Namen. Die Funktion bekommt das Array als Kopie und kann das Array in main nicht ändern. Sie gibt deshalb ihre geänderte Kopie zurück:

// liefert eine Kopie des Arrays, in der die Nachbarn
// an den Indizes i und i+1 getauscht sind
func swap(a [10]int, i int) [10]int {
    a[i], a[i+1] = a[i+1], a[i]
    return a
}

Der Aufrufer weist die Rückgabe seinem Array zu:

if isGreater(a, i) {
    a = swap(a, i)
}

Die Zeile liest sich so: Ist das Element am Index i größer als sein Nachbar, dann tausche die zwei.

Das Muster ist das gleiche wie bei negToZeroValue in Listing 7.1 des Kurstexts: Die Funktion ändert ihre Kopie und gibt sie zurück.

Kurstext v3.0.6, Abschnitt 7.2, Seiten 169–170. Die Funktion swap ist ein eigenes Beispiel.

Schritt 3: Ein Durchgang

Erst vorhersagen, dann ausprobieren
  1. Der erste Durchgang vergleicht neun Paare und tauscht achtmal. Wie viele Elemente kopiert der Rechner dabei für die Aufrufe von isGreater und swap?
    Auflösung250. Neun Aufrufe von isGreater kopieren je 10 Elemente. Acht Aufrufe von swap kopieren je 20: zehn hin und zehn zurück.

Die Demo führt den ersten Durchgang aus. Sie zeigt für jeden Aufruf den Rahmen der Funktion mit ihrer Kopie des Arrays und zählt die kopierten Elemente mit.

    Ausgabe

    Das Programm ist ein eigenes Beispiel. Die Demo zeigt die Schleife nicht Anweisung für Anweisung, sie zeigt jeden Aufruf einer Funktion.

    Schritt 4: Das ganze Programm

    package main

import "fmt"

// liefert true, wenn das Element am Index i
// größer ist als sein rechter Nachbar
func isGreater(a [10]int, i int) bool {
    return a[i] > a[i+1]
}

// liefert eine Kopie des Arrays, in der die Nachbarn
// an den Indizes i und i+1 getauscht sind
func swap(a [10]int, i int) [10]int {
    a[i], a[i+1] = a[i+1], a[i]
    return a
}

func main() {
    a := [10]int{42, 7, 19, 88, 3, 25, 71, 14, 60, 9}
    fmt.Println("Start:", a)

    for durchgang := 0; durchgang < len(a)-1; durchgang++ {
        for i := 0; i < len(a)-1-durchgang; i++ {
            if isGreater(a, i) {
                a = swap(a, i)
            }
        }
        fmt.Printf("Nach Durchgang %d: %v\n", durchgang+1, a)
    }

    fmt.Println("Sortiert:", a)
}

    Die Bilanz

    • Lesbarkeit: Die innere Schleife sagt in Worten, was sie tut: Ist das linke Element größer, dann tausche.
    • Aufwand: Das Programm vergleicht 45-mal und tauscht 23-mal, wie die Fassung aus Kapitel 6. Dazu kommen jetzt die Kopien: 45 · 10 + 23 · 20 = 910 kopierte Elemente.

    Wie stark das mit der Länge des Arrays wächst, rechnet der Exkurs Das Kopier-Problem aus. Die Programmierübung Bubble Sort mit Zeigern schafft die Kopien ab.
