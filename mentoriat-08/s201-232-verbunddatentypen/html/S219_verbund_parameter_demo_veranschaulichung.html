Kapitel 8.2.6 und 8.2.7: Verbund-Parameter und Rückgabewerte

Die Seite zeigt, wann eine Funktion einen Zeiger auf einen Verbund zurückliefert, warum implizite Dereferenzierung bei Feldzugriffen möglich ist und wann bei Parametern ein Verbund-Zeiger oder ein Verbund-Wert sinnvoll ist.

1. Verbund-Zeiger als Rückgabewert

Die Funktion werIstÄlter(p1, p2 *person) *person liefert einen Zeiger auf den älteren Verbund zurück. Der Rückgabewert ist also nicht der Verbund selbst, sondern seine Adresse.

func werIstÄlter(p1, p2 *person) *person { if p1.gebJahr < p2.gebJahr { return p1 } return p2 }
Kernidee: Ein Funktionsaufruf kann einen Zeiger liefern, und dieser Zeiger kann wie ein normaler Zeiger weiterverwendet werden.

2. Implizite Dereferenzierung beim Feldzugriff

Wenn ein Funktionsaufruf einen Zeiger auf einen Verbund liefert, darf direkt auf ein Feld zugegriffen werden. Go dereferenziert den Zeiger dabei implizit.

werIstÄlter(&otto1, &otto2).nachname += " senior"
Beobachtung: Obwohl der Rückgabewert ein Zeiger ist, wirkt der Zugriff auf nachname wie ein normaler Feldzugriff.
FormLesart
werIstÄlter(...).nachnameimplizite Dereferenzierung, dann Feldzugriff
(*werIstÄlter(...)).nachnameexplizite Dereferenzierung, dann Feldzugriff

3. Was auf der linken Seite stehen darf

Ein dereferenzierter Rückgabewert darf auf der linken Seite einer Zuweisung stehen, weil dann eine Variable adressiert wird. Ein bloßer Zeiger-Wert darf dort nicht stehen.

*werIstÄlter(&otto1, &otto2) = person{} // nicht zulässig: // werIstÄlter(&otto1, &otto2) = &person{}
Wichtig: Werte können nur Variablen zugewiesen werden. Ein Zeiger-Wert selbst ist keine Variable.

4. Zeiger als Parameter

Bei tüvErneuern(a *auto) bekommt die Funktion einen Zeiger auf den Verbund. Dadurch kann sie das Original verändern.

golf := auto{marke: "VW", kennzeichen: "M-FG574", tachostand: 12000, tüvJahr: 2024} tüvErneuern(&golf) fmt.Println(golf.tüvJahr) // 2026
Fazit: Wenn eine Funktion den Verbund verändern soll oder große Daten effizient übergeben werden sollen, ist der Zeiger-Parameter passend.

5. Wert als Parameter

Bei tüvErneuernWert(a auto) erhält die Funktion nur eine Kopie. Änderungen wirken deshalb nicht auf das Original zurück.

tüvErneuernWert(golf) fmt.Println(golf.tüvJahr) // bleibt 2024
Fazit: Der Wert-Parameter ist sinnvoll, wenn die Unveränderbarkeit des Originals geschützt werden soll.

6. Entscheidungshilfe

FragestellungEmpfehlung
Die Funktion soll Daten ändernZeiger auf den Verbund übergeben
Die Funktion soll nur lesen, aber effizient seinOft trotzdem Zeiger verwenden
Die Funktion soll das Original sicher schützenVerbund-Wert übergeben
Merksatz: Zeiger für Änderung oder Effizienz, Wert für Schutz und Kopie.
