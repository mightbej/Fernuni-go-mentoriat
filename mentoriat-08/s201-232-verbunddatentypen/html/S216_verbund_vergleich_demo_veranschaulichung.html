Kapitel 8.2.5: Vergleich von Verbünden

Veranschaulichung zu Vergleichbarkeit, Feld-fuer-Feld-Vergleich, Wertgleichheit und dem Unterschied zwischen gleichen Werten und gleichen Speicherstellen.
Ziel: zeigen, wann == und != auf struct-Werte anwendbar sind und warum Wertgleichheit nicht Identitaet bedeutet.

1. Wann ist ein struct vergleichbar?

Ein Verbund ist genau dann vergleichbar, wenn alle seine Feld-Typen vergleichbar sind. Dann koennen == und != verwendet werden.

Voraussetzung

Alle Feld-Typen muessen vergleichbar sein.

Folge

Der gesamte Verbund ist mit == und != vergleichbar.

Kernidee: Der Vergleich von struct ist feldweise und nicht nur oberflaechlich.

2. Vergleich Feld fuer Feld

Der Studienbrief zeigt das am Koordinaten-Beispiel. Nur wenn alle Felder gleich sind, ist auch der gesamte Verbund gleich.

a := koordinate{5, -7, 8}
b := koordinate{0, -7, 8}
fmt.Println(a == b)
b.x = 3 + 2
fmt.Println(a == b)
VergleichAussage
a == btrue nur wenn alle Feldwerte gleich sind
a.x == b.x && a.y == b.y && a.z == b.zentspricht dem internen Vergleichsmechanismus
Wichtig: Ein einziges unterschiedliches Feld macht den gesamten Vergleich false.

3. Gleicher Wert ist nicht gleiche Identitaet

Zwei Verbund-Variablen koennen denselben Wert haben und trotzdem verschiedene Variablen bleiben. Die Adressen sind dann verschieden.

p1 := person{vorname: "Anna", nachname: "Schmidt", alter: 30}
p2 := person{vorname: "Anna", nachname: "Schmidt", alter: 30}
fmt.Println(p1 == p2)
fmt.Println(&p1 == &p2)
Merksatz: Wertgleichheit bedeutet nicht Identitaet. Gleicher Inhalt ist nicht dieselbe Speicherstelle.

4. Zuweisung versus Vergleich

Eine Zuweisung kopiert den Wert. Danach sind die beiden Variablen getrennt. Aenderungen an einer Variable betreffen die andere nicht.

f1 := farbe{rot: 255, gruen: 0, blau: 0}
f2 := farbe{rot: 0, gruen: 255, blau: 0}
f2 = f1
f1.rot = 128
AktionFolge
f2 = f1Wert wird kopiert, Adressen bleiben verschieden
f1.rot = 128f2 bleibt unveraendert

5. Zeigervergleich ist etwas anderes

Vergleicht man Zeiger auf Verbunde, dann werden Adressen verglichen. Zwei unterschiedliche Zeiger koennen auf Verbunde mit gleichem Wert zeigen und trotzdem ungleich sein.

k1 := koordinate{5, 10, 15}
k2 := koordinate{5, 10, 15}
pk1 := &k1
pk2 := &k2
fmt.Println(k1 == k2)
fmt.Println(pk1 == pk2)
Unterscheidung: k1 == k2 vergleicht Werte, pk1 == pk2 vergleicht Adressen.
